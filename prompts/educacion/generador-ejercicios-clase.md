# Generador de ejercicios para clase…

**Tipo:** Prompt · **Área:** Formación · **Licencia:** CC BY 4.0

Prompt para pedir a una IA una lista de ejercicios ordenados por dificultad sobre cualquier tema y nivel.

## Qué es y qué hace

Prompt que pide a una IA una lista de ejercicios sobre un tema y nivel, ordenados de menor a mayor dificultad, cada uno con su respuesta entre corchetes. Entra tema, nivel, número de ejercicios y minutos; sale una hoja lista para copiar a un documento. Se usa en Claude, Codex, Gemini o una IA local, y el profesor debe comprobar las respuestas antes de repartirlas.

## Cómo usarla

1. Rellena tema, nivel y número de ejercicios
2. Pega el prompt en tu IA
3. Comprueba cada respuesta
4. Copia la hoja al documento

## Cuándo usarla

Necesitas una hoja de ejercicios de un tema concreto, ordenados de menos a más difíciles y con la respuesta de cada uno, para tus alumnos.

## Cómo ganar dinero con ella

Prepara cuadernillos de ejercicios para profesores particulares o academias, o véndelos como pack por materia y nivel ([TU PRECIO]). Comprueba tú las respuestas antes de repartirlos, porque la IA puede equivocarse.

- Cuadernillos de ejercicios por materia y nivel para profesores particulares.
- Hojas de repaso para academias antes de un examen.
- Banco de ejercicios por niveles para formadores de empresa con material propio.

**Precio orientativo:** 10–30 € por cuadernillo. *Cifra inventada para hacerte una idea, no una recomendación: investiga tu mercado y pon el precio que quieras.*

## El prompt (cópialo entero)

```text
Genera [NÚMERO] ejercicios sobre [TEMA] para alumnos de [NIVEL O CURSO].

Sigue estas reglas:
- Ordena los ejercicios de menor a mayor dificultad.
- Cada ejercicio debe tener un enunciado claro y, si hace falta, un ejemplo resuelto antes.
- Al final de cada ejercicio añade la respuesta correcta entre corchetes, así: [Respuesta: ...].
- No uses vocabulario más avanzado del nivel [NIVEL O CURSO].
- Si el tema necesita fórmulas, datos o un texto de apoyo, escríbelos antes de los ejercicios, no dentro de cada uno.

Formato de cada ejercicio:
1. Enunciado
2. Respuesta

Datos del ejercicio:
Tema: [TEMA]
Nivel: [NIVEL O CURSO]
Número de ejercicios: [NÚMERO]
Duración estimada para resolverlos: [MINUTOS] minutos

Devuélveme el resultado listo para copiar y pegar en un documento, sin explicaciones adicionales ni comentarios sobre lo que has hecho.
```
