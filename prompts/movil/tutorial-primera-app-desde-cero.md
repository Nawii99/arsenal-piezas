# Tutorial de mi primera app desde cero…

**Tipo:** Prompt · **Área:** Móvil · **Licencia:** CC BY 4.0

Prompt para pedirle a Claude un tutorial completo de tu primera app o juego, con el código entero y explicado, para usarlo en un móvil Android sin instalar nada.

## Qué es y qué hace

Es un prompt para pedir a una IA un tutorial completo de una primera app en un solo archivo HTML, con la lista de pasos, el código entero y la explicación de cada bloque. Entra el tipo de app y el tema; sale un guion para móvil Android con Chrome, sin instalar nada. Sirve en Claude, Codex, Gemini o una IA local, y también como base de un curso.

## Cómo usarla

1. Rellena tipo de app y tema
2. Pega el prompt en Claude, Codex, Gemini o una IA local
3. Sigue los pasos y prueba el archivo en el móvil

## Cuándo usarla

Es tu primera app y quieres un camino paso a paso, con el código entero y sin perderte entre tecnicismos.

## Cómo ganar dinero con ella

Aprende haciendo un primer producto vendible, como un quiz o un contador de hábitos para un nicho concreto, y ofrécelo después a negocios de ese nicho por un pago único de [TU PRECIO].

- Cursos de iniciación en móvil para personas mayores o autónomos, por alumno…
- Talleres para academias de formación que enseñan una primera app, por grupo…
- Material descargable de primera app para creadores de contenido, por producto…

**Precio orientativo:** 40–120 € por proyecto. *Cifra inventada para hacerte una idea, no una recomendación: investiga tu mercado y pon el precio que quieras.*

## El prompt (cópialo entero)

```text
Quiero hacer mi primera app y no he programado nunca. Guíame como si tuviera cero conocimientos.

Lo que quiero construir: un [TIPO DE APP: QUIZ / LISTA DE TAREAS / CONTADOR DE HÁBITOS / JUEGO DE MEMORIA] sobre [TEMA].
La usaré en mi móvil Android, en el navegador Chrome. No quiero instalar programas ni pagar nada.

Cómo quiero que me lo expliques:
1. Dame primero la lista de pasos que vamos a seguir, una frase por paso.
2. Dame el código en UN solo archivo HTML, entero y de una pieza. Nunca a trozos.
3. Debajo del código, explícame qué hace cada bloque en una frase, sin palabras técnicas. Si usas una, explícamela entre paréntesis.
4. Dime cómo pasar el archivo a mi móvil, cómo abrirlo con Chrome y cómo añadirlo a la pantalla de inicio para que parezca una app de verdad.
5. Dime tres cambios fáciles que pueda hacer yo solo para practicar (un color, un texto, una pregunta), con la línea exacta donde está cada cosa.

Reglas: no des nada por sabido, no uses librerías externas y, si el código no te cabe en una sola respuesta, avísame antes de empezar en vez de cortarlo por la mitad.
```
