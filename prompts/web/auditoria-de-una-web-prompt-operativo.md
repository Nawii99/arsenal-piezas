# Auditoría de una web · Prompt operativo…

**Tipo:** Prompt · **Área:** Web · **Licencia:** CC BY 4.0

Pregunta, escucha, haz diagnóstico de web en vivo.

## Qué es y qué hace

Entra la situación de tu web, el público y las restricciones, y la IA pide solo los datos imprescindibles. Sale una respuesta con resumen, tres riesgos, opciones comparadas por impacto y esfuerzo, problemas priorizados con cambios verificables y una primera acción de menos de 30 minutos. Funciona con Claude, Codex, Gemini o una IA local en una conversación.

## Cómo usarla

1. Rellena los datos de la web
2. Responde las preguntas de la IA
3. Aplica la primera acción y mide el resultado
4. Que lo revise un profesional

## Cuándo usarla

Cuando quieras mejorar claridad, accesibilidad, rendimiento y conversión sin recibir una respuesta genérica.

## Cómo ganar dinero con ella

Conviértelo en una sesión guiada de auditoría de una web o en un entregable recurrente para clientes.

- Sesión de diagnóstico de una web de servicios profesionales para mejorar la captación de contactos.
- Consultoría rápida para una tienda que quiere saber qué le frena a comprar en el móvil.
- Revisión guiada de una página de producto antes de una campaña de pago.

**Precio orientativo:** 100–250 € por sesión. *Cifra inventada para hacerte una idea, no una recomendación: investiga tu mercado y pon el precio que quieras.*

## El prompt (cópialo entero)

```text
Actúa como especialista prudente en auditoría de una web.

Objetivo: mejorar claridad, accesibilidad, rendimiento y conversión para equipo web.

Antes de empezar, pídeme únicamente los datos imprescindibles que falten. Distingue hechos, supuestos y dudas. No inventes cifras, fuentes, herramientas ni resultados. Explica los límites y no prometas resultados.

Trabaja en este orden:
1. Resume la situación y el resultado que debemos conseguir.
2. Señala los tres riesgos o huecos de información más importantes.
3. Propón opciones pequeñas y compara impacto, esfuerzo, coste y reversibilidad.
4. Crea el entregable: problemas priorizados y cambios verificables.
5. Cierra con una lista de comprobación, una primera acción de menos de 30 minutos y qué medir.

Datos:
- Situación: [SITUACIÓN]
- Público o usuario: [PÚBLICO]
- Recursos disponibles: [RECURSOS]
- Plazo: [PLAZO]
- Restricciones: [RESTRICCIONES]

Escribe en español claro. Si algo requiere validación externa, indícalo de forma explícita.
```
