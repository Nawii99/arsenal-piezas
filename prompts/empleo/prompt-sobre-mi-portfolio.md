# Prompt para escribir el "sobre mí" de tu web de currículum…

**Tipo:** Prompt · **Área:** Empleo y currículum · **Licencia:** CC BY 4.0

Texto listo para pegar en un chat de IA que redacta el párrafo de presentación de tu web de CV o portfolio en segundos, en vez de darle vueltas tú mismo durante media hora.

## Qué es y qué hace

Texto para pegar en una IA de texto (Claude, Codex, Gemini o una IA local) que redacta el párrafo de presentación de tu web de currículum o portfolio: máximo cuatro frases en primera persona, con tu puesto, tus años de experiencia, un punto fuerte con ejemplo real y el tipo de empresa que buscas. Si no le das un logro con cifra, no lo inventa. Sirve cuando ya tienes la web y te bloqueas escribiendo el texto.

## Cómo usarla

1. Rellena nombre, puesto, punto fuerte y tono
2. Pega el prompt en la IA
3. Lee el texto y cambia lo que no sea cierto
4. Que lo revise un profesional

## Cuándo usarla

Cuando ya has montado la web y te bloqueas escribiendo el párrafo de presentación: pegas este prompt con tus datos y sale en segundos, en vez de perder media hora dándole vueltas a cómo presentarte.

## Cómo ganar dinero con ella

Sirve como imán de leads para quien ofrezca montar webs de currículum como servicio: quien lo usa y se queda atascado con el resto de la web es candidato a pagar por que…

- Textos de presentación para webs de currículum de personas que buscan empleo…
- Pack de perfil profesional para autónomos que se presentan en su web…
- Taller de redacción de presentación para orientadores laborales…

**Precio orientativo:** 15–30 € por texto. *Cifra inventada para hacerte una idea, no una recomendación: investiga tu mercado y pon el precio que quieras.*

## El prompt (cópialo entero)

```text
Quiero que escribas el párrafo de presentación ("sobre mí") para mi web de currículum. Tiene que sonar a una persona real, no a un currículum copiado ni a una IA genérica.

Mis datos:
- Nombre: [TU NOMBRE]
- Puesto o sector al que aspiro: [PUESTO O SECTOR]
- Años de experiencia: [AÑOS DE EXPERIENCIA]
- Lo que hago mejor, con un ejemplo concreto: [TU PUNTO FUERTE CON UN EJEMPLO REAL]
- Un logro con cifra, si lo tengo: [LOGRO CON NÚMERO, O ESCRIBE 'NO TENGO' SI NO APLICA]
- Qué tipo de empresa o proyecto busco ahora: [TIPO DE EMPRESA O PROYECTO QUE BUSCAS]
- Tono que quiero: [FORMAL / CERCANO / DIRECTO]

Instrucciones para el texto:
- Máximo 4 frases cortas, en primera persona.
- Nada de frases hechas tipo "apasionado/a por", "gran capacidad de trabajo en equipo" u "orientado a resultados" sin un ejemplo detrás.
- Si no te doy un dato (por ejemplo el logro con cifra), no lo inventes: escribe el párrafo sin ese dato en vez de rellenar con algo falso.
- Dame 2 versiones distintas: una más corta para debajo de la foto y otra un poco más larga para una sección aparte.
- Al final dime en una línea qué parte del párrafo debería revisar yo a mano, porque solo yo puedo saber si es del todo cierta.
```
