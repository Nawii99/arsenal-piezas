# Mensaje comercial para cliente de edición de vídeo…

**Tipo:** Prompt · **Área:** Vídeo · **Licencia:** CC BY 4.0

Prompt para escribir un mensaje corto y directo que ofrece tu servicio de montaje a un cliente potencial concreto.

## Qué es y qué hace

Prompt para Claude, Codex, Gemini o una IA local que redacta un mensaje corto y directo para ofrecer un servicio de edición de vídeo a un cliente concreto. Entra tu servicio, plazo, precio y lo que incluye, y los datos del cliente y su vídeo actual; sale un mensaje en español de España sin tono de plantilla. Ejemplo: un mensaje a una tienda local con un vídeo de ritmo lento y un paquete de Reels. Se usa para captar clientes que ya publican contenido.

## Cómo usarla

1. Rellena tu servicio, precio y plazo
2. Añade datos del cliente y su problema
3. Revisa el tono y el precio
4. Envía el mensaje por el canal adecuado

## Cuándo usarla

Si quieres escribir a un cliente concreto, como una marca local o un creador, y ofrecerle tu edición sin sonar a plantilla. Rellenas tus datos y los suyos y sale un mensaje corto.

## Cómo ganar dinero con ella

Úsalo para captar clientes de edición de vídeo escribiendo a negocios que ya publican contenido. Cobra por el paquete que ofrezcas en el mensaje, [TU PRECIO], con revisiones y plazo definidos.

- Mensajes de captación para editores que buscan clientes locales…
- Plantillas de contacto para creadores que venden paquetes de edición…
- Secuencia de mensajes para negocios que ya publican vídeos…

**Precio orientativo:** 10–25 € por mensaje. *Cifra inventada para hacerte una idea, no una recomendación: investiga tu mercado y pon el precio que quieras.*

## El prompt (cópialo entero)

```text
Eres un editor de vídeo que ofrece un servicio de montaje profesional con [DAVINCI RESOLVE / CAPCUT / KDENLIVE] y quieres escribir un mensaje comercial claro para un cliente potencial.
Datos del negocio:
- Nombre o marca: [NOMBRE DEL SERVICIO]
- Tipo de vídeo que editas mejor: [REELS / YOUTUBE LARGO / BODAS / CORPORATIVO / PUBLICIDAD]
- Plazo de entrega habitual: [NUMERO] días laborables
- Precio del paquete que quieres ofrecer: [PRECIO] euros, incluye [QUE INCLUYE: NUMERO DE REVISIONES, SUBTITULOS, MUSICA CON LICENCIA]
- Un ejemplo de trabajo anterior (enlace o descripción breve): [ENLACE O DESCRIPCION]
Datos del cliente al que escribes:
- Nombre: [NOMBRE DEL CLIENTE]
- Qué tipo de contenido publica: [TIPO DE CONTENIDO]
- Problema que parece tener con su vídeo actual (si lo sabes): [PROBLEMA: RITMO LENTO, POCO ENGANCHE, CALIDAD DE AUDIO...]
Escribe un mensaje corto, en español de España, para enviar por [WHATSAPP / EMAIL / INSTAGRAM], con estas partes:
1. Una frase inicial que mencione algo concreto de su contenido, no una frase genérica de plantilla.
2. Qué le ofreces en una línea, sin tecnicismos de edición.
3. El precio y el plazo, sin esconderlos ni obligar a preguntar.
4. Una llamada a la acción simple: pedir 5 minutos de llamada o mandar un vídeo de muestra.
No uses superlativos ('el mejor', 'increíble', 'espectacular') ni prometas resultados de audiencia o ventas que no puedes garantizar.
Máximo 120 palabras. Sin emojis salvo que el cliente los use primero en su perfil.
```
