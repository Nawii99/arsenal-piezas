# Brief de edición para formato recurrente…

**Tipo:** Prompt · **Área:** Vídeo · **Licencia:** CC BY 4.0

Prompt para generar un brief de edición fijo de un formato de vídeo que se repite cada semana, así no se decide lo mismo cada vez que se monta.

## Qué es y qué hace

Prompt para pegar en Claude, Codex, Gemini o una IA local que genera un brief de edición fijo para un formato de vídeo que se repite, como un resumen semanal o un reel de novedades. Entra la plataforma, la duración, la estructura habitual, el estilo de rótulos, la música y los olvidos frecuentes; sale una lista de pasos de montaje que se repite cada vez. Ejemplo: un resumen semanal de 60 segundos con gancho, tres puntos y cierre. Se usa para no decidir la estructura en cada edición.

## Cómo usarla

1. Rellena los campos entre corchetes con tu formato
2. Pega el prompt en la IA
3. Guarda el brief como plantilla
4. Úsalo en cada edición del formato

## Cuándo usarla

Útil para quien monta el mismo tipo de vídeo (resumen semanal, reel de novedades) y pierde tiempo repensando la estructura cada vez.

## Cómo ganar dinero con ella

Se pega tal cual en Claude, Codex, Gemini o una IA local, rellenando los campos entre corchetes.

- Brief de edición para creadores que publican un formato semanal fijo…
- Plantilla de montaje para marcas que repiten el mismo tipo de vídeo…
- Documento de estilo de edición para equipos que publican cada semana…

**Precio orientativo:** 15–30 € por brief. *Cifra inventada para hacerte una idea, no una recomendación: investiga tu mercado y pon el precio que quieras.*

## El prompt (cópialo entero)

```text
Eres mi ayudante de montaje. Tengo un formato de vídeo que repito cada semana y quiero un brief de edición fijo que pueda seguir sin pensarlo cada vez, para no perder tiempo decidiendo lo mismo una y otra vez.

Datos del formato:
- Nombre del formato: [NOMBRE DEL FORMATO, EJ. RESUMEN SEMANAL]
- Plataforma de destino: [PLATAFORMA, EJ. INSTAGRAM REELS / YOUTUBE / TIKTOK]
- Duración objetivo: [DURACIÓN EN SEGUNDOS O MINUTOS]
- Programa de montaje que uso: [CAPCUT / DAVINCI RESOLVE / KDENLIVE]
- Estructura habitual del contenido: [EJ. GANCHO, 3 PUNTOS, CIERRE CON LLAMADA A LA ACCIÓN]
- Estilo de rótulos: [EJ. TÍTULOS GRANDES EN CADA CAMBIO DE IDEA / SOLO SUBTÍTULOS]
- Música o silencio: [TIPO DE MÚSICA O "SIN MÚSICA"]
- Cosas que suelo olvidar al montar: [EJ. BAJAR EL VOLUMEN DE LA MÚSICA CUANDO HABLO, PONER EL LOGO AL FINAL]

Con estos datos, dame un brief de edición en formato lista de pasos, en el orden en que tengo que hacer las cosas dentro del programa que uso, desde importar los clips hasta exportar. Incluye en qué paso van los rótulos, en qué paso baja la música, y un recordatorio final con las cosas que suelo olvidar. No me des consejos generales de edición, solo los pasos de este formato concreto.
```
