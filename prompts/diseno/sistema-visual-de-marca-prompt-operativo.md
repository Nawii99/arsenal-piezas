# Sistema visual de marca · Prompt operativo…

**Tipo:** Prompt · **Área:** Diseño · **Licencia:** CC BY 4.0

De la dispersión visual a reglas coherentes: paso a paso sin teoría ni endeudamiento.

## Qué es y qué hace

Prompt paso a paso que pide a una IA convertir una marca dispersa en reglas visuales coherentes: pide solo los datos que faltan, separa hechos de supuestos, compara opciones pequeñas y entrega tokens, composiciones y una lista de comprobación. Se usa en Claude, Codex, Gemini o una IA local. No garantiza resultados ni sustituye a un diseñador.

## Cómo usarla

1. Rellena situación, recursos y plazo
2. Pega el prompt en tu IA
3. Responde a las preguntas de datos
4. Aplica la primera regla y revísala

## Cuándo usarla

Cuando quieras convertir una marca dispersa en reglas visuales coherentes sin recibir una respuesta genérica.

## Cómo ganar dinero con ella

Conviértelo en una sesión guiada de sistema visual de marca o en un entregable recurrente para clientes.

- Sesión guiada de identidad visual para autónomos que quieren ordenar su imagen.
- Entregable de reglas visuales para diseñadores freelance que trabajan con pymes.
- Ordenación de marca para negocios locales que se preparan para una nueva temporada.

**Precio orientativo:** 30–80 € por sesión. *Cifra inventada para hacerte una idea, no una recomendación: investiga tu mercado y pon el precio que quieras.*

## El prompt (cópialo entero)

```text
Actúa como especialista prudente en sistema visual de marca.

Objetivo: convertir una marca dispersa en reglas visuales coherentes para diseñador o negocio pequeño.

Antes de empezar, pídeme únicamente los datos imprescindibles que falten. Distingue hechos, supuestos y dudas. No inventes cifras, fuentes, herramientas ni resultados. Explica los límites y no prometas resultados.

Trabaja en este orden:
1. Resume la situación y el resultado que debemos conseguir.
2. Señala los tres riesgos o huecos de información más importantes.
3. Propón opciones pequeñas y compara impacto, esfuerzo, coste y reversibilidad.
4. Crea el entregable: tokens, composiciones y lista de comprobación.
5. Cierra con una lista de comprobación, una primera acción de menos de 30 minutos y qué medir.

Datos:
- Situación: [SITUACIÓN]
- Público o usuario: [PÚBLICO]
- Recursos disponibles: [RECURSOS]
- Plazo: [PLAZO]
- Restricciones: [RESTRICCIONES]

Escribe en español claro. Si algo requiere validación externa, indícalo de forma explícita.
```
