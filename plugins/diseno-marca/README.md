# arsenal-diseno-marca · Diseño · Marca y sistema visual

Diseño · Marca y sistema visual: 12 subagentes, 9 comandos /, 4 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-diseno-marca@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| auditar-logo | Comando / | Revisa un logo que ya existe y te dice qué falla, qué versiones faltan y qué arreglar antes de usarlo en todas partes. | `/auditar-logo` |
| brief-logo | Comando / | Te hace 3 preguntas y entrega concepto de marca, 3 territorios visuales, paleta con hex, tipografías de Google Fonts, el brief para el diseñador y 3 prompts para Ideogram o Recraft. | `/brief-logo` |
| favicon-avatar | Comando / | Convierte tu marca en icono diminuto: favicon, avatar redondo, icono de app y marca de agua, con todos los tamaños. | `/favicon-avatar` |
| kit-entrega-marca | Comando / | Te prepara la lista exacta de archivos, formatos y nombres para entregar una marca a un cliente o a la imprenta sin líos. | `/kit-entrega-marca` |
| manual-marca-express | Comando / | Escribe el manual de marca en una hoja: reglas claras de logo, color, tipografía y tono que cualquiera puede seguir. | `/manual-marca-express` |
| moodboard-marca | Comando / | Convierte una idea vaga de marca en una dirección visual concreta: referencias, criterios y qué buscar, antes de diseñar nada. | `/moodboard-marca` |
| paleta-accesible | Comando / | Crea la paleta de color completa de tu marca con los códigos exactos, el papel de cada color y el contraste comprobado. | `/paleta-accesible` |
| pareja-tipografica | Comando / | Elige dos tipografías gratis que peguen entre sí y te monta la escala de tamaños completa para web y para papel. | `/pareja-tipografica` |
| plantillas-redes | Comando / | Diseña el sistema de plantillas para tus redes: medidas exactas, rejilla, zonas seguras y reglas para que todo se vea de la misma familia. | `/plantillas-redes` |
| mockup-producto-diseno | Skill | Coloca tu diseño, etiqueta o logotipo sobre un producto real (camiseta, taza, bote, caja) para enseñarlo antes de fabricar nada. | se activa sola cuando hace falta |
| pulir-diseno-visual-web-app | Skill | Revisa el diseño visual de tu web, tienda o app y propone cambios concretos de jerarquía, espacio, tipografía y color, ordenados por prioridad. | se activa sola cuando hace falta |
| sistema-visual-de-marca-skill-guiada | Skill | Skill portable que convierte sistema visual de marca en un proceso repetible y verificable. | se activa sola cuando hace falta |
| taller-creativos-visuales-anuncios-redes | Skill | Prepara y mejora piezas visuales (posts, banners, anuncios, miniaturas) a partir de un brief claro, con varias direcciones, formatos listos y los textos legales a revisar. | se activa sola cuando hace falta |
| auditor-de-coherencia-de-marca | Subagente | Revisa todas tus piezas publicadas (web, redes, PDFs, facturas) y saca la lista de dónde tu marca se está contradiciendo a sí misma. | pídele a Claude «usa el subagente auditor-de-coherencia-de-marca» |
| iconos-y-favicon-completos | Subagente | Genera todo el paquete de iconos de tu web y app (favicon, icono de móvil, imagen de compartir) con las medidas correctas. | pídele a Claude «usa el subagente iconos-y-favicon-completos» |
| kit-de-plantillas-para-redes | Subagente | Te crea plantillas propias de post, carrusel y story con tu marca, editables cambiando el texto, sin depender de Canva. | pídele a Claude «usa el subagente kit-de-plantillas-para-redes» |
| manual-de-marca-en-una-pagina | Subagente | Reúne todas tus decisiones de marca en una página web de una sola pantalla larga que puedes enviar a cualquier colaborador. | pídele a Claude «usa el subagente manual-de-marca-en-una-pagina» |
| ordenar-el-archivo-de-marca | Subagente | Pone orden en tu carpeta de diseños: nombres claros, versiones, duplicados fuera y una estructura donde encuentras todo en segundos. | pídele a Claude «usa el subagente ordenar-el-archivo-de-marca» |
| ordenar-estilos-web | Subagente | Revisa los estilos de una web (CSS o Sass), encuentra lo repetido y propone colores, tamaños y espacios con nombre fijo, sin cambiar cómo se ve. | pídele a Claude «usa el subagente ordenar-estilos-web» |
| plan-formacion-continua | Subagente | Te prepara un plan de formación por semanas, con objetivo medible, práctica, sistema de repaso y recursos por verificar, para una persona o un equipo pequeño. | pídele a Claude «usa el subagente plan-formacion-continua» |
| revisor-de-contraste-y-accesibilidad | Subagente | Comprueba si tus colores y tipos se leen de verdad (también con sol, en móvil o con la vista cansada) y te da los HEX corregidos. | pídele a Claude «usa el subagente revisor-de-contraste-y-accesibilidad» |
| sistema-tipografico-de-marca | Subagente | Elige la pareja de tipografías gratis de tu marca y monta la escala completa de tamaños, pesos e interlineados que se usa en todo. | pídele a Claude «usa el subagente sistema-tipografico-de-marca» |
| sistema-visual-de-marca-subagente-revisor | Subagente | Revisión de tu marca: tokens, composiciones, qué mejorar para que se reconozca al momento. | pídele a Claude «usa el subagente sistema-visual-de-marca-subagente-revisor» |
| tokens-de-marca-a-css | Subagente | Convierte tu marca (colores, tipos, espacios) en variables CSS listas para pegar en cualquier web o plantilla y que todo salga igual siempre. | pídele a Claude «usa el subagente tokens-de-marca-a-css» |
| variantes-de-logo-para-todo | Subagente | A partir de tu logo, define y genera todas las versiones que vas a necesitar: horizontal, apilada, símbolo solo, negativo y tamaños mínimos. | pídele a Claude «usa el subagente variantes-de-logo-para-todo» |
