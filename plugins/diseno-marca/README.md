# arsenal-diseno-marca · Diseño · Marca y sistema visual

Diseño · Marca y sistema visual: 9 subagentes, 8 comandos /, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-diseno-marca@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| auditar-logo | Comando / | Revisa un logo que ya existe y te dice qué falla, qué versiones faltan y qué arreglar antes de usarlo en todas partes. | `/auditar-logo` o `/arsenal-diseno-marca:auditar-logo` |
| brief-logo | Comando / | Te hace 3 preguntas y entrega concepto de marca, 3 territorios visuales, paleta con hex, tipografías de Google Fonts, el brief para el diseñador y 3 prompts para Ideogram o Recraft. | `/brief-logo` o `/arsenal-diseno-marca:brief-logo` |
| favicon-avatar | Comando / | Convierte tu marca en icono diminuto: favicon, avatar redondo, icono de app y marca de agua, con todos los tamaños. | `/favicon-avatar` o `/arsenal-diseno-marca:favicon-avatar` |
| kit-entrega-marca | Comando / | Te prepara la lista exacta de archivos, formatos y nombres para entregar una marca a un cliente o a la imprenta sin líos. | `/kit-entrega-marca` o `/arsenal-diseno-marca:kit-entrega-marca` |
| manual-marca-express | Comando / | Escribe el manual de marca en una hoja: reglas claras de logo, color, tipografía y tono que cualquiera puede seguir. | `/manual-marca-express` o `/arsenal-diseno-marca:manual-marca-express` |
| moodboard-marca | Comando / | Convierte una idea vaga de marca en una dirección visual concreta: referencias, criterios y qué buscar, antes de diseñar nada. | `/moodboard-marca` o `/arsenal-diseno-marca:moodboard-marca` |
| nombre-marca | Comando / | Genera 20 nombres en 4 estilos con pronunciación, por qué funcionan y su pega si la hay. Elige 3 favoritos y te dice qué comprobar: dominio, redes y registro de marcas. | `/nombre-marca` o `/arsenal-diseno-marca:nombre-marca` |
| paleta-accesible | Comando / | Crea la paleta de color completa de tu marca con los códigos exactos, el papel de cada color y el contraste comprobado. | `/paleta-accesible` o `/arsenal-diseno-marca:paleta-accesible` |
| sistema-visual-de-marca-skill-guiada | Skill | Skill portable que convierte sistema visual de marca en un proceso repetible y verificable. | se activa sola cuando hace falta |
| auditor-de-coherencia-de-marca | Subagente | Revisa todas tus piezas publicadas (web, redes, PDFs, facturas) y saca la lista de dónde tu marca se está contradiciendo a sí misma. | pídele a Claude «usa el subagente auditor-de-coherencia-de-marca» |
| iconos-y-favicon-completos | Subagente | Genera todo el paquete de iconos de tu web y app (favicon, icono de móvil, imagen de compartir) con las medidas correctas. | pídele a Claude «usa el subagente iconos-y-favicon-completos» |
| manual-de-marca-en-una-pagina | Subagente | Reúne todas tus decisiones de marca en una página web de una sola pantalla larga que puedes enviar a cualquier colaborador. | pídele a Claude «usa el subagente manual-de-marca-en-una-pagina» |
| ordenar-el-archivo-de-marca | Subagente | Pone orden en tu carpeta de diseños: nombres claros, versiones, duplicados fuera y una estructura donde encuentras todo en segundos. | pídele a Claude «usa el subagente ordenar-el-archivo-de-marca» |
| revisor-de-contraste-y-accesibilidad | Subagente | Comprueba si tus colores y tipos se leen de verdad (también con sol, en móvil o con la vista cansada) y te da los HEX corregidos. | pídele a Claude «usa el subagente revisor-de-contraste-y-accesibilidad» |
| sistema-tipografico-de-marca | Subagente | Elige la pareja de tipografías gratis de tu marca y monta la escala completa de tamaños, pesos e interlineados que se usa en todo. | pídele a Claude «usa el subagente sistema-tipografico-de-marca» |
| sistema-visual-de-marca-subagente-revisor | Subagente | Revisión de tu marca: tokens, composiciones, qué mejorar para que se reconozca al momento. | pídele a Claude «usa el subagente sistema-visual-de-marca-subagente-revisor» |
| tokens-de-marca-a-css | Subagente | Convierte tu marca (colores, tipos, espacios) en variables CSS listas para pegar en cualquier web o plantilla y que todo salga igual siempre. | pídele a Claude «usa el subagente tokens-de-marca-a-css» |
| variantes-de-logo-para-todo | Subagente | A partir de tu logo, define y genera todas las versiones que vas a necesitar: horizontal, apilada, símbolo solo, negativo y tamaños mínimos. | pídele a Claude «usa el subagente variantes-de-logo-para-todo» |
