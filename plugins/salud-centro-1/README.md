# arsenal-salud-centro-1 · Salud y deporte · Gestión del centro (1)

Salud y deporte · Gestión del centro (1): 12 comandos /, 7 skills, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-salud-centro-1@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| barreras-agente-pacientes | Comando / | Revisa cómo está configurado Claude Code en un proyecto con datos de pacientes y redacta barreras y un registro de actividad para que los aplique una persona. | `/barreras-agente-pacientes` |
| bienestar-para-empresas | Comando / | Prepara la propuesta para vender tus servicios de bienestar a empresas de tu zona, con formatos, precios y email de contacto. | `/bienestar-para-empresas` |
| bonos-y-ocupacion | Comando / | Diseña bonos y packs de sesiones con precios que aguanten, y calcula cuántas horas necesitas llenar para que la sala salga rentable. | `/bonos-y-ocupacion` |
| bonos-y-packs | Comando / | Diseña bonos de sesiones y packs con precio, caducidad y condiciones claras, y calcula qué le hacen a tu caja y a tu agenda. | `/bonos-y-packs` |
| cuadro-mando-clinica | Comando / | Monta el cuadro de mando mensual de tu centro: qué seis números mirar, cómo calcularlos con lo que ya tienes y qué hacer con cada uno. | `/cuadro-mando-clinica` |
| factura-consulta-sanitaria | Comando / | Genera el texto de una factura de consulta sanitaria en España con la mención de exención de IVA correcta, a partir de cuatro datos. | `/factura-consulta-sanitaria` |
| fotos-evolucion | Comando / | Monta el protocolo para hacer fotos de evolución que se puedan comparar de verdad: permiso, encuadre fijo, luz y dónde se guardan. | `/fotos-evolucion` |
| onboarding-nutricion | Comando / | Comando que genera el cuestionario de alta y la propuesta de precio para un cliente nuevo del servicio de nutrición, antes de calcular nada. | `/onboarding-nutricion` |
| proteger-datos-clinica | Comando / | Revisa cómo guardas y compartes los datos de salud de tus clientes y te da la lista de arreglos concretos, ordenados por riesgo. | `/proteger-datos-clinica` |
| protocolo-datos-clinica | Comando / | Revisa cómo guardas y compartes los datos de tus pacientes y te da el protocolo corregido, en lenguaje normal. | `/protocolo-datos-clinica` |
| protocolo-derivacion | Comando / | Crea el protocolo escrito para que tu equipo sepa cuándo parar, no opinar y derivar a un profesional sanitario, con las frases exactas. | `/protocolo-derivacion` |
| revisar-publicidad-sanitaria | Comando / | Revisa tus textos de salud y bienestar para quitar promesas de curación, testimonios problemáticos y afirmaciones que te pueden meter en un lío. | `/revisar-publicidad-sanitaria` |
| adherencia-ejercicios-casa | Skill | Cómo hacer que el paciente cumpla la pauta de casa: recordatorios, registro y revisión. | se activa sola cuando hace falta |
| consentimiento-y-datos-clinica | Skill | Prepara los textos de consentimiento y protección de datos de una clínica pequeña en España, y la lista de lo que hay que tener guardado y firmado. | se activa sola cuando hace falta |
| cuadro-mando-clinica-skill | Skill | Monta el panel de cinco números que dice de verdad cómo va una clínica, con la fórmula de cada uno y qué hacer si sale mal. | se activa sola cuando hace falta |
| protocolo-de-alta | Skill | Diseña cómo se da el alta y qué pasa después: la sesión de cierre, el plan de mantenimiento y los contactos de seguimiento a 1, 3 y 12 meses. | se activa sola cuando hace falta |
| protocolo-sala-y-material | Skill | Escribe el protocolo diario de apertura, entre pacientes y cierre de la sala, con higiene, material y control de stock. | se activa sola cuando hace falta |
| resenas-clinica-sin-datos | Skill | Responde reseñas de una clínica sin confirmar que esa persona es paciente ni dar un solo dato de salud, y monta el sistema para pedir reseñas legalmente. | se activa sola cuando hace falta |
| revisar-publicidad-sanitaria-skill | Skill | Revisa tus textos de web, redes y folletos para quitar promesas prohibidas y dejarlos correctos sin que pierdan fuerza comercial. | se activa sola cuando hace falta |
| analista-resenas-centro | Subagente | Lee tus reseñas, saca el patrón de quejas y elogios, te deja respuestas sin revelar datos de salud. | pídele a Claude «usa el subagente analista-resenas-centro» |
