# arsenal-negocio-estrategia-1 · Negocio · Plan y estrategia (1)

Negocio · Plan y estrategia (1): 19 skills, 3 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-estrategia-1@arsenal
```
