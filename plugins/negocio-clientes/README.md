# arsenal-negocio-clientes · Negocio · Clientes y atención

Negocio · Clientes y atención: 10 skills, 8 subagentes, 3 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-clientes@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| faq-negocio | Comando / | Crea 20 preguntas frecuentes con respuesta, respuestas rápidas y mensajes de bienvenida y ausencia para WhatsApp Business, variantes para chatbot y qué debe pasar a una persona. | `/faq-negocio` o `/arsenal-negocio-clientes:faq-negocio` |
| recordatorio-citas | Comando / | Monta el sistema de citas de un negocio local: herramienta de reservas gratis, mensajes de confirmación y recordatorio, automatización con n8n o Make, política de cancelación y qué medir. | `/recordatorio-citas` o `/arsenal-negocio-clientes:recordatorio-citas` |
| respuestas-clientes | Comando / | Analiza el mensaje de un cliente y te da un diagnóstico, una respuesta lista para copiar, una versión firme, una versión para reseña pública y cómo evitar que se repita. | `/respuestas-clientes` o `/arsenal-negocio-clientes:respuestas-clientes` |
| atencion-whatsapp-fuera-de-horario | Skill | Monta la atención por WhatsApp Business de un negocio: respuestas rápidas, mensajes fuera de horario, clasificación de consultas, reglas para pasar a una persona y resumen diario. | se activa sola cuando hace falta |
| bandeja-clientes-borrador-revisado | Skill | Lee el hilo entero de cada email de cliente, lo clasifica por urgencia y tipo y deja un borrador de respuesta sin enviar para que una persona lo revise. | se activa sola cuando hace falta |
| escalera-atencion-cliente-autoservicio-ia-personas | Skill | Reparte la atención al cliente entre autoservicio, asistente de IA y personas, con reglas claras de cuándo pasar de un nivel al siguiente. | se activa sola cuando hace falta |
| gorgias-clasificar-tickets-y-borradores | Skill | Lee los tickets abiertos en Gorgias, los clasifica por tipo y urgencia y deja un borrador de respuesta para que lo revise una persona. | se activa sola cuando hace falta |
| mapa-donantes-valor | Skill | Segmenta a los donantes de una ONG según cuándo, cuánto y con qué frecuencia donan, y propone qué hacer con cada grupo. | se activa sola cuando hace falta |
| montar-chatwoot-para-clientes | Skill | Instala y configura Chatwoot para que un negocio pequeño atienda a sus clientes por chat, email o WhatsApp, y deja montado el cobro de instalación y mantenimiento. | se activa sola cuando hace falta |
| pedir-archivos-dropbox | Skill | Prepara una solicitud de archivos de Dropbox ordenada: qué pedir, cómo nombrarlo, el mensaje para enviar y el seguimiento de lo que llega. | se activa sola cuando hace falta |
| triaje-casos-service-cloud | Skill | Ordena la cola de casos de Service Cloud por urgencia y tema, resume cada conversación y deja borradores de respuesta que revisa una persona. | se activa sola cuando hace falta |
| whatsapp-api-oficial-avisos-y-citas | Skill | API oficial WhatsApp para avisos pedido, envío, cita: plantillas, flujo n8n, paso a persona. | se activa sola cuando hace falta |
| whatsapp-mucho-volumen-bandeja-y-calidad | Skill | Organiza la atención por WhatsApp cuando entran muchos mensajes: reparto entre personas, respuestas automáticas con salida a persona, reglas de escalado y vigilancia del número. | se activa sola cuando hace falta |
| atencion-al-cliente | Subagente | Clasifica mensajes de clientes y redacta respuestas con el tono de tu marca, versiones firme y pública, respuestas rápidas y FAQ, y escala a una persona lo delicado. | pídele a Claude «usa el subagente atencion-al-cliente» |
| atencion-cliente-con-seguimiento | Subagente | Ordena la atención al cliente de un negocio pequeño: motivos de consulta, respuestas modelo, qué contesta una persona y qué una máquina, y avisos proactivos tras la compra. | pídele a Claude «usa el subagente atencion-cliente-con-seguimiento» |
| auditoria-de-promesas-cumplidas | Subagente | Contrasta lo que tu negocio promete con lo que entrega de verdad y propone, para cada diferencia, ajustar la promesa o la forma de trabajar. | pídele a Claude «usa el subagente auditoria-de-promesas-cumplidas» |
| control-de-renovaciones-y-caducidades | Subagente | Ordena renovaciones y caducidades de tus clientes (suscripciones, licencias, mantenimientos, dominios) y te prepara los avisos y las reglas del periodo de gracia, sin enviar ni cobrar nada. | pídele a Claude «usa el subagente control-de-renovaciones-y-caducidades» |
| entrenador-comunicacion-ensayos | Subagente | Prepara tu comunicación con ensayo escrito: revisa tus mensajes, escribe las réplicas y objeciones de la otra parte con huecos para que respondas, y te da comentarios y un plan de práctica. | pídele a Claude «usa el subagente entrenador-comunicacion-ensayos» |
| guia-trato-intercultural | Subagente | Prepara un trato, un mensaje o una reunión con personas de otra cultura, con hipótesis que comprobar y un texto adaptado. | pídele a Claude «usa el subagente guia-trato-intercultural» |
| plan-arranque-cliente-empresa | Subagente | Plan de arranque de empresa grande: fases, personas, formación, comunicación, riesgos. | pídele a Claude «usa el subagente plan-arranque-cliente-empresa» |
| plan-recuperar-confianza | Subagente | Ordena lo ocurrido en un conflicto con un cliente, tu equipo o un socio, detecta qué confianza se rompió y prepara un plan a 7, 30 y 90 días con un borrador de reconocimiento. | pídele a Claude «usa el subagente plan-recuperar-confianza» |
