# arsenal-ecommerce-varios · Tienda por internet · Más de tienda por internet

Tienda por internet · Más de tienda por internet: 13 skills, 5 comandos /, 2 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ecommerce-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| pagina-producto | Comando / | Genera el HTML de una página de producto autoalojable, sin plantilla de pago, con el botón de compra enlazado a un Payment Link de Stripe ya creado. | `/pagina-producto` o `/arsenal-ecommerce-varios:pagina-producto` |
| revisar-anuncio-de-oferta | Comando / | Revisa un anuncio de oferta antes de publicarlo: urgencia verdadera, precio anterior bien indicado y condiciones claras, con semáforo y propuesta de corrección. | `/revisar-anuncio-de-oferta` o `/arsenal-ecommerce-varios:revisar-anuncio-de-oferta` |
| revisar-correo-transaccional | Comando / | Revisa un correo de pedido ya escrito: claridad, datos que faltan, tono y qué comprobar en la ley, con la frase literal y un arreglo mínimo por fallo. | `/revisar-correo-transaccional` o `/arsenal-ecommerce-varios:revisar-correo-transaccional` |
| revisar-fila-feed | Comando / | Revisa una fila o un trozo de tu feed de productos y te dice qué atributos faltan, cuáles están mal puestos y qué valor poner, con una tabla de corrección. | `/revisar-fila-feed` o `/arsenal-ecommerce-varios:revisar-fila-feed` |
| stock-decidir | Comando / | Analiza el listado de ventas y existencias que le pegas y devuelve qué reponer, qué liquidar y qué vigilar, con las cuentas escritas producto a producto. | `/stock-decidir` o `/arsenal-ecommerce-varios:stock-decidir` |
| adaptar-ficha-a-un-marketplace-concreto | Skill | Convierte la ficha de un producto en el anuncio de un marketplace concreto: título, viñetas, descripción, atributos, fotos y normas por comprobar. | se activa sola cuando hace falta |
| auditoria-conversion-camino-de-compra | Skill | Guía una auditoría del camino de compra: qué datos sacar de tu analítica, qué mirar en cada paso y cómo ordenar los arreglos por esfuerzo e impacto. | se activa sola cuando hace falta |
| avisos-envio-control-entregas | Skill | Revisa el estado de los envíos de un negocio, señala los pedidos parados o con incidencia y redacta los avisos al cliente para que tú los apruebes. | se activa sola cuando hace falta |
| calendario-comercial-anual-y-precio-rebajado-legal | Skill | Planifica el calendario de campañas del año de una tienda online y da la lista para comprobar un precio rebajado frente a la norma de precio anterior. | se activa sola cuando hace falta |
| diagnostico-rechazo-productos-merchant-center | Skill | Lee el aviso de Merchant Center sobre productos rechazados, explica la causa en lenguaje llano y da el orden de corrección y qué comprobar. | se activa sola cuando hace falta |
| disenar-secuencia-carrito-abandonado | Skill | Diseña la secuencia de correos para recuperar carritos abandonados: cuántos, cuándo, qué dice cada uno y a quién no escribir, con el consentimiento por delante. | se activa sola cuando hace falta |
| hoja-de-stock-tienda-minimo-y-reposicion | Skill | Monta un control de stock en hoja de cálculo: columnas, umbrales y fórmulas para saber qué reponer, cuánto pedir y qué no rota, con tus ventas reales. | se activa sola cuando hace falta |
| plan-correos-postcompra-tienda | Skill | Planifica los correos de después de la compra: confirmación, envío, entrega, opinión y recompra, separando los avisos de los comerciales. | se activa sola cuando hace falta |
| revision-stock-reposicion-odoo | Skill | Analiza una exportación de stock y ventas de Odoo, dice qué falta, qué sobra y cuánto dinero hay parado, y propone reglas de reposición y ubicaciones para probar, sin tocar Odoo. | se activa sola cuando hace falta |
| sistema-de-opiniones-de-tienda-online | Skill | Monta el sistema de opiniones de una tienda online: cuándo pedirlas, con qué texto, cómo responder (también las malas) y qué prácticas no se pueden hacer. | se activa sola cuando hace falta |

| taller-fichas-de-producto | Skill | Escribe o mejora fichas de producto para tu tienda online usando solo datos reales: título, beneficios, descripción, preguntas frecuentes y textos para buscadores. | se activa sola cuando hace falta |
| tienda-woocommerce-espana-paso-a-paso | Skill | Guía el montaje o la mejora de una tienda WooCommerce en España: pagos, envíos, variantes, ventas cruzadas, IVA y textos legales, siempre probando antes en una copia. | se activa sola cuando hace falta |
| revisor-de-anuncio-de-marketplace | Subagente | Revisa un anuncio de marketplace antes de publicarlo y devuelve un informe de fallos ordenados por gravedad, con la frase exacta, el motivo y cómo corregirlo. | pídele a Claude «usa el subagente revisor-de-anuncio-de-marketplace» |
| revisor-pagina-de-producto-fricciones | Subagente | Revisa una página de producto a partir de su texto o de una captura y devuelve un informe de fricciones con cita literal, arreglo propuesto y esfuerzo. | pídele a Claude «usa el subagente revisor-pagina-de-producto-fricciones» |
