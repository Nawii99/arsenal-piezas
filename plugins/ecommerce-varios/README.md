# arsenal-ecommerce-varios · Tienda por internet · Más de tienda por internet

Tienda por internet · Más de tienda por internet: 5 skills, 1 comando / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ecommerce-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| pagina-producto | Comando / | Genera el HTML de una página de producto autoalojable, sin plantilla de pago, con el botón de compra enlazado a un Payment Link de Stripe ya creado. | `/pagina-producto` o `/arsenal-ecommerce-varios:pagina-producto` |
| avisos-envio-control-entregas | Skill | Revisa el estado de los envíos de un negocio, señala los pedidos parados o con incidencia y redacta los avisos al cliente para que tú los apruebes. | se activa sola cuando hace falta |
| revision-stock-reposicion-odoo | Skill | Analiza una exportación de stock y ventas de Odoo, dice qué falta, qué sobra y cuánto dinero hay parado, y propone reglas de reposición y ubicaciones para probar, sin tocar Odoo. | se activa sola cuando hace falta |
| stock-coherente-zoho-inventory | Skill | Compara el stock de Zoho Inventory con tus canales de venta, localiza descuadres por código de producto y prepara los ajustes para que los apruebes. | se activa sola cuando hace falta |
| taller-fichas-de-producto | Skill | Escribe o mejora fichas de producto para tu tienda online usando solo datos reales: título, beneficios, descripción, preguntas frecuentes y textos para buscadores. | se activa sola cuando hace falta |
| tienda-woocommerce-espana-paso-a-paso | Skill | Guía el montaje o la mejora de una tienda WooCommerce en España: pagos, envíos, variantes, ventas cruzadas, IVA y textos legales, siempre probando antes en una copia. | se activa sola cuando hace falta |
