# arsenal-ventas-captar-3 · Ventas · Captar clientes (3)

Ventas · Captar clientes (3): 14 subagentes, 5 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ventas-captar-3@arsenal
```
