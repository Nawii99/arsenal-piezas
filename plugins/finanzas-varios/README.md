# arsenal-finanzas-varios · Finanzas · Más de finanzas

Finanzas · Más de finanzas: 4 subagentes, 4 comandos /, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-finanzas-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| cierre-mensual-negocio | Comando / | Rutina de cierre de mes en una hora: qué números miras, cómo comparas con lo previsto y qué tres decisiones tomas antes del día 5. | `/cierre-mensual-negocio` o `/arsenal-finanzas-varios:cierre-mensual-negocio` |
| colchon-de-tesoreria | Comando / | Calcula cuánto dinero deberías tener parado por si vienen mal dadas y te monta el plan de cuentas separadas para llegar ahí sin ahogarte. | `/colchon-de-tesoreria` o `/arsenal-finanzas-varios:colchon-de-tesoreria` |
| comprar-o-no-herramienta | Comando / | Decide si merece la pena comprar esa herramienta, equipo o suscripción cara: coste real, en cuánto se paga sola y qué alternativas hay antes. | `/comprar-o-no-herramienta` o `/arsenal-finanzas-varios:comprar-o-no-herramienta` |
| podar-gastos-fijos | Comando / | Revisa todas tus cuotas, suscripciones y gastos recurrentes, señala cuáles sobran o están duplicadas y te da el guion para dar de baja o renegociar. | `/podar-gastos-fijos` o `/arsenal-finanzas-varios:podar-gastos-fijos` |
| finanzas-pyme | Skill | Reglas de finanzas para autónomos y pymes en España: margen por venta, tesorería, cobros, impuestos básicos, precios y qué medir cada mes. | se activa sola cuando hace falta |
| comprar-renting-o-leasing | Subagente | Subagente que compara comprar al contado, financiar, leasing o renting para una inversión concreta y te dice qué opción sale mejor y cuándo se recupera. | pídele a Claude «usa el subagente comprar-renting-o-leasing» |
| dinero-parado-en-stock | Subagente | Calcula cuánto dinero dormido tienes en existencias, qué rota, qué liquidar para recuperar caja. Una persona revisa. | pídele a Claude «usa el subagente dinero-parado-en-stock» |
| reparto-en-botes | Subagente | Monta tu sistema: cada euro que entra se reparte en botes con destino (impuestos, colchón, sueldo). Una persona comprueba. | pídele a Claude «usa el subagente reparto-en-botes» |
| tesoreria-13-semanas | Subagente | Subagente que construye tu previsión de caja semana a semana para 13 semanas y te avisa de en qué semana te quedas sin dinero. | pídele a Claude «usa el subagente tesoreria-13-semanas» |
