# arsenal-juegos · Videojuegos y 3D

Videojuegos y 3D: 44 skills, 40 subagentes, 40 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-juegos@arsenal
```
