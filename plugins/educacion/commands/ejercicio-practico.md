Vas a diseñar un ejercicio práctico para que el alumno practique: $ARGUMENTS
La regla de oro: el ejercicio debe parecerse a la tarea real, no a un examen.

PASO 1. Preguntas (máximo 4)
1. ¿Qué acaba de aprender el alumno justo antes de este ejercicio?
2. ¿Cuánto tiempo quieres que le lleve? (recomendado entre 15 y 45 minutos)
3. ¿Lo corrige él solo, lo corriges tú, o se corrigen entre compañeros?
4. ¿Con qué herramientas cuenta?

PASO 2. Elige el nivel de andamiaje
Primer contacto: le das el caso, los datos y un ejemplo resuelto a medias.
Consolidación: le das el caso y los datos, sin ejemplo.
Transferencia: le das solo el objetivo y él decide los datos y el camino.
Elige uno y justifícalo en una línea. Si el alumno acaba de ver el tema, no le pongas transferencia.

PASO 3. Construye el ejercicio
Escribe un caso con contexto real: un cliente, un negocio, una situación con nombres y cifras concretas.
Prepara los DATOS DE PARTIDA que el alumno necesita, ya listos para copiar y pegar. Si tiene que inventarse los datos, la mitad se atasca ahí.
Divide la tarea en 3 a 5 pasos numerados y verificables.
Añade una AMPLIACIÓN opcional para quien acabe rápido, para que no se aburra ni te pregunte.
Añade una PISTA que se lea solo si se atasca, colocada al final y avisada.

PASO 4. Criterio de calidad para el alumno
Escribe una lista de comprobación de 5 a 8 puntos en la que el alumno pueda responder sí o no sin depender de ti.
Cada punto es observable: no vale que quede bien, sí vale que el archivo abre sin error o que el precio cubre coste más margen.

PASO 5. Solución modelo
Da la solución completa y, sobre todo, explica las decisiones: por qué esta opción y no la otra.
Añade dos SOLUCIONES ALTERNATIVAS válidas si las hay, para que el alumno no crea que solo hay un camino.

ERRORES TÍPICOS QUE DEBES EVITAR
Ejercicios de rellenar huecos: no enseñan a decidir.
Enunciados ambiguos: si dos personas pueden entender cosas distintas, reescríbelo.
Ejercicios que dependen de una herramienta de pago que el alumno no tiene.
Poner un ejercicio de 3 horas dentro de un módulo de 40 minutos.

FORMATO DE SALIDA EXACTO
1) TÍTULO Y OBJETIVO en una línea.
2) TIEMPO ESTIMADO y nivel de andamiaje elegido.
3) ENUNCIADO listo para copiar, con el caso y los pasos numerados.
4) DATOS DE PARTIDA en bloque aparte.
5) LISTA DE COMPROBACIÓN del alumno (casillas).
6) PISTA (bajo el aviso: léela solo si llevas 10 minutos atascado).
7) AMPLIACIÓN opcional.
8) SOLUCIÓN MODELO comentada + alternativas válidas.
9) PARA EL FORMADOR: los 3 fallos que vas a ver más y qué decir en cada caso.

Antes de entregar, verifica que el ejercicio se puede resolver SOLO con lo enseñado hasta ese punto del curso. Si hace falta algo que no se ha explicado, córrígelo o añádelo a los datos de partida.
