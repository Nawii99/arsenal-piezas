# arsenal-empleo-varios · Empleo y currículum · Más de empleo y currículum

Empleo y currículum · Más de empleo y currículum: 5 subagentes, 3 comandos /, 2 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-empleo-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| carta-con-tu-voz | Comando / | Genera una carta de presentación desde la oferta y tu perfil, y la reescribe con tu forma de escribir, sin inventar nada. | `/carta-con-tu-voz` o `/arsenal-empleo-varios:carta-con-tu-voz` |
| presupuesto-cv-web | Comando / | Comando que, a partir de dos o tres respuestas del cliente, genera un presupuesto listo para copiar y enviar por email o WhatsApp. | `/presupuesto-cv-web` o `/arsenal-empleo-varios:presupuesto-cv-web` |
| presupuesto-servicio-cv | Comando / | Comando de Claude Code que redacta un presupuesto formal para un encargo de currículum o carta de presentación, listo para pegar en un email. | `/presupuesto-servicio-cv` o `/arsenal-empleo-varios:presupuesto-servicio-cv` |
| carta-con-investigacion | Skill | Investiga la empresa antes de escribir la carta de presentación y la redacta con datos reales, no con adjetivos vacíos. | se activa sola cuando hace falta |
| montar-servicio-candidatos | Skill | Convierte tu ayuda a candidatos en un servicio de verdad: paquetes, precios, alcance cerrado, condiciones y alta de autonomo en Espana. | se activa sola cuando hace falta |
| brujula-giro-profesional | Subagente | Giro profesional pensado: pruebas pequeñas a 90 días con tus cifras, sin saltos ciegos. | pídele a Claude «usa el subagente brujula-giro-profesional» |
| critico-carta-presentacion | Subagente | Revisa una carta de presentación ya escrita y señala sin suavizarlo qué frases son relleno, qué suena genérico y qué la hace indistinguible de las de cualquier otro candidato. | pídele a Claude «usa el subagente critico-carta-presentacion» |
| gestor-servicio-cv | Subagente | Coordina un encargo de pago de CV y carta de presentación de principio a fin, desde los datos del cliente hasta el paquete final listo para entregar. | pídele a Claude «usa el subagente gestor-servicio-cv» |
| hoja-de-ruta-profesional-tres-anos | Subagente | Monta una hoja de ruta profesional a uno o tres años con lo que sabes hacer, lo que piden ofertas reales y un guion para hablar con tu responsable. | pídele a Claude «usa el subagente hoja-de-ruta-profesional-tres-anos» |
| mapa-cambio-de-profesion | Subagente | Ordena un cambio de profesión: qué habilidades te llevas, qué te falta, cómo contar el cambio y a quién pedir una conversación. | pídele a Claude «usa el subagente mapa-cambio-de-profesion» |
