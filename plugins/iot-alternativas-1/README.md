# arsenal-iot-alternativas-1 · IoT y hardware · Alternativas (1)

IoT y hardware · Alternativas (1): 16 comandos /, 9 skills en español que se parecen a otras piezas de iot y hardware; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-iot-alternativas-1@arsenal
```
