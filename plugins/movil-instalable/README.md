# arsenal-movil-instalable · Móvil · Apps web instalables

Móvil · Apps web instalables: 5 comandos /, 3 skills, 3 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-movil-instalable@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| alcance-mini-app | Comando / | Convierte el «quiero una app» de un cliente en un alcance cerrado que se puede hacer con Claude Code en pocos días, con lo que entra, lo que no entra, las horas y tres precios. | `/alcance-mini-app` |
| app-instalable-pwa | Comando / | Convierte tu web en una app que se instala en el móvil con icono propio, sin pasar por App Store ni Google Play ni pagar cuotas. | `/app-instalable-pwa` |
| web-a-app | Comando / | Convierte tu web en una aplicación instalable en el móvil, con icono en la pantalla de inicio y funcionamiento sin cobertura, sin pasar por las tiendas. | `/web-a-app` |
| web-a-app-instalable | Comando / | Convierte tu web en una app que se instala en el móvil desde el navegador, con icono en la pantalla de inicio, sin pasar por App Store ni Google Play. | `/web-a-app-instalable` |
| web-en-movil | Comando / | Audita tu web tal como se ve y se usa en un móvil: dedos, velocidad, formularios y todo lo que hace que la gente se vaya. | `/web-en-movil` |
| elegir-formato-app | Skill | Te dice si lo que necesitas es una web móvil, una PWA instalable, una app nativa o un no-code, y con qué coste y plazo real. | se activa sola cuando hace falta |
| elegir-nocode-app | Skill | Qué herramienta sin código para tu app (Glide, Bubble, FlutterFlow) sin gastar meses equivocado. | se activa sola cuando hace falta |
| pwa-instalable | Skill | Convierte tu web en una app instalable en el móvil (icono, pantalla completa y funcionamiento offline) sin pasar por App Store ni Google Play. | se activa sola cuando hace falta |
| convertidor-web-a-pwa | Subagente | Convierte tu web o tienda en una aplicación instalable en el móvil, con icono en la pantalla de inicio y funcionamiento sin cobertura. | pídele a Claude «usa el subagente convertidor-web-a-pwa» |
| medidor-eventos-app | Subagente | Elige qué eventos medir en tu app: los 12 que contestan todas tus preguntas de negocio. | pídele a Claude «usa el subagente medidor-eventos-app» |
| plan-de-medicion-de-tu-app | Subagente | Subagente que decide qué eventos hay que medir dentro de la app, cómo se llaman, qué datos llevan y qué panel mirar cada semana para saber si va bien. | pídele a Claude «usa el subagente plan-de-medicion-de-tu-app» |
