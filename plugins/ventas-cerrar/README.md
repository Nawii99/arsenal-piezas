# arsenal-ventas-cerrar · Ventas · Cerrar ventas

Ventas · Cerrar ventas: 13 subagentes, 4 comandos /, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ventas-cerrar@arsenal
```
