# arsenal-movil-alternativas-1 · Móvil · Alternativas (1)

Móvil · Alternativas (1): 25 comandos /, 5 skills en español que se parecen a otras piezas de móvil; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-movil-alternativas-1@arsenal
```
