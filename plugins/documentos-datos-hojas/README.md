# arsenal-documentos-datos-hojas · Documentos · Datos, facturas y hojas de cálculo

Documentos · Datos, facturas y hojas de cálculo: 6 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-documentos-datos-hojas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| auditor-excel-heredado | Subagente | Revisa un Excel que llevas años arrastrando o que te han pasado: errores antes de que cuesten dinero. | pídele a Claude «usa el subagente auditor-excel-heredado» |
| limpiar-base-clientes | Subagente | Coge tu lista de clientes hecha un desastre: limpia, sin duplicados, lista para importar. | pídele a Claude «usa el subagente limpiar-base-clientes» |
| subagente-adaptar-datos-a-la-plantilla-que-te-exigen | Subagente | Convierte tu fichero de datos al formato exacto que exigen: columnas, orden, formatos, valores permitidos. | pídele a Claude «usa el subagente subagente-adaptar-datos-a-la-plantilla-que-te-exigen» |
| subagente-conciliador-de-banco-y-facturas | Subagente | Subagente que cruza el extracto del banco con tus facturas emitidas y te dice qué está cobrado, qué falta por cobrar y qué ingreso no tiene factura. | pídele a Claude «usa el subagente subagente-conciliador-de-banco-y-facturas» |
| subagente-extractor-de-facturas-a-csv | Subagente | Subagente que abre una carpeta de facturas y tickets recibidos (PDF e imágenes) y saca un CSV limpio con base, IVA, retención y total para tu gestor. | pídele a Claude «usa el subagente subagente-extractor-de-facturas-a-csv» |
| validar-csv-antes-de-importar | Subagente | Revisa tu CSV o Excel antes de subirlo: codificación, separador, columnas, valores permitidos. | pídele a Claude «usa el subagente validar-csv-antes-de-importar» |
