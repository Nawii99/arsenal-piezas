# arsenal-negocio-estrategia-2 · Negocio · Plan y estrategia (2)

Negocio · Plan y estrategia (2): 17 subagentes, 4 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-estrategia-2@arsenal
```
