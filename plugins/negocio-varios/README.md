# arsenal-negocio-varios · Negocio · Más de negocio

Negocio · Más de negocio: 3 skills, 1 comando / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| carta-menu | Comando / | Revisa la carta de tu restaurante, bar o tienda: qué destacar, reescribe nombres y descripciones, propone orden y diseño, textos para Google y redes, y reglas para mostrar precios. | `/carta-menu` o `/arsenal-negocio-varios:carta-menu` |
| parte-diario-alquiler-booqable | Skill | Te prepara cada mañana el parte de un negocio de alquiler con Booqable: qué sale, qué vuelve, qué va con retraso y qué reservas chocan, con los mensajes a clientes en borrador. | se activa sola cuando hace falta |
| procedimientos-y-formacion-hotel | Skill | Convierte cómo se hace de verdad una tarea del hotel en un procedimiento escrito, claro y revisable, con ficha, checklist y test para formar a personal nuevo. | se activa sola cuando hace falta |
| reservas-alojamiento-sin-solapes | Skill | Revisa las reservas de tu alojamiento (cabañas, apartamentos, casas rurales), detecta solapes y datos que faltan, y deja preparados los mensajes a huéspedes y las tareas de cada llegada. | se activa sola cuando hace falta |
