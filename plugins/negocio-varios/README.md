# arsenal-negocio-varios · Negocio · Más de negocio

Negocio · Más de negocio: 5 subagentes, 2 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| resumen-salud-para-consulta | Skill | Ordena las analíticas, los síntomas y la medicación que tú le das en un resumen claro, con preguntas para tu médico y sin diagnosticar. | se activa sola cuando hace falta |
| stock-coherente-zoho-inventory | Skill | Compara el stock de Zoho Inventory con tus canales de venta, localiza descuadres por código de producto y prepara los ajustes para que los apruebes. | se activa sola cuando hace falta |
| disenador-comprobacion-licencias | Subagente | Diseña, en lenguaje claro, cómo comprobar por API las licencias de tu software cuando lo vendes a través de terceros, y deja una ficha lista para quien lo programe. | pídele a Claude «usa el subagente disenador-comprobacion-licencias» |
| entrevistas-de-alcance-y-requisitos | Subagente | Prepara las entrevistas con las personas implicadas en un proyecto y convierte las notas en requisitos numerados, con prioridad, forma de comprobarlos y dudas pendientes. | pídele a Claude «usa el subagente entrevistas-de-alcance-y-requisitos» |
| guia-participacion-local | Subagente | Convierte las ganas de participar en la vida local en un plan de 90 días con vías reales, textos borrador y límites claros. | pídele a Claude «usa el subagente guia-participacion-local» |
| resumen-para-decidir | Subagente | Condensa informes, cifras y notas en un resumen de una página para inversores, bancos, socios o dirección que dice qué se pide, por qué y qué riesgos hay. | pídele a Claude «usa el subagente resumen-para-decidir» |
| voz-propia-sin-complacer | Subagente | Revisa tus textos de trabajo y quita el tono de complacer a todos, sin inventarte otra personalidad. | pídele a Claude «usa el subagente voz-propia-sin-complacer» |
