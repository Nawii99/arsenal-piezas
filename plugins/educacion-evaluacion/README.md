# arsenal-educacion-evaluacion · Formación · Evaluación y corrección

Formación · Evaluación y corrección: 10 comandos /, 9 skills, 9 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-educacion-evaluacion@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| banco-preguntas | Comando / | Genera un banco de preguntas de examen o quiz con distractores creíbles, clave de respuestas y explicación de cada error. | `/banco-preguntas` |
| caso-practico | Comando / | Diseña un caso práctico realista con datos, contexto y solución comentada para que tus alumnos practiquen de verdad. | `/caso-practico` |
| comando-rubrica | Comando / | Crea una rúbrica de evaluación de 4 niveles a partir de la tarea que vas a corregir. Tabla lista para pegar en Word, Google Docs o el cuaderno del profesor. | `/comando-rubrica` |
| corregir-entrega | Comando / | Corrige el trabajo de un alumno con una rúbrica, le dice qué está bien, qué falla y exactamente qué rehacer, sin desanimarle. | `/corregir-entrega` |
| corregir-entregas | Comando / | Monta la rúbrica de un ejercicio y corrige las entregas de tus alumnos con feedback útil, en el mismo tono y sin quedarte horas. | `/corregir-entregas` |
| ejercicio-practico | Comando / | Diseña un ejercicio práctico con enunciado, datos de partida, solución modelo y criterio para que el alumno sepa solo si lo ha hecho bien. | `/ejercicio-practico` |
| examen-diagnostico | Comando / | Crea un test de nivel para saber qué sabe cada alumno antes de empezar y colocarlo en el itinerario que le toca. | `/examen-diagnostico` |
| prueba-de-nivel | Comando / | Crea una prueba de nivel corta que coloca a cada alumno en el punto correcto del curso y te dice a quién no le vendas todavía. | `/prueba-de-nivel` |
| prueba-nivel | Comando / | Crea una prueba de nivel corta que coloca a cada persona en el punto de partida correcto y te dice qué necesita antes de venderle nada. | `/prueba-nivel` |
| rubrica-y-feedback | Comando / | Crea la rúbrica para corregir entregas de alumnos siempre igual, y los textos de feedback para cada nivel de resultado. | `/rubrica-y-feedback` |
| banco-de-preguntas-y-examen | Skill | Crea un examen o test de un curso con preguntas bien construidas, distractores creíbles, clave de corrección y criterios de aprobado. | se activa sola cuando hace falta |
| banco-preguntas-test | Skill | Crea preguntas tipo test bien construidas (con distractores creíbles y justificación) para evaluar de verdad, no para regalar el aprobado. | se activa sola cuando hace falta |
| buscar-skill-para-tarea-de-clase | Skill | Encuentra skill ya hecha para clase: verifica que sea fiable, con licencia, antes usarla. | se activa sola cuando hace falta |
| corregir-lote-ejercicios | Skill | Corrige de golpe todos los exámenes o ejercicios de una carpeta contra una rúbrica, y devuelve nota, feedback y un resumen del grupo. | se activa sola cuando hace falta |
| revisor-examenes | Skill | Revisa un examen ya escrito y señala los fallos más comunes antes de publicarlo: preguntas ambiguas, opciones absurdas, falta de variedad de dificultad y clave de corrección incompleta. | se activa sola cuando hace falta |
| rubrica-correccion | Skill | Crea la rúbrica con la que corriges los trabajos de tus alumnos y redacta el feedback de cada entrega en minutos, siempre con el mismo criterio. | se activa sola cuando hace falta |
| rubrica-de-evaluacion | Skill | Construye la rúbrica para corregir trabajos, proyectos o entregas de alumnos con criterios claros, niveles y notas justificables. | se activa sola cuando hace falta |
| rubrica-evaluacion-lomloe | Skill | Convierte una tarea o proyecto en una rúbrica con criterios, cuatro niveles de logro y descriptores observables, redactada con el lenguaje que piden las programaciones en España. | se activa sola cuando hace falta |
| rubrica-y-feedback | Skill | Crea la rúbrica de corrección de una entrega y te redacta el feedback a cada alumno: rápido, concreto y sin desanimar. | se activa sola cuando hace falta |
| banco-de-preguntas-con-trampa | Subagente | Subagente que construye un banco de preguntas de examen con distractores creíbles basados en los errores reales que comete la gente. | pídele a Claude «usa el subagente banco-de-preguntas-con-trampa» |
| banco-de-preguntas-evaluacion | Subagente | Subagente que construye un banco de preguntas de examen calibrado por dificultad, con distractores creíbles y con la justificación de cada respuesta. | pídele a Claude «usa el subagente banco-de-preguntas-evaluacion» |
| banco-preguntas-rubrica | Subagente | Genera un banco de preguntas de examen con varias versiones, clave de corrección y rúbrica de las preguntas abiertas. | pídele a Claude «usa el subagente banco-preguntas-rubrica» |
| corrector-con-rubrica | Subagente | Subagente que corrige los ejercicios entregados por tus alumnos con una rúbrica clara y devuelve una nota y un feedback personalizado a cada uno. | pídele a Claude «usa el subagente corrector-con-rubrica» |
| disenador-rubricas | Subagente | Subagente que construye rúbricas de corrección evitando los errores típicos: criterios subjetivos, niveles que no se distinguen entre sí y pesos que no suman 100. | pídele a Claude «usa el subagente disenador-rubricas» |
| examen-final-defendible | Subagente | Diseña la evaluación final que aguanta si alguien la cuestiona: ni más fraude ni menos, papel útil. Una persona revisa. | pídele a Claude «usa el subagente examen-final-defendible» |
| examen-final-y-certificado | Subagente | Diseña la prueba final y el certificado: que acredite de verdad qué sabe hacer el alumno. | pídele a Claude «usa el subagente examen-final-y-certificado» |
| fabrica-de-ejercicios | Subagente | Convierte tu teoría en ejercicios prácticos: enunciado, datos, solución paso a paso, criterio de corrección. | pídele a Claude «usa el subagente fabrica-de-ejercicios» |
| generador-examenes-variantes | Subagente | Crea un examen completo con varias versiones distintas para evitar copias, con soluciones y rúbrica de corrección incluidas. | pídele a Claude «usa el subagente generador-examenes-variantes» |
