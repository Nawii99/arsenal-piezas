# arsenal-iot-proyectos · IoT y hardware · Proyectos caseros con ESP32

IoT y hardware · Proyectos caseros con ESP32: 4 skills, 2 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-iot-proyectos@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| estacion-meteorologica-esp32 | Skill | Guía completa para montar una estación meteorológica casera con ESP32 y sensor BME280: compra, cables, código y ver los datos en el móvil. Sin soldar. | se activa sola cuando hace falta |
| montaje-proyecto-iot | Skill | Te planifica de principio a fin una estación meteorológica, un riego automático, una alarma o una cámara de vigilancia: qué comprar, cómo montarlo y qué te ahorra cada día. | se activa sola cuando hace falta |
| piloto-de-sensores-skill-guiada | Skill | Piloto de sensores repetible: mismos criterios de éxito cada prueba. | se activa sola cuando hace falta |
| presupuesto-proyecto-iot | Skill | Convierte un proyecto de riego, alarma, cámara o estación meteorológica en un presupuesto y propuesta que se pueda enviar a un cliente: material, horas, cuota mensual, IVA y lo que toca. | se activa sola cuando hace falta |
| diagnostico-iot | Subagente | Tu cámara, sensor o riego dejó de funcionar. Te guía paso a paso antes de que compres nada: alimentación, WiFi, configuración. | pídele a Claude «usa el subagente diagnostico-iot» |
| revisor-riego-automatico | Subagente | Revisa la lista de piezas, el esquema y el código de un riego automático casero (ESP32, sensor de humedad, relé, bomba) y dice qué es peligroso, qué va a fallar y qué está bien. | pídele a Claude «usa el subagente revisor-riego-automatico» |
