# arsenal-diseno-alternativas · Diseño · Alternativas

Diseño · Alternativas: 3 comandos /, 2 skills en español que se parecen a otras piezas de diseño; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-diseno-alternativas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| arte-final-imprenta | Comando / | Repasa tu diseño antes de mandarlo a imprimir: sangrado, márgenes, resolución, color y tipografías, con la lista de comprobación real. | `/arte-final-imprenta` o `/arsenal-diseno-alternativas:arte-final-imprenta` |
| etiqueta-producto | Comando / | Organiza la etiqueta o el packaging de tu producto: qué información obligatoria va, dónde cabe y cómo que se vea bien en el lineal. | `/etiqueta-producto` o `/arsenal-diseno-alternativas:etiqueta-producto` |
| pareja-tipografica | Comando / | Elige dos tipografías gratis que peguen entre sí y te monta la escala de tamaños completa para web y para papel. | `/pareja-tipografica` o `/arsenal-diseno-alternativas:pareja-tipografica` |
| mockup-producto-diseno | Skill | Coloca tu diseño, etiqueta o logotipo sobre un producto real (camiseta, taza, bote, caja) para enseñarlo antes de fabricar nada. | se activa sola cuando hace falta |
| mockup-producto-skill | Skill | Coloca tu diseño sobre camisetas, tazas, packaging o rótulos de forma creíble, con la escala, la perspectiva y las arrugas correctas. | se activa sola cuando hace falta |
