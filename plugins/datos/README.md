# arsenal-datos · Datos

Datos: 5 skills, 5 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-datos@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| control-de-calidad-de-datos-skill-guiada | Skill | Control de calidad de datos como una rutina: same check, every time. | se activa sola cuando hace falta |
| elegir-y-revisar-graficos | Skill | Qué gráfico contar bien tus datos o revisar uno existente y limpiar lo que confunde. | se activa sola cuando hace falta |
| hojas-de-calculo-revisables | Skill | Crea y edita hojas de cálculo Excel y CSV con fórmulas que se recalculan, formato claro y gráficos sencillos, y te dice qué ha comprobado y qué debes mirar tú. | se activa sola cuando hace falta |
| lector-transacciones-tarjetas-vinculadas | Skill | Analiza las compras de tarjetas vinculadas a un programa de fidelización con Fidel API, o su exportación en CSV. | se activa sola cuando hace falta |
| preguntas-negocio-bigquery | Skill | Convierte una pregunta de negocio en una consulta SQL para BigQuery, estima su coste antes de lanzarla y explica el resultado sin jerga. | se activa sola cuando hace falta |
| control-de-calidad-de-datos-subagente-revisor | Subagente | Detecta si tus datos están sucios sin que pierdas tiempo revisándolo todo a mano. | pídele a Claude «usa el subagente control-de-calidad-de-datos-subagente-revisor» |
| perfiles-de-cliente-con-datos-reales | Subagente | Agrupa a tus clientes en segmentos y escribe perfiles con sus necesidades, hábitos y problemas sin resolver a partir de tus propios datos, marcando lo que es hipótesis. | pídele a Claude «usa el subagente perfiles-de-cliente-con-datos-reales» |
| prevision-ventas-con-rango | Subagente | Calcula una previsión de ventas o de demanda a partir del histórico, con escenario bajo, esperado y alto, y mide antes cuánto suele equivocarse. | pídele a Claude «usa el subagente prevision-ventas-con-rango» |
| prevision-vs-realidad | Subagente | Compara previsión con realidad, mide error, propone ajustes comprobables, sin adivinar. | pídele a Claude «usa el subagente prevision-vs-realidad» |
| previsor-demanda-salud-mental | Subagente | Estima, con datos agregados y fuentes citadas, cuánta atención en salud mental hará falta en un territorio o colectivo en los próximos meses, con rangos y sin diagnosticar a nadie. | pídele a Claude «usa el subagente previsor-demanda-salud-mental» |
