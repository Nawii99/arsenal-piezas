# arsenal-marketing-mensajes · Marketing · Email y mensajes

Marketing · Email y mensajes: 18 skills, 1 comando /, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-marketing-mensajes@arsenal
```
