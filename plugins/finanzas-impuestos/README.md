# arsenal-finanzas-impuestos · Finanzas · Impuestos

Finanzas · Impuestos: 4 comandos /, 2 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-finanzas-impuestos@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| apartar-impuestos | Comando / | Calcula cuánto dinero de cada cobro tienes que apartar en otra cuenta para llegar al IVA y al IRPF sin sustos y te deja el calendario del año. | `/apartar-impuestos` o `/arsenal-finanzas-impuestos:apartar-impuestos` |
| autonomo-o-sl | Comando / | Compara seguir como autónomo o montar una sociedad con tus números reales, contando costes ocultos y responsabilidad. | `/autonomo-o-sl` o `/arsenal-finanzas-impuestos:autonomo-o-sl` |
| cierre-ano-fiscal | Comando / | Repasa en noviembre o diciembre qué puedes ajustar antes del 31 para no llevarte sustos con la declaración de la renta. | `/cierre-ano-fiscal` o `/arsenal-finanzas-impuestos:cierre-ano-fiscal` |
| gasto-deducible | Comando / | Decide si un gasto se puede deducir, qué parte, qué papel necesitas y cómo dejarlo justificado antes de que te lo discutan. | `/gasto-deducible` o `/arsenal-finanzas-impuestos:gasto-deducible` |
| auditor-facturas-deducibles | Subagente | Revisa un lote de facturas recibidas de un autónomo o pyme española y marca cuáles son deducibles en IVA e IRPF, con el motivo, como control de calidad antes de entregar el cierre. | pídele a Claude «usa el subagente auditor-facturas-deducibles» |
| cierre-trimestre-gestoria | Subagente | Prepara la carpeta del trimestre: ordena facturas, detecta las que faltan, resumen de IVA e IRPF. Una persona comprueba. | pídele a Claude «usa el subagente cierre-trimestre-gestoria» |
