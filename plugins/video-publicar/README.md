# arsenal-video-publicar · Vídeo · Revisar y publicar

Vídeo · Revisar y publicar: 4 comandos /, 3 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-video-publicar@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| exportar-para-plataforma | Comando / | Te dice los ajustes exactos de exportación de cada red y te da el comando ffmpeg para adaptar un vídeo ya hecho sin que se vea mal. | `/exportar-para-plataforma` o `/arsenal-video-publicar:exportar-para-plataforma` |
| ficha-youtube | Comando / | Escribe el paquete de publicación de un vídeo: título, descripción, capítulos con tiempos, etiquetas, comentario fijado y texto de la pantalla final. | `/ficha-youtube` o `/arsenal-video-publicar:ficha-youtube` |
| pack-publicacion-video | Comando / | A partir de un vídeo ya montado, escribe el título, la descripción, los capítulos, las etiquetas, el comentario fijado y las versiones de texto para cada red. | `/pack-publicacion-video` o `/arsenal-video-publicar:pack-publicacion-video` |
| qa-antes-de-publicar | Comando / | Revisión técnica final de un vídeo antes de subirlo: audio, volumen, formato, zonas seguras, primer fotograma y metadatos, con comandos que lo comprueban de verdad. | `/qa-antes-de-publicar` o `/arsenal-video-publicar:qa-antes-de-publicar` |
| adaptador-de-un-video-a-todas-las-plataformas | Subagente | Saca cada versión del vídeo: formato, duración, gancho y texto listos para YouTube, TikTok, LinkedIn y tu web. | pídele a Claude «usa el subagente adaptador-de-un-video-a-todas-las-plataformas» |
| control-calidad-video | Subagente | Revisa un vídeo antes de publicar: formato, resolución, audio, zonas seguras, duración sin sorpresas. | pídele a Claude «usa el subagente control-calidad-video» |
| metadatos-youtube | Subagente | Convierte la transcripción en capítulos, descripción, título, tags, todo listo para pegar en YouTube. | pídele a Claude «usa el subagente metadatos-youtube» |
