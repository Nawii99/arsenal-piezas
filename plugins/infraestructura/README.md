# arsenal-infraestructura · Infraestructura

Infraestructura: 2 skills, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-infraestructura@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| montar-coolify-para-clientes | Skill | Guía para instalar, configurar y mantener Coolify (PaaS auto-alojado) como servicio de hosting gestionado para un negocio pequeño. | se activa sola cuando hace falta |
| runbook-de-despliegue-skill-guiada | Skill | Runbook de despliegue repetible: puedes dejar a alguien nuevo hacerlo. | se activa sola cuando hace falta |
| runbook-de-despliegue-subagente-revisor | Subagente | Despliegues auditados: recuperación comprobada, documentación clara. | pídele a Claude «usa el subagente runbook-de-despliegue-subagente-revisor» |
