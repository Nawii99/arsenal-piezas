# arsenal-backend-alternativas · Backend · Alternativas

Backend · Alternativas: 4 comandos /, 4 skills en español que se parecen a otras piezas de backend; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-backend-alternativas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| aguanta-el-pico | Comando / | Comprueba si tu web o tu app aguantaría un golpe de visitas y te dice exactamente qué se rompería primero y cómo evitarlo. | `/aguanta-el-pico` o `/arsenal-backend-alternativas:aguanta-el-pico` |
| blindar-claves | Comando / | Busca claves y contraseñas sueltas en tu proyecto, te dice cuáles hay que cambiar ya y te deja el sistema de variables de entorno bien montado. | `/blindar-claves` o `/arsenal-backend-alternativas:blindar-claves` |
| migracion-sin-romper | Comando / | Te guía para cambiar la estructura de tu base de datos en producción sin perder datos ni tumbar la web mientras hay gente usándola. | `/migracion-sin-romper` o `/arsenal-backend-alternativas:migracion-sin-romper` |
| webhook-entrante | Comando / | Monta bien la recepción de avisos automáticos de Stripe, Shopify o quien sea: firma verificada, sin duplicados y sin perder ninguno. | `/webhook-entrante` o `/arsenal-backend-alternativas:webhook-entrante` |
| cobrar-con-stripe | Skill | Guía a Claude Code para montar cobros y suscripciones con Stripe usando Checkout, Portal de cliente y webhooks, con IVA y facturas que valen en España. Se activa cuando quieres cobrar algo. | se activa sola cuando hace falta |
| colas-azure-pedidos-dotnet | Skill | Te dice si necesitas colas de Azure Service Bus y, si es así, diseña y genera en C# (.NET) el reparto de pedidos entre sistemas, con reintentos y mensajes fallidos controlados. | se activa sola cuando hace falta |
| stripe-primer-cobro-desde-cero | Skill | Skill para Claude Code que te lleva de no tener nada a cobrar tu primer pago con Stripe: crear la cuenta, usar un enlace de pago sin código, probar con tarjeta falsa y configurar el IVA. | se activa sola cuando hace falta |
| tareas-criticas-azure-python | Skill | Genera en Python un trabajador que procesa tareas críticas (cobros, envíos) desde una cola de Azure Service Bus, con reintentos, buzón de fallidos y alertas. | se activa sola cuando hace falta |
