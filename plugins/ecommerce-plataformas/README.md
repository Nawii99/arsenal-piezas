# arsenal-ecommerce-plataformas · Tienda por internet · Plataformas y herramientas de tienda

Tienda por internet · Plataformas y herramientas de tienda: 6 skills, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ecommerce-plataformas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| catalogo-cloudcart-con-marcha-atras | Skill | Prepara cambios masivos de precios, stock y fichas de tu tienda CloudCart en un archivo que revisas, con copia del original para poder deshacerlos. | se activa sola cuando hace falta |
| gumroad-informe-ventas-y-licencias | Skill | Resume tus ventas de Gumroad, comprueba licencias, avisa de reembolsos y redacta respuestas a compradores sin tocar precios ni productos. | se activa sola cuando hace falta |
| puente-odoo-shopify | Skill | Planifica cómo se reparten y sincronizan productos, stock, pedidos, clientes e impuestos entre Shopify y Odoo, y detecta diferencias entre ambos antes de que te cuesten ventas. | se activa sola cuando hace falta |
| puesta-en-marcha-tienda-odoo | Skill | Te guía por fases para dejar lista una tienda online en Odoo (catálogo, impuestos, pagos, envíos, stock, SEO y textos legales) y cierra con un pedido de prueba antes de abrir. | se activa sola cuando hace falta |
| revision-tienda-lemon-squeezy | Skill | Lee ventas, suscripciones, clientes y licencias de Lemon Squeezy, señala lo que necesita atención y prepara reembolsos, cancelaciones o descuentos que solo se ejecutan si los confirmas. | se activa sola cuando hace falta |
| webflow-cambios-por-lotes-con-copia | Skill | Prepara y aplica cambios masivos en el contenido de una web de Webflow (CMS, precios, textos, imágenes) con copia previa, tabla de cambios y publicación solo con tu visto bueno. | se activa sola cuando hace falta |
| agente-pago-a-plazos | Subagente | Plan para pago en cuotas en tu tienda: proveedor, textos, pruebas antes de activar. | pídele a Claude «usa el subagente agente-pago-a-plazos» |
