# arsenal-juegos-alternativas-2 · Videojuegos y 3D · Alternativas (2)

Videojuegos y 3D · Alternativas (2): 14 skills, 6 subagentes en español que se parecen a otras piezas de videojuegos y 3d; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-juegos-alternativas-2@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| localizar-un-juego | Skill | Prepara tu juego para venderlo en otros idiomas: textos ordenados, contexto para traducir y revisión final en pantalla. | se activa sola cuando hace falta |
| optimizar-3d-para-web | Skill | Convierte un modelo 3D pesado en un .glb ligero que carga rápido en el móvil, con visor listo para pegar en tu web. | se activa sola cuando hace falta |
| optimizar-modelo-3d-para-web | Skill | Deja un modelo 3D ligero y rápido para que cargue en una web o un móvil sin que se vea mal ni tarde diez segundos. | se activa sola cuando hace falta |
| pack-assets-vender | Skill | Prepara un pack de modelos 3D para venderlo en tiendas de assets: qué incluir, cómo nombrarlo, cómo dejarlo limpio y cómo presentarlo. | se activa sola cuando hace falta |
| playtest-cinco | Skill | Monta una sesión de pruebas con 5 personas para tu juego o app: qué preparar, qué medir, qué no decir y cómo leer los resultados. | se activa sola cuando hace falta |
| playtest-con-cinco-personas | Skill | Organiza y ejecuta una sesión de pruebas de tu juego con gente real y saca conclusiones accionables. | se activa sola cuando hace falta |
| preparar-modelo-impresion-3d | Skill | Revisa y prepara un modelo 3D para que se imprima bien de verdad: grosores, agujeros, apoyos, escala y encajes. | se activa sola cuando hace falta |
| preparar-pack-assets | Skill | Prepara un pack de assets 3D o 2D para venderlo: estructura de carpetas, nombres, capturas, descripción, licencia y requisitos de cada tienda. | se activa sola cuando hace falta |
| presupuestar-encargo-3d | Skill | Calcula y redacta el presupuesto de un encargo de modelado 3D o animación, con alcance, revisiones y condiciones. | se activa sola cuando hace falta |
| presupuesto-3d-encargo | Skill | Calcula y redacta el presupuesto de un encargo de 3D (modelado, render de producto, visualización) con alcance, revisiones y condiciones cerradas. | se activa sola cuando hace falta |
| publicar-build-web-itch | Skill | Empaqueta tu juego para navegador y lo publica en itch.io: ajustes de exportación, tamaño de ventana, compresión y los fallos que dejan la pantalla en negro. | se activa sola cuando hace falta |
| revisar-licencias-assets | Skill | Revisa si los assets (arte, música, sonido, fuentes, código) que usas en tu juego tienen licencia para venderlo, y qué exige cada tipo. Para quien empieza y no distingue licencias. | se activa sola cuando hace falta |
| revisor-licencias-assets | Skill | Revisa las licencias de los assets (arte, musica, sonido, codigo, fuentes) que usa tu juego y te dice si puedes venderlo sin riesgo legal. | se activa sola cuando hace falta |
| stl-impresion-3d | Skill | Prepara un modelo 3D para que se imprima bien y se pueda vender como archivo: grosores, escala, cortes, soportes y comprobaciones. | se activa sola cuando hace falta |
| agente-precio-lanzamiento | Subagente | Subagente que investiga precios de juegos comparables y propone un precio de lanzamiento y un calendario de descuentos. | pídele a Claude «usa el subagente agente-precio-lanzamiento» |
| analista-del-primer-minuto | Subagente | Analiza los primeros 60 segundos de tu juego y te dice exactamente dónde se marcha el jugador. | pídele a Claude «usa el subagente analista-del-primer-minuto» |
| auditor-licencias-assets | Subagente | Revisa de dónde sale cada asset y si los puedes usar comercialmente; te deja el fichero de créditos. | pídele a Claude «usa el subagente auditor-licencias-assets» |
| auditor-licencias-de-assets | Subagente | Revisa qué has metido en tu juego para saber qué puedes publicar sin que te traiga problemas. Consulta legales si tomas decisiones finales. | pídele a Claude «usa el subagente auditor-licencias-de-assets» |
| auditor-rendimiento-escena | Subagente | Analiza por qué tu juego va a tirones y marca qué tocar primero en escenas, modelos y texturas. | pídele a Claude «usa el subagente auditor-rendimiento-escena» |
| balanceador-de-economia-de-juego | Subagente | Subagente que ajusta los números de tu juego (costes, recompensas, mejoras, daño) para que no sea ni un muro ni un paseo, y te deja una hoja con las fórmulas. | pídele a Claude «usa el subagente balanceador-de-economia-de-juego» |
