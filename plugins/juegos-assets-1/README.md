# arsenal-juegos-assets-1 · Videojuegos y 3D · Modelos, texturas y assets (1)

Videojuegos y 3D · Modelos, texturas y assets (1): 13 comandos /, 11 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-juegos-assets-1@arsenal
```
