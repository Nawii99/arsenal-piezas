# arsenal-ventas-embudo · Ventas · Embudo y seguimiento

Ventas · Embudo y seguimiento: 9 skills, 4 comandos /, 3 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ventas-embudo@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| crm-en-hoja | Comando / | Te monta un control de oportunidades en una hoja de cálculo: estados, siguiente acción y revisión semanal, sin pagar ningún software. | `/crm-en-hoja` |
| desatascar-trato | Comando / | Analiza una venta que lleva semanas parada y te da el movimiento concreto para desbloquearla o cerrarla en falso. | `/desatascar-trato` |
| diagnostico-embudo | Comando / | Averigua en qué punto exacto se te caen las ventas contando pasos, y te dice qué arreglar primero con las cifras que ya tienes. | `/diagnostico-embudo` |
| revisar-pipeline | Comando / | Repasa contigo todas tus oportunidades abiertas y te devuelve el plan de la semana: a quién escribes, qué le dices y qué sueltas. | `/revisar-pipeline` |
| embudo-ventas-reglas-rutina | Skill | Diseña u ordena el embudo comercial de cualquier CRM u hoja de cálculo con etapas de criterio claro, campos mínimos, reglas de aviso interno y una rutina de revisión semanal. | se activa sola cuando hace falta |
| mantenimiento-diario-espocrm | Skill | Mantiene al día tu EspoCRM: altas de leads, notas de llamada, tareas de seguimiento y oportunidades paradas, siempre con tu OK antes de escribir. | se activa sola cuando hace falta |
| odoo-oportunidades-presupuestos-prevision | Skill | Revisa el CRM y las ventas de Odoo, señala oportunidades paradas o mal rellenadas, prepara borradores de presupuesto y calcula una previsión de ingresos que luego verifica una persona. | se activa sola cuando hace falta |
| orden-en-capsule-crm | Skill | Revisa tu Capsule CRM, detecta datos sucios, registra llamadas y prepara tareas de seguimiento proponiendo siempre los cambios antes de hacerlos. | se activa sola cuando hace falta |
| revision-semanal-pipeline-salesmate | Skill | Revisa tu pipeline de Salesmate, marca las oportunidades paradas o sin siguiente paso y prepara el seguimiento de cada una. | se activa sola cuando hace falta |
| seguimiento-oportunidades-nocrm | Skill | Revisa tus leads de noCRM.io, detecta los que se han quedado sin seguimiento, propone la siguiente acción de cada uno y, con tu confirmación, actualiza el CRM. | se activa sola cuando hace falta |
| seguimiento-pipeline-kommo | Skill | Revisa tu embudo de Kommo, detecta tratos parados o sin siguiente paso y te deja preparadas las tareas y los mensajes de seguimiento para que los apruebes. | se activa sola cuando hace falta |
| tabla-de-evidencia-de-estudios | Skill | Busca estudios científicos sobre una pregunta concreta, saca sus datos clave en una tabla con la fuente de cada cifra y separa lo que se puede afirmar de lo que no. | se activa sola cuando hace falta |
| whatsapp-mucho-volumen-bandeja-y-calidad | Skill | Organiza la atención por WhatsApp cuando entran muchos mensajes: reparto entre personas, respuestas automáticas con salida a persona, reglas de escalado y vigilancia del número. | se activa sola cuando hace falta |
| higiene-pipeline | Subagente | Subagente que audita tu lista de oportunidades, elimina las zombis, las prioriza y te dice qué vas a cerrar de verdad este mes. | pídele a Claude «usa el subagente higiene-pipeline» |
| informe-de-venta-unificado | Subagente | Junta varios análisis sueltos (técnico, de mercado, de cliente) en un único informe de venta, centrado en lo que gana quien lo lee y con un solo siguiente paso. | pídele a Claude «usa el subagente informe-de-venta-unificado» |
| revisor-precios-prueba-controlada | Subagente | Calcula cuánto ganas de verdad por venta en cada canal y tipo de cliente, y te propone una prueba pequeña de precios antes de cambiar nada. | pídele a Claude «usa el subagente revisor-precios-prueba-controlada» |
