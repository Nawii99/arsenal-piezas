# arsenal-iot-sensores · IoT y hardware · Sensores y cámaras

IoT y hardware · Sensores y cámaras: 5 skills, 2 comandos /, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-iot-sensores@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| contar-clientes | Comando / | Monta un contador de personas o de paso en un negocio con sensores baratos y saca informes de horas punta para decidir horarios y personal. | `/contar-clientes` o `/arsenal-iot-sensores:contar-clientes` |
| elegir-sensor | Comando / | Qué sensor comprar para tu caso concreto: marcas, trampas, rango de medida y qué va junto. | `/elegir-sensor` o `/arsenal-iot-sensores:elegir-sensor` |
| cadena-de-frio-hosteleria | Skill | Monta el control de temperatura de cámaras y neveras de un negocio de comida, con avisos y registro para inspecciones. | se activa sola cuando hace falta |
| depurar-lecturas-sensor | Skill | Encuentra por qué un sensor da valores absurdos, saltos o ceros, revisando alimentación, masas, cableado y ruido eléctrico. | se activa sola cuando hace falta |
| leer-maquina-antigua-skill | Skill | Saca datos de una máquina o instalación vieja que no es inteligente (contador, horno, compresor, bomba) sin modificarla ni perder la garantía. | se activa sola cuando hace falta |
| sensor-temperatura-fiable | Skill | Coloca y calibra sensores de temperatura y humedad para que midan la realidad y no el calor del propio aparato. | se activa sola cuando hace falta |
| sensores-y-camaras-cumpliendo-rgpd | Skill | Qué cámaras y sensores puedes instalar en tu local legalmente (revísalo con un abogado). | se activa sola cuando hace falta |
| control-calidad-datos-sensores | Subagente | Revisa el histórico de sensores y detecta lecturas pegadas, deriva y valores imposibles antes de confiar. | pídele a Claude «usa el subagente control-calidad-datos-sensores» |
