# arsenal-juegos-encargos · Videojuegos y 3D · Encargos para clientes

Videojuegos y 3D · Encargos para clientes: 3 subagentes, 3 comandos /, 2 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-juegos-encargos@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| entrega-cliente-3d | Comando / | Revisa contigo un modelo 3D antes de mandárselo al cliente y te da la checklist técnica que evita el correo de «esto no me sirve». | `/entrega-cliente-3d` |
| presupuesto-3d | Comando / | Convierte un encargo de modelado o render 3D en un presupuesto cerrado: partidas, entregables, revisiones incluidas y condiciones de pago. | `/presupuesto-3d` |
| presupuesto-encargo-3d | Comando / | Convierte un encargo de 3D o de videojuego en un presupuesto por partidas, con revisiones incluidas y condiciones claras. | `/presupuesto-encargo-3d` |
| presupuestar-encargo-3d | Skill | Calcula y redacta el presupuesto de un encargo de modelado 3D o animación, con alcance, revisiones y condiciones. | se activa sola cuando hace falta |
| presupuesto-3d-encargo | Skill | Calcula y redacta el presupuesto de un encargo de 3D (modelado, render de producto, visualización) con alcance, revisiones y condiciones cerradas. | se activa sola cuando hace falta |
| presupuesto-de-encargo-3d | Subagente | Cierra un encargo 3D: desglosa alcance, revisiones y precio para no perder dinero en cambios. | pídele a Claude «usa el subagente presupuesto-de-encargo-3d» |
| presupuesto-encargo-3d | Subagente | Subagente que convierte el encargo de un cliente en un presupuesto profesional de modelado o animación 3D, con partidas, revisiones y condiciones. | pídele a Claude «usa el subagente presupuesto-encargo-3d» |
| visor-3d-para-clientes | Subagente | Monta una web para girar tu modelo 3D en el navegador sin instalaciones ni cuota mensual. | pídele a Claude «usa el subagente visor-3d-para-clientes» |
