# arsenal-web-varios · Web · Más de web

Web · Más de web: 8 comandos /, 7 subagentes, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-web-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| adelgazar-web | Comando / | Deja tu web ligera y rápida: pesa las imágenes, quita lo que sobra y te da los arreglos concretos, no consejos genéricos. | `/adelgazar-web` |
| arreglar-error-web | Comando / | Te ayuda a cazar y arreglar un fallo de tu web guiándote para leer el error del navegador aunque no sepas programar. | `/arreglar-error-web` |
| clonar-para-cliente | Comando / | Coge una web tuya que ya funciona y la adapta a un cliente nuevo: marca, colores, textos y datos, sin romper nada por el camino. | `/clonar-para-cliente` |
| entrega-web-cliente | Comando / | Prepara el paquete de entrega de una web a un cliente: accesos, manual de uso, qué incluye, qué no, y la oferta de mantenimiento. | `/entrega-web-cliente` |
| no-se-ven-los-cambios | Comando / | Resuelve el clásico: has cambiado la web, la has subido y sigues viendo la versión antigua. Encuentra dónde se ha quedado atascado. | `/no-se-ven-los-cambios` |
| revisar-movil | Comando / | Revisa tu web en pantalla de móvil y te dice exactamente qué se rompe y qué línea de CSS lo arregla. | `/revisar-movil` |
| revision-prelanzamiento | Comando / | Repasa tu web entera antes de publicarla y te da la lista de fallos ordenada por gravedad, con el arreglo hecho. | `/revision-prelanzamiento` |
| web-en-dos-idiomas | Comando / | Convierte tu web en bilingüe bien hecha: traducción, selector de idioma y las etiquetas para que Google entienda cada versión. | `/web-en-dos-idiomas` |
| producto-minimo-con-cobro | Skill | Guía a Claude Code para construir, probar, publicar y vigilar un producto digital mínimo con página de venta y cobro real, parando a pedirte permiso antes de publicar, cobrar o gastar. | se activa sola cuando hace falta |
| convertir-web-en-app-instalable | Subagente | Tu web se instala como app en el móvil sin tiendas de aplicaciones ni que tengas que programar. | pídele a Claude «usa el subagente convertir-web-en-app-instalable» |
| detector-errores-javascript | Subagente | Subagente que busca los errores de JavaScript que rompen tu web sin avisar: botones que no hacen nada, contadores parados, carritos que fallan. | pídele a Claude «usa el subagente detector-errores-javascript» |
| empaquetar-web-para-entregar | Subagente | Cierra la entrega web: limpieza, copias de seguridad, accesos, manual y el checklist final. | pídele a Claude «usa el subagente empaquetar-web-para-entregar» |
| rescate-web-caida | Subagente | Subagente que diagnostica en orden por qué tu web no se ve: dominio, DNS, certificado, hosting o el propio código. Y te dice a quién llamar. | pídele a Claude «usa el subagente rescate-web-caida» |
| revisor-movil-de-verdad | Subagente | Descubre qué se rompe en el móvil de verdad: botones imposibles, textos minúsculos y menús atascados. | pídele a Claude «usa el subagente revisor-movil-de-verdad» |
| seo-tecnico-y-tarjetas-sociales | Subagente | Subagente que deja tu web bien presentada ante Google y ante WhatsApp: títulos, descripciones, datos estructurados y la imagen que sale al compartir. | pídele a Claude «usa el subagente seo-tecnico-y-tarjetas-sociales» |
| web-en-dos-idiomas | Subagente | Tu web en dos idiomas bien estructurada: URLs, selector de idioma, hreflang y sin traducciones a trozos. | pídele a Claude «usa el subagente web-en-dos-idiomas» |
