# arsenal-web-alternativas · Web · Alternativas

Web · Alternativas: 17 comandos /, 3 skills, 1 subagente en español que se parecen a otras piezas de web; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-web-alternativas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| accesibilidad-web | Comando / | Revisa tu web para que la pueda usar cualquiera: contraste, textos alternativos, navegación con teclado y formularios entendibles. | `/accesibilidad-web` o `/arsenal-web-alternativas:accesibilidad-web` |
| adelgazar-web | Comando / | Deja tu web ligera y rápida: pesa las imágenes, quita lo que sobra y te da los arreglos concretos, no consejos genéricos. | `/adelgazar-web` o `/arsenal-web-alternativas:adelgazar-web` |
