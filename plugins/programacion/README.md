# arsenal-programacion · Programación

Programación: 3 skills, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-programacion@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| del-acierto-a-la-receta | Skill | Convierte en una skill guardada un flujo que ha funcionado en la conversación (un email, un anuncio, una propuesta) para repetirlo después con un solo comando. | se activa sola cuando hace falta |
| producto-minimo-con-cobro | Skill | Guía a Claude Code para construir, probar, publicar y vigilar un producto digital mínimo con página de venta y cobro real, parando a pedirte permiso antes de publicar, cobrar o gastar. | se activa sola cuando hace falta |
| refactor-seguro-skill-guiada | Skill | Refactor seguro repetible: mismos principios, menos sustos cada vez. | se activa sola cuando hace falta |
| refactor-seguro-subagente-revisor | Subagente | Código mejorado y verificado: sin sorpresas en producción. | pídele a Claude «usa el subagente refactor-seguro-subagente-revisor» |
