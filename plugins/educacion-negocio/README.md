# arsenal-educacion-negocio · Formación · Vender formación

Formación · Vender formación: 4 skills, 3 comandos /, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-educacion-negocio@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| formacion-empresa | Comando / | Prepara la propuesta de una formación para una empresa: ficha del curso, objetivos, horas, evaluación y presupuesto, en el lenguaje que pide recursos humanos. | `/formacion-empresa` o `/arsenal-educacion-negocio:formacion-empresa` |
| presupuesto-materiales | Comando / | Convierte la petición de un profesor, academia o centro en un presupuesto claro: alcance, entregables, plazo, precio y condiciones. Pensado para autónomos en España. | `/presupuesto-materiales` o `/arsenal-educacion-negocio:presupuesto-materiales` |
| testimonios-alumnos | Comando / | Te guía para entrevistar a un alumno y convertir su experiencia en un caso de éxito y testimonios que puedas usar para vender. | `/testimonios-alumnos` o `/arsenal-educacion-negocio:testimonios-alumnos` |
| formacion-bonificada-fundae | Skill | Te explica si tu formación puede bonificarse por FUNDAE, qué requisitos y papeles hacen falta y cómo plantearlo al cliente sin prometer de más. | se activa sola cuando hace falta |
| metricas-curso | Skill | Los seis números que te dicen si tu curso va bien o mal (sin analítica avanzada). | se activa sola cuando hace falta |
| montar-frappe-lms-para-clientes | Skill | Guía para instalar, configurar y mantener Frappe LMS (plataforma de cursos online) como servicio para una academia o negocio que quiere vender formación. | se activa sola cuando hace falta |
| pack-materiales-clase-cliente | Skill | Convierte el encargo de un profesor o academia en un pack completo (presentación, ficha, rúbrica y juego) con formato de entrega profesional. Sirve para cobrar por el material. | se activa sola cuando hace falta |
| expediente-formacion-empresa | Subagente | Prepara toda la documentación de una formación para empresa: ficha técnica, programa, control de asistencia, evaluación y certificados. | pídele a Claude «usa el subagente expediente-formacion-empresa» |
