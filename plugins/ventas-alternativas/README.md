# arsenal-ventas-alternativas · Ventas · Alternativas

Ventas · Alternativas: 8 subagentes, 6 comandos /, 2 skills en español que se parecen a otras piezas de ventas; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ventas-alternativas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| guion-llamada-descubrimiento | Comando / | Te prepara la primera llamada con un cliente: qué preguntar, en qué orden, qué anotar y cómo cerrarla con un siguiente paso. | `/guion-llamada-descubrimiento` o `/arsenal-ventas-alternativas:guion-llamada-descubrimiento` |
| reactivar-clientes-dormidos | Comando / | Saca ventas de tu lista de clientes antiguos: los agrupa por tipo, escribe el mensaje de cada grupo y te da el orden para llamarlos. | `/reactivar-clientes-dormidos` o `/arsenal-ventas-alternativas:reactivar-clientes-dormidos` |
| rebatir-objeciones | Comando / | Convierte las pegas que te pone un cliente en respuestas preparadas, con la pregunta previa que debes hacer antes de contestar. | `/rebatir-objeciones` o `/arsenal-ventas-alternativas:rebatir-objeciones` |
| recuperar-clientes-dormidos | Comando / | Crea la campaña para volver a activar clientes que te compraron y llevan meses sin aparecer. | `/recuperar-clientes-dormidos` o `/arsenal-ventas-alternativas:recuperar-clientes-dormidos` |
| seguimiento-presupuesto | Comando / | Escribe la secuencia de mensajes para reactivar un presupuesto enviado del que el cliente no contesta, sin parecer pesado. | `/seguimiento-presupuesto` o `/arsenal-ventas-alternativas:seguimiento-presupuesto` |
| upsell-siguiente-compra | Comando / | Diseña qué venderle después a un cliente que ya te compró, cuándo proponérselo y con qué mensaje. | `/upsell-siguiente-compra` o `/arsenal-ventas-alternativas:upsell-siguiente-compra` |
| primer-contacto-email-empresas | Skill | Prepara una secuencia corta de primer contacto por email a empresas, con la lista justificada y una prueba de envío, y la deja pausada en Emelia para que la lances tú. | se activa sola cuando hace falta |
| prospectos-datos-publicos-apify | Skill | Monta con Apify una lista de empresas que encajan con tu cliente ideal, con la fuente de cada dato anotada y un filtro de protección de datos antes de contactar a nadie. | se activa sola cuando hace falta |
| auditor-de-embudo | Subagente | Coge tus números de ventas: calcula dónde se te cae la gente, qué arreglar primero. | pídele a Claude «usa el subagente auditor-de-embudo» |
| autopsia-de-llamada | Subagente | Analiza la transcripción de una llamada comercial: dónde la perdiste exactamente, qué decir la próxima. | pídele a Claude «usa el subagente autopsia-de-llamada» |
| cierra-presupuestos-parados | Subagente | Coge presupuestos enviados sin respuesta: seguimiento exacto, qué mandar, cuándo, excusa creíble. | pídele a Claude «usa el subagente cierra-presupuestos-parados» |
| fabricar-casos-de-exito | Subagente | Subagente que entrevista a tu cliente contento y convierte lo que cuenta en un caso de éxito que vende, más el testimonio corto para redes. | pídele a Claude «usa el subagente fabricar-casos-de-exito» |
| mapa-recorrido-de-compra | Subagente | Dibuja el recorrido del cliente desde que te conoce hasta que compra, señala dónde se pierde la gente y propone pruebas pequeñas ordenadas por prioridad. | pídele a Claude «usa el subagente mapa-recorrido-de-compra» |
| motor-de-referidos | Subagente | Monta tu sistema para pedir recomendaciones a clientes contentos: a quién, cuándo, palabras exactas, seguimiento. | pídele a Claude «usa el subagente motor-de-referidos» |
| rescate-presupuestos-frios | Subagente | Coge presupuestos enviados sin respuesta: ordena por posibilidades reales, secuencia de seguimiento de cada uno. | pídele a Claude «usa el subagente rescate-presupuestos-frios» |
| venta-despues-de-la-venta | Subagente | Diseña qué ofrecer justo después de cada compra: upsell, cross-sell, mensajes exactos. | pídele a Claude «usa el subagente venta-despues-de-la-venta» |
