# arsenal-juegos-vender · Videojuegos y 3D · Publicar y vender juegos

Videojuegos y 3D · Publicar y vender juegos: 14 comandos /, 8 subagentes, 3 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-juegos-vender@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| configurador-3d-web | Comando / | Planifica y presupuesta un visualizador 3D para la web de un cliente: que su producto se gire y cambie de color o de acabado desde el navegador. | `/configurador-3d-web` |
| devlog-semanal | Comando / | Convierte el trabajo de tu semana en un devlog publicable, con el gancho, el GIF adecuado y las versiones para cada sitio donde publicarlo. | `/devlog-semanal` |
| diseno-una-pagina | Comando / | Aprieta la idea de tu juego en una sola página: qué se hace, por qué engancha, qué entra y sobre todo qué se queda fuera. | `/diseno-una-pagina` |
| ficha-marketplace-3d | Comando / | Prepara el modelo, las imágenes y el texto para poner uno de tus modelos 3D a la venta en un marketplace y que lo aprueben. | `/ficha-marketplace-3d` |
| ficha-steam | Comando / | Escribe la página de tienda de tu juego en Steam: descripción corta, textos largos, etiquetas, orden de capturas y qué pedirle al diseñador de cápsulas. | `/ficha-steam` |
| ficha-tienda | Comando / | Genera el texto de la pagina de tienda (Steam, itch.io o Google Play) de tu juego a partir de una descripcion breve. | `/ficha-tienda` |
| pack-assets-tienda | Comando / | Prepara un pack de modelos 3D para venderlo en una tienda de assets: qué incluir, cómo nombrarlo, qué imágenes hacer y cómo describirlo. | `/pack-assets-tienda` |
| pack-assets-venta | Comando / | Prepara un pack de modelos 3D para vender en tiendas de assets: qué meter, cómo nombrar los archivos, qué formatos y cómo escribir la ficha. | `/pack-assets-venta` |
| pagina-tienda | Comando / | Redacta el texto de la página de tienda de un juego (Steam, itch.io o similar): descripción corta, descripción larga, etiquetas y bullets de gancho. | `/pagina-tienda` |
| pagina-tienda-juego | Comando / | A partir de una descripción del juego en dos o tres frases, genera el borrador completo de la ficha de tienda: frase corta, descripción larga, etiquetas, lista de capturas y GIF necesarios. | `/pagina-tienda-juego` |
| pagina-tienda-juego-2 | Comando / | Redacta la ficha completa del juego para Steam o itch.io: descripción corta, descripción larga, textos de cápsula, etiquetas y bloque de acceso anticipado. Es lo que te lleva horas cada vez. | `/pagina-tienda-juego-2` |
| pagina-tienda-juego-3 | Comando / | Redacta el texto completo de la ficha de tienda de un juego (descripción corta, sección Sobre el juego, viñetas, etiquetas) como entregable para un estudio. | `/pagina-tienda-juego-3` |
| pagina-tienda-juego-4 | Comando / | Genera el texto de la página de tienda de tu juego (Steam o itch.io): descripción corta, descripción larga, bullets de características y etiquetas. Para la primera ficha de tienda. | `/pagina-tienda-juego-4` |
| vender-configurador | Comando / | Prepara la propuesta comercial para venderle a un negocio un configurador 3D de sus productos, con alcance, precio por fases y email de contacto. | `/vender-configurador` |
| auditoria-licencias-assets | Skill | Revisa uno a uno los assets de un juego (arte, música, fuentes, código, IA) y entrega un informe en semáforo que puedes cobrar como servicio cerrado. | se activa sola cuando hace falta |
| ficha-steam-skill | Skill | Monta la página de Steam de tu juego: título, descripción corta, tags, capturas y textos que hacen que la gente le dé a «Seguir» o «Lista de deseados». | se activa sola cuando hace falta |
| plugins-oficiales-con-ficha | Skill | Antes de usar skills de terceros, comprueba si un plugin oficial de Claude Code ya cubre la tarea, verifica que viene del sitio oficial, lista lo que instala y deja una ficha. | se activa sola cuando hace falta |
| agente-precio-lanzamiento | Subagente | Subagente que investiga precios de juegos comparables y propone un precio de lanzamiento y un calendario de descuentos. | pídele a Claude «usa el subagente agente-precio-lanzamiento» |
| asesor-precio-juego | Subagente | Ayuda a fijar el precio de venta de tu juego indie contando la comisión de la tienda, el IVA como autónomo en España y el precio de juegos parecidos. Para quien pone precio por primera vez. | pídele a Claude «usa el subagente asesor-precio-juego» |
| documentador-requisitos-juego | Subagente | Notas de videojuego se convierten en documento requisitos y texto ficha tienda validados. | pídele a Claude «usa el subagente documentador-requisitos-juego» |
| estratega-precios-juego | Subagente | Recomienda el precio de lanzamiento de un juego, el calendario de descuentos y si conviene entrar en bundles, comparándolo con juegos similares. | pídele a Claude «usa el subagente estratega-precios-juego» |
| ficha-tienda-juego | Subagente | Subagente que escribe la página de tu juego en Steam o itch.io y te dice qué capturas y qué imágenes necesitas, con medidas exactas. | pídele a Claude «usa el subagente ficha-tienda-juego» |
| ficha-venta-asset-3d | Subagente | Prepara un modelo para venderlo: la ficha en inglés, qué renders necesitas y por qué rechazan otras. | pídele a Claude «usa el subagente ficha-venta-asset-3d» |
| kit-prensa-juego | Subagente | Prepara el kit de prensa de un juego y los correos de contacto para medios y creadores de contenido, con reglas para no regalar claves a estafadores. | pídele a Claude «usa el subagente kit-prensa-juego» |
| minero-de-opiniones-de-jugadores | Subagente | Lee reseñas y comentarios de tus jugadores: extrae qué arreglar primero separando ruido de señal. | pídele a Claude «usa el subagente minero-de-opiniones-de-jugadores» |
