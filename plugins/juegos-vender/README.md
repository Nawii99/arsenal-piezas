# arsenal-juegos-vender · Videojuegos y 3D · Publicar y vender juegos

Videojuegos y 3D · Publicar y vender juegos: 3 skills, 3 subagentes, 3 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-juegos-vender@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| devlog-semanal | Comando / | Convierte el trabajo de tu semana en un devlog publicable, con el gancho, el GIF adecuado y las versiones para cada sitio donde publicarlo. | `/devlog-semanal` o `/arsenal-juegos-vender:devlog-semanal` |
| ficha-marketplace-3d | Comando / | Prepara el modelo, las imágenes y el texto para poner uno de tus modelos 3D a la venta en un marketplace y que lo aprueben. | `/ficha-marketplace-3d` o `/arsenal-juegos-vender:ficha-marketplace-3d` |
| pagina-tienda-juego | Comando / | A partir de una descripción del juego en dos o tres frases, genera el borrador completo de la ficha de tienda: frase corta, descripción larga, etiquetas, lista de capturas y GIF necesarios. | `/pagina-tienda-juego` o `/arsenal-juegos-vender:pagina-tienda-juego` |
| pitch-publisher | Skill | Prepara el email frío y el dossier de 10-12 diapositivas para enseñar tu juego a una publisher o a un inversor. | se activa sola cuando hace falta |
| publicar-pack-assets-3d | Skill | Prepara y publica un pack de modelos 3D para venderlo en tiendas de assets, con los requisitos técnicos que piden. | se activa sola cuando hace falta |
| trailer-juego | Skill | Tu juego en 60 segundos: guion plano a plano de qué grabar y cómo montarlo. | se activa sola cuando hace falta |
| asesor-precio-juego | Subagente | Ayuda a fijar el precio de venta de tu juego indie contando la comisión de la tienda, el IVA como autónomo en España y el precio de juegos parecidos. Para quien pone precio por primera vez. | pídele a Claude «usa el subagente asesor-precio-juego» |
| kit-prensa-y-claves | Subagente | Organiza el envío de claves a streamers y redactores con el material que necesitan para mostrar tu juego. | pídele a Claude «usa el subagente kit-prensa-y-claves» |
| publicador-build-itch | Subagente | Prepara y sube tu build a itch.io comprimida, por canales, y sin líos en la ficha de presentación. | pídele a Claude «usa el subagente publicador-build-itch» |
