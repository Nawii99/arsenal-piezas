# arsenal-foto-producto · Foto e imagen · Fotos de producto

Foto e imagen · Fotos de producto: 3 comandos /, 2 skills, 2 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-producto@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| angulos-foto | Comando / | Te da 8 variantes de ángulo, plano y lente para tu producto, cada una con su prompt en inglés para IA, la medida según el uso y cuál elegir como foto principal. | `/angulos-foto` o `/arsenal-foto-producto:angulos-foto` |
| catalogo-en-lote | Comando / | Organiza la producción de fotos de muchos productos de golpe, con una sola sesión y un sistema de nombres, sin volverte loco. | `/catalogo-en-lote` o `/arsenal-foto-producto:catalogo-en-lote` |
| escena-campana | Comando / | Adapta las fotos que ya tienes a una campaña concreta (Navidad, rebajas, verano, vuelta al cole) sin rehacer el producto. | `/escena-campana` o `/arsenal-foto-producto:escena-campana` |
| lote-catalogo-imagenes | Skill | Monta el sistema para producir en serie las imágenes de 30, 50 o 200 productos sin perderte ni repetir trabajo. | se activa sola cuando hace falta |
| sesion-de-producto-skill-guiada | Skill | Cada sesión sale igual de bien: mismo orden de pasos, mismas preguntas, misma calidad en cada foto. | se activa sola cuando hace falta |
| control-color-producto | Subagente | Subagente que comprueba que el color de tus fotos coincide con el color real del producto y te dice cómo corregirlo antes de publicar. | pídele a Claude «usa el subagente control-color-producto» |
| sesion-de-producto-subagente-revisor | Subagente | Pásale tu idea de sesión y te devuelve lista de planos, esquema de luz, atrezzo y entrega de archivos. | pídele a Claude «usa el subagente sesion-de-producto-subagente-revisor» |
