# arsenal-foto-producto · Foto e imagen · Fotos de producto

Foto e imagen · Fotos de producto: 10 subagentes, 9 comandos /, 4 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-producto@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| angulos-foto | Comando / | Te da 8 variantes de ángulo, plano y lente para tu producto, cada una con su prompt en inglés para IA, la medida según el uso y cuál elegir como foto principal. | `/angulos-foto` |
| auditar-fotos-ficha | Comando / | Revisa el conjunto de fotos de un producto y te dice cuáles faltan, en qué orden colocarlas y cuál debe ser la primera. | `/auditar-fotos-ficha` |
| catalogo-en-lote | Comando / | Organiza la producción de fotos de muchos productos de golpe, con una sola sesión y un sistema de nombres, sin volverte loco. | `/catalogo-en-lote` |
| fondo-limpio-marketplace | Comando / | Te prepara las fotos de producto con fondo limpio cumpliendo las normas de Amazon, Google Shopping, Wallapop o tu tienda, sin que te rechacen la ficha. | `/fondo-limpio-marketplace` |
| foto-marketplace | Comando / | Prepara las fotos de un producto para que cumplan las normas de Amazon, Wallapop, Google Shopping o tu tienda y no te las rechacen. | `/foto-marketplace` |
| fotos-para-marketplace | Comando / | Adapta tus fotos a las normas exactas de Amazon, Wallapop, Google Shopping, Etsy o el marketplace que uses, para que no te tumben la ficha. | `/fotos-para-marketplace` |
| iluminacion-foto | Comando / | Propone 6 esquemas de iluminación para tu producto, cada uno con su efecto, un prompt en inglés para IA y cómo hacerlo con luz real y el móvil. | `/iluminacion-foto` |
| imagenes-marketplace | Comando / | Prepara las fotos de un producto para cumplir los requisitos técnicos de Amazon, Google Shopping, Shopify, Etsy o Wallapop sin que te las rechacen. | `/imagenes-marketplace` |
| rescatar-foto-movil | Comando / | Diagnostica una foto que has hecho con el móvil y te da el plan exacto para repetirla o arreglarla hasta que parezca de catálogo. | `/rescatar-foto-movil` |
| fondo-blanco-marketplace | Skill | Deja tus fotos de producto con fondo blanco puro o transparente cumpliendo las normas de Amazon, eBay, Wallapop y Shopify, sin Photoshop. | se activa sola cuando hace falta |
| foto-movil-a-catalogo | Skill | Cómo fotografiar tu producto con el móvil para que se vea listo para vender. | se activa sola cuando hace falta |
| imagen-para-marketplace | Skill | Prepara tus imágenes para cumplir los requisitos de Amazon, Google Shopping, Wallapop o Etsy y que no te rechacen la publicación. | se activa sola cuando hace falta |
| sesion-de-producto-skill-guiada | Skill | Cada sesión sale igual de bien: mismo orden de pasos, mismas preguntas, misma calidad en cada foto. | se activa sola cuando hace falta |
| adaptador-formatos-visuales | Subagente | Coge tu imagen buena y te dice cómo recortarla para cada sitio (Reels, feed, Amazon, portada, anuncio) sin que se corte lo importante. | pídele a Claude «usa el subagente adaptador-formatos-visuales» |
| auditor-fichas-imagen | Subagente | Antes de subir tus fotos de producto: cuáles tienen mal tamaño, fondo distinto o encuadre roto. | pídele a Claude «usa el subagente auditor-fichas-imagen» |
| auditor-fotos-ficha-producto | Subagente | Antes de subir el producto: qué fotos están mal, qué foto falta y cuál va a rebotar. | pídele a Claude «usa el subagente auditor-fotos-ficha-producto» |
| control-color-producto | Subagente | Subagente que comprueba que el color de tus fotos coincide con el color real del producto y te dice cómo corregirlo antes de publicar. | pídele a Claude «usa el subagente control-color-producto» |
| director-de-fotografia | Subagente | Convierte tu producto en un set completo de fotos: prompts de imagen con IA en inglés con plano, lente, luz y medidas por plataforma, y cómo hacer cada foto con el móvil. | pídele a Claude «usa el subagente director-de-fotografia» |
| limpiador-metadatos-fotos | Subagente | Quita de tus fotos los datos ocultos que delatan tu casa, tu móvil y la hora, y les pone tu autoría antes de publicarlas. | pídele a Claude «usa el subagente limpiador-metadatos-fotos» |
| optimizador-imagenes-lote | Subagente | Convierte y comprime carpetas enteras de fotos a tamaños y formatos web, sin que tengas que abrir un solo programa de edición. | pídele a Claude «usa el subagente optimizador-imagenes-lote» |
| organizador-catalogo-fotos | Subagente | Ordena y renombra tu montón de fotos por producto, quita duplicadas y te deja una hoja con qué foto corresponde a cada referencia. | pídele a Claude «usa el subagente organizador-catalogo-fotos» |
| preparador-fichas-marketplace | Subagente | Deja tus fotos cumpliendo las reglas exactas de Amazon, Google Shopping o el marketplace donde vendas, para que no te rechacen la ficha. | pídele a Claude «usa el subagente preparador-fichas-marketplace» |
| sesion-de-producto-subagente-revisor | Subagente | Pásale tu idea de sesión y te devuelve lista de planos, esquema de luz, atrezzo y entrega de archivos. | pídele a Claude «usa el subagente sesion-de-producto-subagente-revisor» |
