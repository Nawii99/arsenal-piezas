# arsenal-movil-varios · Móvil · Más de móvil

Móvil · Más de móvil: 7 comandos /, 3 skills, 2 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-movil-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| atajos-movil | Comando / | Convierte una tarea repetitiva de tu negocio en una automatización del móvil con Atajos de iPhone o Rutinas de Android, paso a paso. | `/atajos-movil` |
| explica-codigo | Comando / | Comando de Claude Code que traduce a castellano llano el código de un tutorial o proyecto de ejemplo descargado, para entender qué hace antes de tocarlo. | `/explica-codigo` |
| fallos-app | Comando / | Ordena los informes de fallos y bloqueos de tu app para saber cuál arreglar primero y qué contarle a quien la programa. | `/fallos-app` |
| formulario-movil | Comando / | Arregla el formulario o el pago de tu web para que se rellene en el móvil sin rabia: teclados correctos, autocompletado y menos campos. | `/formulario-movil` |
| iniciar-proyecto-movil | Comando / | Genera una checklist antes de crear un proyecto Android o iOS desde plantilla, para evitar los fallos que luego cuestan días arreglar. | `/iniciar-proyecto-movil` |
| lanzar-version | Comando / | Prepara la publicación de una versión nueva de tu app: notas de novedades, despliegue por fases y qué vigilar las primeras 48 horas. | `/lanzar-version` |
| mini-app | Comando / | Crea una app o un juego completo en un solo archivo HTML que se abre con Chrome en cualquier Android, sin instalar nada. De la idea a la app funcionando en una sesión. | `/mini-app` |
| componente-ui-consistente-con-tema | Skill | Crea un componente visual nuevo respetando los colores, tipografía y espaciados que ya usa la app, para no acabar con una interfaz descuadrada. Se activa al pedir un componente visual nuevo. | se activa sola cuando hace falta |
| crear-plantilla-app-movil | Skill | Crea la estructura inicial de una app móvil con Expo (React Native) para Android e iOS cuando alguien quiere arrancar un proyecto desde cero. | se activa sola cuando hace falta |
| minar-resenas-rivales | Skill | Extrae de las reseñas de las apps de tu competencia lo que la gente odia y echa de menos, y lo convierte en tu lista de funciones y tus argumentos de venta. | se activa sola cuando hace falta |
| arregla-mi-app | Subagente | Depura tus mini-apps y juegos en HTML cuando algo falla: encuentra la causa, arregla solo eso y te explica qué pasaba en una frase que se entiende. | pídele a Claude «usa el subagente arregla-mi-app» |
| enlaces-que-abren-tu-app | Subagente | Monta enlaces profundos: un QR, un enlace o un anuncio abre la pantalla exacta de tu app. | pídele a Claude «usa el subagente enlaces-que-abren-tu-app» |
