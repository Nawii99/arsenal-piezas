# arsenal-movil-varios · Móvil · Más de móvil

Móvil · Más de móvil: 6 skills, 5 subagentes, 2 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-movil-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| atajos-movil | Comando / | Convierte una tarea repetitiva de tu negocio en una automatización del móvil con Atajos de iPhone o Rutinas de Android, paso a paso. | `/atajos-movil` o `/arsenal-movil-varios:atajos-movil` |
| precio-app | Comando / | Decide cómo cobrar por tu app y a qué precio: pago único, suscripción o gratis con extras, con las comisiones reales de cada tienda. | `/precio-app` o `/arsenal-movil-varios:precio-app` |
| auditoria-ingresos-app-movil | Skill | Revisa cómo gana (o pierde) dinero una app móvil con compras, suscripciones o publicidad y entrega una lista ordenada de cambios a probar, sin tocar el código. | se activa sola cuando hace falta |
| elegir-formato-app | Skill | Te dice si lo que necesitas es una web móvil, una PWA instalable, una app nativa o un no-code, y con qué coste y plazo real. | se activa sola cuando hace falta |
| elegir-nocode-app | Skill | Qué herramienta sin código para tu app (Glide, Bubble, FlutterFlow) sin gastar meses equivocado. | se activa sola cuando hace falta |
| minar-resenas-rivales | Skill | Extrae de las reseñas de las apps de tu competencia lo que la gente odia y echa de menos, y lo convierte en tu lista de funciones y tus argumentos de venta. | se activa sola cuando hace falta |
| notificaciones-push | Skill | Diseña qué notificaciones manda tu app, cuándo y con qué texto, para que ayuden en vez de provocar que te desinstalen. | se activa sola cuando hace falta |
| paywall-suscripcion | Skill | Monta el muro de pago de tu app: qué se cobra, qué precios, qué prueba gratis y qué pantalla enseñar, contando la comisión de la tienda. | se activa sola cuando hace falta |
| auditor-notificaciones-push | Subagente | Revisa la configuración de notificaciones push (Firebase Cloud Messaging y APNs) antes de un lanzamiento, para detectar fallos que hacen que no lleguen o que Apple rechace la app. | pídele a Claude «usa el subagente auditor-notificaciones-push» |
| auditor-notificaciones-push-2 | Subagente | Subagente que audita la configuración de notificaciones push en Android e iOS y detecta los errores que hacen que el usuario las desactive o desinstale la app. | pídele a Claude «usa el subagente auditor-notificaciones-push-2» |
| convertir-web-en-app-instalable | Subagente | Tu web se instala como app en el móvil sin tiendas de aplicaciones ni que tengas que programar. | pídele a Claude «usa el subagente convertir-web-en-app-instalable» |
| gestor-resenas-y-valoraciones-app | Subagente | Convierte las valoraciones de tu app en una herramienta: cuándo pedir la valoración, cómo responder y qué reseña esconde un fallo real. | pídele a Claude «usa el subagente gestor-resenas-y-valoraciones-app» |
| mineria-de-resenas-de-la-tienda | Subagente | Lee todas las reseñas, saca motivos reales, respuestas a cada una y una lista de mejoras ordenada. | pídele a Claude «usa el subagente mineria-de-resenas-de-la-tienda» |
