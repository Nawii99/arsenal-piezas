# arsenal-ciencia · Ciencia e investigación

Ciencia e investigación: 1 skill, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ciencia@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| analisis-de-un-estudio-cientifico-skill-guiada | Skill | Skill portable que convierte análisis de un estudio científico en un proceso repetible y verificable. | se activa sola cuando hace falta |
| analisis-de-un-estudio-cientifico-subagente-revisor | Subagente | Subagente especializado en leer y resumir un estudio sin exagerar lo que demuestra sin permisos de escritura ni acciones externas. | pídele a Claude «usa el subagente analisis-de-un-estudio-cientifico-subagente-revisor» |
