# arsenal-salud-alternativas-2 · Salud y deporte · Alternativas (2)

Salud y deporte · Alternativas (2): 20 subagentes en español que se parecen a otras piezas de salud y deporte; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-salud-alternativas-2@arsenal
```
