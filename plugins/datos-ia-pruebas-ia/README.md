# arsenal-datos-ia-pruebas-ia · Datos e IA · Pruebas y evaluación de la IA

Datos e IA · Pruebas y evaluación de la IA: 3 subagentes, 1 comando /, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-datos-ia-pruebas-ia@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| diagnostico-agente | Comando / | Analiza una conversación concreta en la que tu bot o agente respondió mal y te dice dónde está la causa y qué línea cambiar. | `/diagnostico-agente` o `/arsenal-datos-ia-pruebas-ia:diagnostico-agente` |
| evaluacion-de-una-ia-skill-guiada | Skill | Evalúa una IA cada vez igual: mismos criterios, mismo rigor. | se activa sola cuando hace falta |
| auditor-de-prompts | Subagente | Coge un prompt que da resultados irregulares: desmonta, encuentra por qué falla, versión reescrita. | pídele a Claude «usa el subagente auditor-de-prompts» |
| banco-de-pruebas-de-asistentes | Subagente | Subagente que crea un banco de casos de prueba y una rúbrica para saber, con datos, si tu asistente de IA responde bien o mal. | pídele a Claude «usa el subagente banco-de-pruebas-de-asistentes» |
| evaluacion-de-una-ia-subagente-revisor | Subagente | ¿Una IA cumple lo que promete? Esto te dice si confiar en ella. | pídele a Claude «usa el subagente evaluacion-de-una-ia-subagente-revisor» |
