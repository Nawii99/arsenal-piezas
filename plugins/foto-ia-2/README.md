# arsenal-foto-ia-2 · Foto e imagen · Imágenes con IA (2)

Foto e imagen · Imágenes con IA (2): 14 subagentes, 3 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-ia-2@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| optimizar-imagenes-web | Skill | Convierte tus fotos en imágenes web ligeras y nítidas: tamaños, formatos, compresión y el HTML correcto para que la página cargue rápida. | se activa sola cuando hace falta |
| seo-imagenes | Skill | Prepara nombres de archivo, textos alternativos y datos de tus imágenes para que aparezcan en Google Imágenes y ayuden a posicionar la página. | se activa sola cuando hace falta |
| texto-legible-en-imagen | Skill | Consigue imágenes con texto que se lea de verdad: carteles, promos, precios y portadas, sin faltas de ortografía ni letras inventadas. | se activa sola cuando hace falta |
| auditor-imagenes-web | Subagente | Revisa todas las imágenes de tu web o tienda y te dice cuáles pesan de más, están mal cortadas o sin texto alternativo, con la lista de arreglos. | pídele a Claude «usa el subagente auditor-imagenes-web» |
| ficha-estilo-visual | Subagente | De tus mejores fotos al documento que le das al fotógrafo o generador IA para que repita. | pídele a Claude «usa el subagente ficha-estilo-visual» |
| guardian-coherencia-visual | Subagente | Cuáles de tus imágenes no parecen de la misma marca y cómo hacerlas coherentes. | pídele a Claude «usa el subagente guardian-coherencia-visual» |
| guia-estilo-visual | Subagente | Fija el estilo de tus imágenes (luz, color, encuadre, fondo) en una receta reutilizable para que todas tus fotos parezcan de la misma marca. | pídele a Claude «usa el subagente guia-estilo-visual» |
| ingeniero-inverso-de-estilo | Subagente | Subagente que mira una foto que te gusta y te devuelve la receta para replicarla: plano, lente, luz, fondo y el prompt listo. | pídele a Claude «usa el subagente ingeniero-inverso-de-estilo» |
| inventario-banco-imagenes | Subagente | Subagente que pone orden en el caos de fotos que tienes repartidas por carpetas: las cataloga, encuentra duplicados y te dice qué imágenes te faltan. | pídele a Claude «usa el subagente inventario-banco-imagenes» |
| limpieza-metadatos-imagen | Subagente | Los datos ocultos en tus fotos (GPS, equipo, cliente) antes de publicar o entregar. | pídele a Claude «usa el subagente limpieza-metadatos-imagen» |
| optimizador-imagenes-web | Subagente | De imágenes pesadas de 5 MB a una web que carga rápido: tamaños, WebP, srcset. | pídele a Claude «usa el subagente optimizador-imagenes-web» |
| qa-imagen-ia | Subagente | Los detalles que falla la IA: manos, dedos, texto, logos, reflejos (antes que lo note alguien). | pídele a Claude «usa el subagente qa-imagen-ia» |
| revisor-derechos-de-imagen | Subagente | De dónde vienen tus imágenes y cuáles te pueden traer problemas legales: licencias, caras. | pídele a Claude «usa el subagente revisor-derechos-de-imagen» |
| revisor-derechos-imagen | Subagente | Comprueba de dónde salen las imágenes que vas a publicar y si puedes usarlas, para que no te llegue una reclamación. | pídele a Claude «usa el subagente revisor-derechos-imagen» |
| revisor-imagenes-ia | Subagente | Revisa una imagen generada con IA antes de que la publiques y te dice si tiene fallos que delatan que es falsa o que te van a costar una devolución. | pídele a Claude «usa el subagente revisor-imagenes-ia» |
| revisor-legibilidad-visual | Subagente | Subagente que comprueba que tus imágenes con texto se leen de verdad: contraste, tamaño, miniatura y visión con problemas de color. | pídele a Claude «usa el subagente revisor-legibilidad-visual» |
| seo-imagenes-google | Subagente | Escribe los nombres de archivo, el texto alternativo y los pies de foto de tus imágenes para que aparezcan en Google Imágenes y en las búsquedas. | pídele a Claude «usa el subagente seo-imagenes-google» |
