# arsenal-negocio-estrategia · Negocio · Plan y estrategia

Negocio · Plan y estrategia: 8 subagentes, 2 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-estrategia@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| estrategia-por-rondas | Skill | Construye la estrategia de un negocio en seis rondas (premisas, cliente, números, precio, posicionamiento con plan de 90 días, y riesgos y decisión) cuestionando cada premisa. | se activa sola cuando hace falta |
| informe-competencia-apify | Skill | Recoge datos públicos de tus competidores con Apify (web, precios, redes, anuncios, reseñas) y los convierte en un informe que separa lo que se ha visto de lo que se supone. | se activa sola cuando hace falta |
| ficha-riesgos-naturales-ubicacion | Subagente | Reúne en una ficha lo que dicen fuentes oficiales sobre inundación, incendio, terremoto, terreno y otros riesgos de un lugar de España, citando cada fuente y sin inventar probabilidades. | pídele a Claude «usa el subagente ficha-riesgos-naturales-ubicacion» |
| mapa-ingresos-repartidos | Subagente | Analiza de dónde viene tu dinero hoy, mide cuánto dependes de un solo cliente, producto o plataforma y diseña pruebas pequeñas para añadir otras fuentes de ingresos sin prometer nada. | pídele a Claude «usa el subagente mapa-ingresos-repartidos» |
| negocio-a-medida-de-tu-vida | Subagente | Cuadra tu negocio con la vida: horas, lugar, ingresos; cambios pequeños a 90 días. | pídele a Claude «usa el subagente negocio-a-medida-de-tu-vida» |
| plan-escalado-negocio-que-ya-vende | Subagente | Revisa los números de un negocio que ya vende, encuentra el cuello de botella y propone qué probar primero con pruebas pequeñas y un tope de gasto. | pídele a Claude «usa el subagente plan-escalado-negocio-que-ya-vende» |
| preparar-venta-o-relevo | Subagente | Ordena lo que hay que tener listo para vender un negocio o pasárselo a otra persona y propone una hoja de ruta con las preguntas que llevar a los asesores. | pídele a Claude «usa el subagente preparar-venta-o-relevo» |
| rutina-de-innovacion-para-pymes | Subagente | Diseña una rutina sencilla y repetible de innovación para una pyme: de dónde salen las ideas, cómo se eligen, cómo se prueban y quién se encarga de cada cosa. | pídele a Claude «usa el subagente rutina-de-innovacion-para-pymes» |
| salto-de-negocio-con-red | Subagente | Ayuda a pensar un cambio grande de negocio o de carrera con tus números reales, tres escenarios, pruebas pequeñas previas y puntos claros donde seguir, ajustar o parar. | pídele a Claude «usa el subagente salto-de-negocio-con-red» |
| vigia-cambios-tecnologicos | Subagente | Busca señales de que una tecnología puede alterar tu mercado y las separa en hechos con fuente, indicios y opiniones, sin inventar fechas ni cifras de mercado. | pídele a Claude «usa el subagente vigia-cambios-tecnologicos» |
