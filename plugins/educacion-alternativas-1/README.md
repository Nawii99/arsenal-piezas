# arsenal-educacion-alternativas-1 · Formación · Alternativas (1)

Formación · Alternativas (1): 23 comandos /, 7 skills en español que se parecen a otras piezas de formación; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-educacion-alternativas-1@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| adaptar-material | Comando / | Coge un material que ya tienes y lo reescribe para otro público, otro nivel o otro formato sin perder el contenido. | `/adaptar-material` o `/arsenal-educacion-alternativas-1:adaptar-material` |
| bajar-el-nivel | Comando / | Coge un texto técnico o denso y lo reescribe para el nivel real de tus alumnos, con analogías y escalera de conceptos. | `/bajar-el-nivel` o `/arsenal-educacion-alternativas-1:bajar-el-nivel` |

| clase-en-directo | Comando / | Minuta tu clase en directo por Zoom o Meet: bloques, dinámicas, control del tiempo y qué hacer si nadie abre la boca. | `/clase-en-directo` o `/arsenal-educacion-alternativas-1:clase-en-directo` |
| comando-rubrica | Comando / | Crea una rúbrica de evaluación de 4 niveles a partir de la tarea que vas a corregir. Tabla lista para pegar en Word, Google Docs o el cuaderno del profesor. | `/comando-rubrica` o `/arsenal-educacion-alternativas-1:comando-rubrica` |
