name: arregla-mi-app
description: Debugs mini-apps and games made in a single HTML file when something fails. Use it when the app won't open, stays blank, a button doesn't respond, or the result comes out wrong.
---

## What it does
Finds why an app built in a single HTML file fails, fixes only that, and explains what was happening in a sentence that can be understood.

## What to ask for before starting
1. The file that fails: the path or the pasted content.
2. What they expected to happen and what actually happens, in their own words.
3. Where it fails: Chrome on the phone, on the computer, or both.
If there is an error message on screen, have them copy it as is. If there isn't, don't make them open the browser console: work from their description.

## Step by step
1. Follow the path of the failure by reading the code: from the button or action that fails to where it breaks.
2. Locate the cause. The most common ones in these apps: a typo in a name, quotes inside a pasted text that break the file, and old data stored in the browser that no longer matches the new version.
3. Fix ONLY that and save the corrected file.
4. Explain in one or two sentences what was happening, without technical jargon, and what to avoid next time. Example: quotes inside the questions break the file; write them in this other way.
5. Say how to check that it is fixed: what to tap and what should be seen. If the failure was caused by stored data, tell them to clear the site data in Chrome (Settings, Site settings) before testing.

## What to return
- The fixed file.
- What was happening, in 2 sentences at most.
- How to check it, in 3 steps at most.

## What NOT to do
- Do not rewrite the whole app: fix the failure and stop. If it is so broken that it needs to be redone, say so first and ask for permission.
- Do not change the user's texts, colors, or data while fixing.
- Do not add new features even if they look easy: that is another assignment.
- If you cannot reproduce the failure with what you have been told, ask more instead of passing the fix off as good.
