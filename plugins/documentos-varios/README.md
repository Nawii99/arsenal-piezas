# arsenal-documentos-varios · Documentos · Más de documentos

Documentos · Más de documentos: 5 skills, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-documentos-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| diagramas-procesos-embudos-mermaid | Skill | Convierte la descripción de un proceso, embudo, calendario o estructura de datos en un diagrama Mermaid que se ve en el navegador y se descarga como imagen. | se activa sola cuando hace falta |
| especificacion-edi-odoo | Skill | Convierte las guías EDI de tu cliente (EDIFACT o X12) en una especificación clara de qué datos entran y salen de Odoo, con reglas de validación, casos de prueba y plan de puesta en marcha. | se activa sola cuando hace falta |
| montar-docuseal-para-clientes | Skill | Instala y configura DocuSeal para que un negocio pueda firmar documentos online, y explica qué cobrar y cómo no incumplir su licencia. | se activa sola cuando hace falta |
| presentaciones-en-serie-desde-plantilla | Skill | Rellena una plantilla de Google Slides con los datos de una tabla y deja una presentación lista por cada fila, para que las revises tú antes de enviarlas. | se activa sola cuando hace falta |
| presentaciones-powerpoint-notas-plantilla | Skill | Crea o edita un archivo .pptx a partir de tu contenido, con diapositivas claras, notas del ponente y, si la tienes, tu plantilla de empresa. | se activa sola cuando hace falta |
| documento-accionable-subagente-revisor | Subagente | Análisis auditado: resumen, qué decidir, tareas claras, qué no sabemos. | pídele a Claude «usa el subagente documento-accionable-subagente-revisor» |
