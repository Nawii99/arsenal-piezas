# arsenal-movil-mini-apps · Móvil · Mini-apps y juegos de un archivo

Móvil · Mini-apps y juegos de un archivo: 3 skills, 2 comandos /, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-movil-mini-apps@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| alcance-mini-app | Comando / | Convierte el «quiero una app» de un cliente en un alcance cerrado que se puede hacer con Claude Code en pocos días, con lo que entra, lo que no entra, las horas y tres precios. | `/alcance-mini-app` o `/arsenal-movil-mini-apps:alcance-mini-app` |
| explica-codigo | Comando / | Comando de Claude Code que traduce a castellano llano el código de un tutorial o proyecto de ejemplo descargado, para entender qué hace antes de tocarlo. | `/explica-codigo` o `/arsenal-movil-mini-apps:explica-codigo` |
| juego-html-para-movil | Skill | Skill de Claude Code que crea un juego completo en un solo archivo HTML, jugable en el Chrome de un Android sin instalar nada ni saber programar. | se activa sola cuando hace falta |
| mini-app-para-cliente | Skill | Construye una app o juego sencillo (quiz, memory, tarjetas de repaso, calculadora) que funcione en el móvil del cliente como página web, partiendo de un proyecto de ejemplo. | se activa sola cuando hace falta |
| tutorial-en-cristiano | Skill | Convierte un proyecto de ejemplo o tutorial con código (GitHub, blog) en una guía paso a paso para alguien que no programa: qué es, si te sirve, cómo arrancarlo y qué tocar. | se activa sola cuando hace falta |
| arregla-mi-app | Subagente | Depura tus mini-apps y juegos en HTML cuando algo falla: encuentra la causa, arregla solo eso y te explica qué pasaba en una frase que se entiende. | pídele a Claude «usa el subagente arregla-mi-app» |
