# arsenal-juegos-visores-3d · Videojuegos y 3D · Visores y configuradores 3D

Videojuegos y 3D · Visores y configuradores 3D: 2 skills, 2 subagentes, 1 comando / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-juegos-visores-3d@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| vender-configurador | Comando / | Prepara la propuesta comercial para venderle a un negocio un configurador 3D de sus productos, con alcance, precio por fases y email de contacto. | `/vender-configurador` o `/arsenal-juegos-visores-3d:vender-configurador` |
| configurador-3d-producto | Skill | Monta un visor 3D interactivo en tu web para que el cliente gire el producto y elija color o acabado antes de comprar. | se activa sola cuando hace falta |
| tour-virtual-negocio | Skill | Monta el tour virtual 360 de un negocio con el móvil o una cámara 360: cómo capturar, cómo procesarlo y dónde publicarlo. | se activa sola cuando hace falta |
| montador-configurador-3d | Subagente | Monta una web donde el cliente gira el producto, elige opciones y pide presupuesto de verdad. | pídele a Claude «usa el subagente montador-configurador-3d» |
| visor-3d-para-clientes | Subagente | Monta una web para girar tu modelo 3D en el navegador sin instalaciones ni cuota mensual. | pídele a Claude «usa el subagente visor-3d-para-clientes» |
