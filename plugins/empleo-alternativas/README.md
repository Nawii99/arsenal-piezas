# arsenal-empleo-alternativas · Empleo y currículum · Alternativas

Empleo y currículum · Alternativas: 11 comandos /, 6 skills, 3 subagentes en español que se parecen a otras piezas de empleo y currículum; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-empleo-alternativas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| adaptar-curriculum | Comando / | Coge el anuncio que pegas y reescribe tu curriculum para esa oferta concreta: reordena, prioriza y usa sus palabras. Sin inventar nada. | `/adaptar-curriculum` o `/arsenal-empleo-alternativas:adaptar-curriculum` |
| carta-oferta | Comando / | Pegas la oferta, sueltas tu experiencia y salen tres versiones de carta: larga, corta y mensaje de portal. | `/carta-oferta` o `/arsenal-empleo-alternativas:carta-oferta` |
| carta-presentacion | Comando / | Comando que genera una carta de presentación corta a partir del CV del usuario y una oferta de trabajo concreta. | `/carta-presentacion` o `/arsenal-empleo-alternativas:carta-presentacion` |
| carta-presentacion-2 | Comando / | Comando que genera una carta de presentación corta adaptada a una oferta de trabajo concreta a partir del CV del usuario, para no escribirla desde cero en cada postulación. | `/carta-presentacion-2` o `/arsenal-empleo-alternativas:carta-presentacion-2` |
| estado-busqueda | Comando / | Comando que resume tu busqueda de empleo: que se ha movido esta semana, que tienes que hacer hoy y que candidaturas hay que dar por muertas y cerrar. | `/estado-busqueda` o `/arsenal-empleo-alternativas:estado-busqueda` |
| preparar-candidatura | Comando / | Comando que, pegando una oferta entera, te devuelve el curriculum adaptado, la carta, el asunto del correo y la lista de revision antes de enviar. | `/preparar-candidatura` o `/arsenal-empleo-alternativas:preparar-candidatura` |
| presupuesto-candidato | Comando / | Presupuesto cerrado en minutos: paquete, extras, precio, plazo y válido hasta cuándo. | `/presupuesto-candidato` o `/arsenal-empleo-alternativas:presupuesto-candidato` |
| primer-curriculum | Comando / | Escribe de cero tu primer curriculum de tecnologia cuando aun no has trabajado en el sector, con el orden y el formato que pasan los filtros. | `/primer-curriculum` o `/arsenal-empleo-alternativas:primer-curriculum` |
| propuesta-precio-cv | Comando / | Genera al momento un mensaje de propuesta de precio y alcance para un cliente potencial del servicio de CV, listo para enviar. | `/propuesta-precio-cv` o `/arsenal-empleo-alternativas:propuesta-precio-cv` |
| revisar-ats | Comando / | Pega tu currículum y la oferta y te devuelve el veredicto del filtro automático, los fallos con la línea exacta y las correcciones ya escritas. | `/revisar-ats` o `/arsenal-empleo-alternativas:revisar-ats` |
| revisar-cv-ats | Comando / | Revisa un CV en texto y señala qué elementos pueden hacer que un sistema ATS lo descarte antes de que lo vea una persona. | `/revisar-cv-ats` o `/arsenal-empleo-alternativas:revisar-cv-ats` |
| adaptar-curriculum-oferta | Skill | Adapta un CV en texto plano a una oferta de trabajo concreta, resaltando palabras clave y logros relevantes sin inventar experiencia. | se activa sola cuando hace falta |
| adaptar-cv-a-oferta | Skill | Adapta un CV a una oferta de trabajo concreta, priorizando las palabras clave que buscan los filtros ATS, sin inventar experiencia. | se activa sola cuando hace falta |
| auditor-ats-cv | Skill | Analiza un CV en busca de los fallos de formato y estructura que hacen que un sistema ATS lo rechace antes de que lo vea una persona, con una lista de arreglos concretos. | se activa sola cuando hace falta |
| candidatura-adaptada-skill-guiada | Skill | Cada candidatura sale con la misma estructura: encaje claro, CV ordenado, carta enfocada, portfolio visible. | se activa sola cuando hace falta |
| crear-cv-web-basico | Skill | Guía a una persona sin conocimientos de programación para montar una página web sencilla con su currículum. | se activa sola cuando hace falta |
| preparar-negociacion-sueldo | Skill | Convierte una oferta en un rango de sueldo defendible: números de mercado, argumentos, guion de la conversación y línea de abandono. | se activa sola cuando hace falta |
| auditor-cv-web | Subagente | Revisa un currículum web o portfolio ya publicado y devuelve un informe de mejoras concreto, pensado como paso previo a vender una reforma del sitio. | pídele a Claude «usa el subagente auditor-cv-web» |
| entrevistador-tecnico-exigente | Subagente | Un subagente que te entrevista de verdad: repregunta, te pide ejemplos concretos y no se traga las respuestas de manual. | pídele a Claude «usa el subagente entrevistador-tecnico-exigente» |
| revisor-portfolio-cv | Subagente | Revisa una web de currículum o portfolio ya publicada y devuelve mejoras concretas, ordenadas por impacto. | pídele a Claude «usa el subagente revisor-portfolio-cv» |
