# arsenal-salud-varios · Salud y deporte · Más de salud y deporte

Salud y deporte · Más de salud y deporte: 5 comandos /, 2 subagentes, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-salud-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| bienestar-para-empresas | Comando / | Prepara la propuesta para vender tus servicios de bienestar a empresas de tu zona, con formatos, precios y email de contacto. | `/bienestar-para-empresas` o `/arsenal-salud-varios:bienestar-para-empresas` |
| lista-compra | Comando / | Convierte un menú semanal ya escrito, o unas recetas sueltas, en una lista de la compra agrupada por sección de supermercado, lista para marcar desde el móvil mientras se compra. | `/lista-compra` o `/arsenal-salud-varios:lista-compra` |
| onboarding-nutricion | Comando / | Comando que genera el cuestionario de alta y la propuesta de precio para un cliente nuevo del servicio de nutrición, antes de calcular nada. | `/onboarding-nutricion` o `/arsenal-salud-varios:onboarding-nutricion` |
| reactivar-pacientes | Comando / | Diseña una campaña para recuperar clientes o pacientes que llevan meses sin volver, segmentada por motivo real de abandono. | `/reactivar-pacientes` o `/arsenal-salud-varios:reactivar-pacientes` |
| red-derivacion | Comando / | Monta una red de derivación con otros profesionales de tu zona: a quién buscar, qué proponerle y cómo llevar la cuenta. | `/red-derivacion` o `/arsenal-salud-varios:red-derivacion` |
| calculadora-macros-tdee | Skill | Calcula el gasto calórico diario y el reparto de macros de una persona a partir de sus datos, para no tener que hacer las cuentas a mano cada vez que cambia de objetivo o de peso. | se activa sola cuando hace falta |
| analista-de-abandonos | Subagente | Subagente que descubre en qué momento exacto tus pacientes o clientes dejan de venir y monta el plan para retener y recuperar. | pídele a Claude «usa el subagente analista-de-abandonos» |
| planificador-menu-semanal | Subagente | Subagente que diseña un menú semanal sencillo y realista ajustado a las calorías y macros objetivo de alguien que empieza de cero en nutrición. | pídele a Claude «usa el subagente planificador-menu-semanal» |
