# arsenal-ecommerce-alternativas · Tienda por internet · Alternativas

Tienda por internet · Alternativas: 3 skills, 2 comandos /, 1 subagente en español que se parecen a otras piezas de tienda por internet; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ecommerce-alternativas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| auditoria-legal-tienda | Comando / | Pegas los textos legales que ya tiene tu tienda (o dices que no tienes ninguno) y te devuelve qué falta, qué está mal y en qué orden arreglarlo. | `/auditoria-legal-tienda` o `/arsenal-ecommerce-alternativas:auditoria-legal-tienda` |
| carrito-abandonado | Comando / | Monta la recuperación de compras a medias: los mensajes, los tiempos y las cinco cosas de tu checkout que hacen que la gente se vaya. | `/carrito-abandonado` o `/arsenal-ecommerce-alternativas:carrito-abandonado` |
| ficha-producto-ecommerce | Skill | Genera la ficha completa de un producto (título, descripción, bullets, FAQ y SEO) a partir de datos sueltos, para no escribirla desde cero cada vez que subes un producto. | se activa sola cuando hace falta |
| redactar-ficha-producto-ecommerce | Skill | Escribe título, descripción, bullets y llamada a la acción de un producto para pegar en Stripe o en un carrito ligero, sin inventar datos que luego generan reclamaciones. | se activa sola cuando hace falta |
| textos-legales-tienda | Skill | Genera los cuatro textos legales que toda tienda online española necesita: aviso legal, condiciones de venta, política de devoluciones y política de privacidad. | se activa sola cuando hace falta |
| redactor-de-fichas-producto | Subagente | Subagente que escribe descripciones de producto en lote a partir de una lista o CSV, con estructura de venta, medidas y datos correctos. | pídele a Claude «usa el subagente redactor-de-fichas-producto» |
