# arsenal-foto-marketplace · Foto e imagen · Fotos para marketplaces

Foto e imagen · Fotos para marketplaces: 3 comandos /, 2 subagentes, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-marketplace@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| auditar-fotos-ficha | Comando / | Revisa el conjunto de fotos de un producto y te dice cuáles faltan, en qué orden colocarlas y cuál debe ser la primera. | `/auditar-fotos-ficha` o `/arsenal-foto-marketplace:auditar-fotos-ficha` |
| fondo-limpio-marketplace | Comando / | Te prepara las fotos de producto con fondo limpio cumpliendo las normas de Amazon, Google Shopping, Wallapop o tu tienda, sin que te rechacen la ficha. | `/fondo-limpio-marketplace` o `/arsenal-foto-marketplace:fondo-limpio-marketplace` |
| foto-marketplace | Comando / | Prepara las fotos de un producto para que cumplan las normas de Amazon, Wallapop, Google Shopping o tu tienda y no te las rechacen. | `/foto-marketplace` o `/arsenal-foto-marketplace:foto-marketplace` |
| fondo-blanco-marketplace | Skill | Deja tus fotos de producto con fondo blanco puro o transparente cumpliendo las normas de Amazon, eBay, Wallapop y Shopify, sin Photoshop. | se activa sola cuando hace falta |
| auditor-fichas-imagen | Subagente | Antes de subir tus fotos de producto: cuáles tienen mal tamaño, fondo distinto o encuadre roto. | pídele a Claude «usa el subagente auditor-fichas-imagen» |
| preparador-fichas-marketplace | Subagente | Deja tus fotos cumpliendo las reglas exactas de Amazon, Google Shopping o el marketplace donde vendas, para que no te rechacen la ficha. | pídele a Claude «usa el subagente preparador-fichas-marketplace» |
