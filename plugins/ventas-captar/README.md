# arsenal-ventas-captar · Ventas · Captar clientes

Ventas · Captar clientes: 10 subagentes, 3 skills, 2 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ventas-captar@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| cualificar-lead | Comando / | Analiza un contacto que te ha escrito y te dice si merece la pena, qué le falta por saber y con qué mensaje responder. | `/cualificar-lead` o `/arsenal-ventas-captar:cualificar-lead` |
| pedir-referidos | Comando / | Monta tu sistema para pedir recomendaciones a los clientes contentos, con el momento exacto y los mensajes. | `/pedir-referidos` o `/arsenal-ventas-captar:pedir-referidos` |
| jotform-ordenar-formularios-y-respuestas | Skill | Revisa tus formularios de Jotform, resume las respuestas nuevas, detecta datos incompletos o raros y prepara el aviso o la fila que debe llegar a cada persona. | se activa sola cuando hace falta |
| plan-captacion-90-dias-producto-digital | Skill | Prepara un plan de 12 semanas con uno o dos canales y experimentos medibles para conseguir usuarios de una app, un SaaS, una newsletter o un curso. | se activa sola cuando hace falta |
| revision-paginas-captacion-formularios | Skill | Revisa una página de captación y su formulario (Callpage u otra): claridad, campos, avisos legales y que los datos lleguen donde deben, y propone pocos cambios que se puedan medir. | se activa sola cuando hace falta |
| alianzas-que-suman | Subagente | Diseña una colaboración entre negocios en la que ganan los dos, con mensaje de contacto, prueba de 30 a 60 días y acuerdo de una página para revisar. | pídele a Claude «usa el subagente alianzas-que-suman» |
| anti-noshow | Subagente | Monta el sistema para que no falten a las reuniones de venta que ya tienen agendadas. | pídele a Claude «usa el subagente anti-noshow» |
| ayuda-primero-a-tus-contactos | Subagente | Te ayuda a decidir qué gestos útiles puedes ofrecer a tus contactos profesionales y a redactar mensajes breves, sin condiciones ocultas, para cuidar la relación a largo plazo. | pídele a Claude «usa el subagente ayuda-primero-a-tus-contactos» |
| del-si-a-la-firma | Subagente | Subagente que gestiona el tramo final: desde que el cliente dice que sí hasta que el contrato está firmado y el primer pago hecho. | pídele a Claude «usa el subagente del-si-a-la-firma» |
| detalles-con-clientes | Subagente | Prepara una agenda de pequeños gestos con tus clientes y contactos (mensajes, recursos útiles, agradecimientos) con borradores y coste en euros, para que los envíes tú. | pídele a Claude «usa el subagente detalles-con-clientes» |
| entrevista-win-loss | Subagente | Prepara y analiza la conversación con quien te dijo que no: la razón real, arréglala. | pídele a Claude «usa el subagente entrevista-win-loss» |
| fichas-de-venta-por-sector | Subagente | Prepara una ficha de venta por sector que traduce tu producto a los problemas, el lenguaje y los frenos de cada uno. | pídele a Claude «usa el subagente fichas-de-venta-por-sector» |
| filtro-de-clientes | Subagente | Subagente que cualifica los contactos que te entran, te dice a quién llamar hoy, a quién dejar en espera y a quién decir que no. | pídele a Claude «usa el subagente filtro-de-clientes» |
| plan-de-upsell-cartera | Subagente | Revisa tus clientes actuales: a cuáles venderles más, qué exactamente y con qué mensaje. | pídele a Claude «usa el subagente plan-de-upsell-cartera» |
| red-de-prescriptores | Subagente | Monta un sistema de referidos: a quién pedir, con qué palabras, qué dar a cambio, llevar la cuenta. | pídele a Claude «usa el subagente red-de-prescriptores» |
