# arsenal-ventas-tienda · Ventas · Venta por internet

Ventas · Venta por internet: 17 skills, 5 subagentes, 1 comando / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ventas-tienda@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| carrito-abandonado | Comando / | Monta la recuperación de compras a medias: los mensajes, los tiempos y las cinco cosas de tu checkout que hacen que la gente se vaya. | `/carrito-abandonado` |
| auditoria-ingresos-app-movil | Skill | Revisa cómo gana (o pierde) dinero una app móvil con compras, suscripciones o publicidad y entrega una lista ordenada de cambios a probar, sin tocar el código. | se activa sola cuando hace falta |
| catalogo-cloudcart-con-marcha-atras | Skill | Prepara cambios masivos de precios, stock y fichas de tu tienda CloudCart en un archivo que revisas, con copia del original para poder deshacerlos. | se activa sola cuando hace falta |
| detector-fricciones-pago-tienda | Skill | Recorre el proceso de compra de tu tienda, del carrito a la confirmación, y lista qué hace que la gente se vaya, ordenado por gravedad y con el arreglo de cada cosa. | se activa sola cuando hace falta |
| flujos-compra-email-sms-tienda | Skill | Subagente que diseña y redacta los mensajes automáticos de una tienda online (bienvenida, carrito abandonado, pedido, envío, reseña) para dejarlos listos en Omnisend o en una herramienta similar. | se activa sola cuando hace falta |
| gorgias-clasificar-tickets-y-borradores | Skill | Lee los tickets abiertos en Gorgias, los clasifica por tipo y urgencia y deja un borrador de respuesta para que lo revise una persona. | se activa sola cuando hace falta |

| pedidos-whatsapp-telegram-botstar | Skill | Skill para Claude Code o cualquier IA que diseña el asistente de pedidos de un negocio que ya vende por WhatsApp o Telegram con BotStar. | se activa sola cuando hace falta |
