# arsenal-ventas-fidelizar · Ventas · Fidelizar y vender más

Ventas · Fidelizar y vender más: 7 subagentes, 7 comandos /, 4 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ventas-fidelizar@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| caso-de-exito | Comando / | Convierte un trabajo que hiciste bien en un caso de éxito con datos, estructura y permiso del cliente, listo para usarlo en ventas. | `/caso-de-exito` |
| reactivar-clientes-dormidos | Comando / | Saca ventas de tu lista de clientes antiguos: los agrupa por tipo, escribe el mensaje de cada grupo y te da el orden para llamarlos. | `/reactivar-clientes-dormidos` |
| recuperar-clientes-dormidos | Comando / | Crea la campaña para volver a activar clientes que te compraron y llevan meses sin aparecer. | `/recuperar-clientes-dormidos` |
| respuestas-clientes | Comando / | Analiza el mensaje de un cliente y te da un diagnóstico, una respuesta lista para copiar, una versión firme, una versión para reseña pública y cómo evitar que se repita. | `/respuestas-clientes` |
| subir-precios | Comando / | Prepara la subida de tarifas a tus clientes actuales: a quién, cuánto, cuándo y con qué carta, previendo quién se irá. | `/subir-precios` |
| subir-ticket-postventa | Comando / | Diseña qué ofrecer justo después de la compra y en los días siguientes para que cada cliente te deje más dinero sin sentirse presionado. | `/subir-ticket-postventa` |
| upsell-siguiente-compra | Comando / | Diseña qué venderle después a un cliente que ya te compró, cuándo proponérselo y con qué mensaje. | `/upsell-siguiente-compra` |
| diagnostico-de-ventas-skill-guiada | Skill | Guía paso a paso para auditar ventas siempre del mismo modo. | se activa sola cuando hace falta |
| ingresos-devengados-saas | Skill | Reparte mes a mes los ingresos de suscripciones y servicios de un SaaS, calcula lo facturado, lo reconocido y lo diferido, y separa los casos dudosos para que los resuelva tu contable. | se activa sola cuando hace falta |
| plan-precios-cobro-y-bajas | Skill | Diseña los precios, el cobro con Stripe y el plan contra las bajas de un producto o servicio de pago recurrente, partiendo de tus costes reales. | se activa sola cuando hace falta |
| triaje-casos-service-cloud | Skill | Ordena la cola de casos de Service Cloud por urgencia y tema, resume cada conversación y deja borradores de respuesta que revisa una persona. | se activa sola cuando hace falta |
| cazador-de-fugas-antes-de-renovar | Subagente | Subagente que detecta qué clientes recurrentes están a punto de irse y te prepara la conversación para retenerlos antes de que lo digan. | pídele a Claude «usa el subagente cazador-de-fugas-antes-de-renovar» |
| diagnostico-de-ventas-subagente-revisor | Subagente | Analiza fugas de ventas y propone dónde intervenir, sin escribir en tus sistemas. | pídele a Claude «usa el subagente diagnostico-de-ventas-subagente-revisor» |
| disenador-de-suscripciones | Subagente | Diseña planes de suscripción mensual o anual con niveles, precios, cambios de plan, impagos y bajas, y deja la lista de pasos para configurarlos en tu herramienta de cobro. | pídele a Claude «usa el subagente disenador-de-suscripciones» |
| fabricar-casos-de-exito | Subagente | Subagente que entrevista a tu cliente contento y convierte lo que cuenta en un caso de éxito que vende, más el testimonio corto para redes. | pídele a Claude «usa el subagente fabricar-casos-de-exito» |
| reactivar-clientes-dormidos | Subagente | Subagente que rescata a los clientes que ya te compraron y desaparecieron, con un motivo creíble para volver y un mensaje por cliente. | pídele a Claude «usa el subagente reactivar-clientes-dormidos» |
| subida-de-precios-a-clientes | Subagente | Subagente que planifica y redacta la subida de precios a tus clientes actuales: a quién, cuánto, cuándo y con qué palabras. | pídele a Claude «usa el subagente subida-de-precios-a-clientes» |
| venta-despues-de-la-venta | Subagente | Diseña qué ofrecer justo después de cada compra: upsell, cross-sell, mensajes exactos. | pídele a Claude «usa el subagente venta-despues-de-la-venta» |
