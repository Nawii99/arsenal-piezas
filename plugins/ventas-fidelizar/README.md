# arsenal-ventas-fidelizar · Ventas · Fidelizar y vender más

Ventas · Fidelizar y vender más: 3 subagentes, 3 comandos /, 2 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ventas-fidelizar@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| caso-de-exito | Comando / | Convierte un trabajo que hiciste bien en un caso de éxito con datos, estructura y permiso del cliente, listo para usarlo en ventas. | `/caso-de-exito` o `/arsenal-ventas-fidelizar:caso-de-exito` |
| renovar-iguala | Comando / | Prepara la conversación de renovación de una iguala o contrato mensual, incluida la subida de precio, con datos y sin perder al cliente. | `/renovar-iguala` o `/arsenal-ventas-fidelizar:renovar-iguala` |
| subir-ticket-postventa | Comando / | Diseña qué ofrecer justo después de la compra y en los días siguientes para que cada cliente te deje más dinero sin sentirse presionado. | `/subir-ticket-postventa` o `/arsenal-ventas-fidelizar:subir-ticket-postventa` |
| fidelizacion-referidos-goody | Skill | Diseña un programa para que tus clientes repitan o te recomienden, con reglas claras, recompensas con tope de gasto, mensajes y seguimiento mensual. | se activa sola cuando hace falta |
| recontacto-clientes-finerworks | Skill | Revisa en solo lectura los clientes y pedidos de tu cuenta de Finerworks, te dice a quién toca escribir y te deja los mensajes en borrador sin enviar nada. | se activa sola cuando hace falta |
| cazador-de-fugas-antes-de-renovar | Subagente | Subagente que detecta qué clientes recurrentes están a punto de irse y te prepara la conversación para retenerlos antes de que lo digan. | pídele a Claude «usa el subagente cazador-de-fugas-antes-de-renovar» |
| diagnostico-bajas-recompra-clientes | Subagente | Analiza tus datos de clientes para ver cuándo y por qué dejan de comprar o se dan de baja, y propone acciones pequeñas que se puedan comprobar. | pídele a Claude «usa el subagente diagnostico-bajas-recompra-clientes» |
| reactivar-clientes-dormidos | Subagente | Subagente que rescata a los clientes que ya te compraron y desaparecieron, con un motivo creíble para volver y un mensaje por cliente. | pídele a Claude «usa el subagente reactivar-clientes-dormidos» |
