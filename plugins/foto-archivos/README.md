# arsenal-foto-archivos · Foto e imagen · Archivos y publicación

Foto e imagen · Archivos y publicación: 6 comandos /, 4 subagentes, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-archivos@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| alt-text-imagenes | Comando / | Escribe el texto alternativo, el nombre de archivo y el pie de foto de tus imágenes para que Google las entienda y sean accesibles. | `/alt-text-imagenes` |
| banco-fotos-negocio | Comando / | Organiza tu carpeta de fotos hecha un desastre: nombres, carpetas, versiones y un sistema para encontrar cualquier imagen en segundos. | `/banco-fotos-negocio` |
| imagenes-rapidas-web | Comando / | Deja las imágenes de tu web ligeras y bien nombradas, con su texto alternativo, para que la página cargue rápido y Google las entienda. | `/imagenes-rapidas-web` |
| imagenes-web-ligeras | Comando / | Deja las fotos de tu web ligeras y bien nombradas para que la página cargue rápido y Google las entienda, sin programas de pago. | `/imagenes-web-ligeras` |
| optimizar-imagenes-web | Comando / | Revisa las imágenes de tu web, te dice cuáles pesan de más y te da los comandos exactos para dejarlas ligeras sin que pierdan calidad. | `/optimizar-imagenes-web` |
| seo-imagenes | Comando / | Prepara los nombres de archivo, los textos alternativos y el marcado de tus imágenes para que traigan visitas desde Google. | `/seo-imagenes` |
| fotos-de-local-y-espacios | Skill | Método para fotografiar con el móvil un local, una consulta, un piso o unas instalaciones y que se vean amplias, limpias y con luz. | se activa sola cuando hace falta |
| redactor-alt-y-nombres | Subagente | Subagente que escribe el texto alternativo y el nombre de archivo de todas las imágenes de tu web: accesibles, útiles y bien vistos por Google. | pídele a Claude «usa el subagente redactor-alt-y-nombres» |
| rescate-fotos-negocio | Subagente | Las fotos con el móvil que tienes, mejoradas o cuáles hay que repetir (sin sesión de fotógrafo). | pídele a Claude «usa el subagente rescate-fotos-negocio» |
| revisor-entrega-fotos | Subagente | Revisa un lote de fotos: medidas, peso, nombres, permisos, IA detectada, antes de entregar. | pídele a Claude «usa el subagente revisor-entrega-fotos» |
| revisor-fotos-antes-publicar | Subagente | Revisa una foto antes de publicarla: recortes, medidas, color, retoques y permisos que faltan. | pídele a Claude «usa el subagente revisor-fotos-antes-publicar» |
