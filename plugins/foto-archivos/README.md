# arsenal-foto-archivos · Foto e imagen · Archivos y publicación

Foto e imagen · Archivos y publicación: 7 subagentes, 1 comando / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-archivos@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| banco-fotos-negocio | Comando / | Organiza tu carpeta de fotos hecha un desastre: nombres, carpetas, versiones y un sistema para encontrar cualquier imagen en segundos. | `/banco-fotos-negocio` o `/arsenal-foto-archivos:banco-fotos-negocio` |
| archivador-de-fotos | Subagente | Subagente que ordena una carpeta caótica de fotos: detecta duplicados, las renombra con un sistema claro y te deja un índice en CSV para encontrarlo todo. | pídele a Claude «usa el subagente archivador-de-fotos» |
| entrega-fotos-cliente | Subagente | Cómo entregar tus fotos: versiones, marca de agua, nombres ordenados y condiciones de uso. | pídele a Claude «usa el subagente entrega-fotos-cliente» |
| limpiador-metadatos-foto | Subagente | Quita la ubicación GPS, el modelo del móvil y otros datos que se ven en tu foto. | pídele a Claude «usa el subagente limpiador-metadatos-foto» |
| optimizador-de-imagenes-web | Subagente | Deja tus fotos e imágenes ligeras y en el formato correcto para que la web cargue rápido sin que se vean feas. | pídele a Claude «usa el subagente optimizador-de-imagenes-web» |
| organizador-catalogo-fotos | Subagente | Ordena y renombra tu montón de fotos por producto, quita duplicadas y te deja una hoja con qué foto corresponde a cada referencia. | pídele a Claude «usa el subagente organizador-catalogo-fotos» |
| preparador-para-imprenta | Subagente | Subagente que comprueba si tus imágenes valen para imprimir y te evita el disgusto de recibir 500 folletos borrosos o con los colores cambiados. | pídele a Claude «usa el subagente preparador-para-imprenta» |
| revisor-entrega-fotos | Subagente | Revisa un lote de fotos: medidas, peso, nombres, permisos, IA detectada, antes de entregar. | pídele a Claude «usa el subagente revisor-entrega-fotos» |
