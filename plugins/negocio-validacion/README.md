# arsenal-negocio-validacion · Negocio · Validar ideas y mercado

Negocio · Validar ideas y mercado: 3 skills, 3 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-validacion@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| ideas-con-prueba-previa | Skill | Cruza lo que sabes hacer, tu tiempo y tu dinero con problemas por los que ya hay gente pagando, y te deja 3 ideas con una prueba barata para cada una. | se activa sola cuando hace falta |
| prueba-de-compra-del-cliente | Skill | Revisa tu oferta poniéndose en el lugar de tu cliente objetivo y responde si pagaría hoy ese precio por esa solución. | se activa sola cuando hace falta |
| validacion-de-oferta-skill-guiada | Skill | Proceso repetible para no dejarme Ideas de lado sin verificarlas. | se activa sola cuando hace falta |
| de-idea-a-primeras-ventas | Subagente | Convierte una idea de negocio en una hipótesis, un guion de entrevistas y una prueba de pago barata, con un criterio para seguir, cambiar o parar que confirmas tú. | pídele a Claude «usa el subagente de-idea-a-primeras-ventas» |
| plan-90-dias-validar-negocio | Subagente | Guía un plan de 90 días para comprobar con clientes reales si una idea de negocio se paga, hacer las cuentas y decidir si seguir, cambiar o parar. | pídele a Claude «usa el subagente plan-90-dias-validar-negocio» |
| validar-demanda-antes-de-invertir | Subagente | Investiga mercado, competencia y clientes posibles con fuentes citadas y te dice si conviene seguir, ajustar o parar antes de gastar dinero. | pídele a Claude «usa el subagente validar-demanda-antes-de-invertir» |
