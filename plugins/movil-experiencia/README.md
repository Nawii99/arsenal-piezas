# arsenal-movil-experiencia · Móvil · Pantallas y experiencia

Móvil · Pantallas y experiencia: 3 subagentes, 1 comando /, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-movil-experiencia@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| onboarding-app | Comando / | Rediseña las primeras pantallas de tu app para que la gente llegue al momento «ah, ya lo pillo» antes de aburrirse y desinstalar. | `/onboarding-app` o `/arsenal-movil-experiencia:onboarding-app` |
| onboarding-movil-skill-guiada | Skill | Onboarding móvil repetible: menos abandonos cada vez, el mismo. | se activa sola cuando hace falta |
| auditor-accesibilidad-movil | Subagente | Revisa si tu app o web se puede usar con una mano, con letra grande, con poca luz y con lector de pantalla, y te da los arreglos concretos. | pídele a Claude «usa el subagente auditor-accesibilidad-movil» |
| onboarding-movil-subagente-revisor | Subagente | Analiza onboarding móvil: dónde se queman usuarios, cómo arreglarlo. | pídele a Claude «usa el subagente onboarding-movil-subagente-revisor» |
| plan-de-medicion-de-tu-app | Subagente | Subagente que decide qué eventos hay que medir dentro de la app, cómo se llaman, qué datos llevan y qué panel mirar cada semana para saber si va bien. | pídele a Claude «usa el subagente plan-de-medicion-de-tu-app» |
