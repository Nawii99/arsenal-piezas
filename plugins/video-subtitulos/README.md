# arsenal-video-subtitulos · Vídeo · Subtítulos y transcripción

Vídeo · Subtítulos y transcripción: 4 subagentes, 2 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-video-subtitulos@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| subtitulos-srt | Comando / | Genera subtítulos bien segmentados en .srt y .txt a partir de tu transcripción, con la velocidad de lectura y el corte de línea correctos. | `/subtitulos-srt` o `/arsenal-video-subtitulos:subtitulos-srt` |
| subtitulos-video | Comando / | Transcribe, corrige y quema subtítulos con estilo en tu vídeo, con el tamaño y la posición correctos para que no los tape la interfaz de la red social. | `/subtitulos-video` o `/arsenal-video-subtitulos:subtitulos-video` |
| revisor-de-subtitulos-en-espanol | Subagente | Subagente que arregla un archivo de subtítulos generado automáticamente: tiempos, velocidad de lectura, cortes de línea, nombres propios y ortografía en español de España. | pídele a Claude «usa el subagente revisor-de-subtitulos-en-espanol» |
| subtitulador-accesible | Subagente | Subagente que crea los subtítulos con tiempos, el texto alternativo de las imágenes y las adaptaciones para que tu contenido lo entienda todo el mundo. | pídele a Claude «usa el subagente subtitulador-accesible» |
| subtitulador-srt | Subagente | Subagente que transcribe un vídeo, corrige la transcripción y genera subtítulos SRT legibles, bien cortados y sincronizados, listos para YouTube, Reels o TikTok. | pídele a Claude «usa el subagente subtitulador-srt» |
| version-otro-idioma | Subagente | Adapta un vídeo que funciona para otro idioma o país: tiempos, textos, sin que pierda efecto. | pídele a Claude «usa el subagente version-otro-idioma» |
