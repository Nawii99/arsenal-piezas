# arsenal-productividad · Productividad

Productividad: 7 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-productividad@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| actualizar-paquete-skills | Skill | Trae la versión nueva de un paquete de skills instalado a mano, te cuenta qué cambia en lenguaje llano y solo la aplica si tú dices que sí, con copia de seguridad previa. | se activa sola cuando hace falta |
| cuaderno-de-lo-que-funciona | Skill | Guarda en un archivo del proyecto los aprendizajes pequeños de tu negocio que ya tienen un dato detrás, para que Claude los lea al empezar. Lo no comprobado va a otro archivo. | se activa sola cuando hace falta |
| cuaderno-de-traspaso | Skill | Guarda en un archivo lo decidido, lo descartado, las hipótesis y los próximos pasos de tu negocio para retomar el trabajo en otra sesión sin repetir análisis. | se activa sola cuando hace falta |
| inventario-automatizaciones-y-suscripciones | Skill | Lista lo que tienes montado en Claude Code (skills, comandos, subagentes, hooks y conectores, explicados en llano) y lo que pagas cada mes o año, para ver qué sigue en marcha y qué sobra. | se activa sola cuando hace falta |
| plugins-oficiales-con-ficha | Skill | Antes de usar skills de terceros, comprueba si un plugin oficial de Claude Code ya cubre la tarea, verifica que viene del sitio oficial, lista lo que instala y deja una ficha. | se activa sola cuando hace falta |
| revision-semanal-skill-guiada | Skill | Revisión semanal repetible: mismo rigor para decidir cada semana. | se activa sola cuando hace falta |
| rutinas-con-supervision | Skill | Te ayuda a listar las tareas repetidas de tu negocio, decidir cuáles automatizar con poco riesgo y supervisión, y diseñar cada rutina con límites, semáforo de salud y botón de parada. | se activa sola cuando hace falta |
