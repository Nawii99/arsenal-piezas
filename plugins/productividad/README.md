# arsenal-productividad · Productividad

Productividad: 1 skill, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-productividad@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| revision-semanal-skill-guiada | Skill | Revisión semanal repetible: mismo rigor para decidir cada semana. | se activa sola cuando hace falta |
| revision-semanal-subagente-revisor | Subagente | Tu semana auditada: balance, qué atacas, qué descartas, agenda clara. | pídele a Claude «usa el subagente revision-semanal-subagente-revisor» |
