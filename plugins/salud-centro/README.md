# arsenal-salud-centro · Salud y deporte · Gestión del centro

Salud y deporte · Gestión del centro: 3 subagentes, 2 skills, 2 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-salud-centro@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| cuadro-mando-clinica | Comando / | Monta el cuadro de mando mensual de tu centro: qué seis números mirar, cómo calcularlos con lo que ya tienes y qué hacer con cada uno. | `/cuadro-mando-clinica` o `/arsenal-salud-centro:cuadro-mando-clinica` |
| fotos-evolucion | Comando / | Monta el protocolo para hacer fotos de evolución que se puedan comparar de verdad: permiso, encuadre fijo, luz y dónde se guardan. | `/fotos-evolucion` o `/arsenal-salud-centro:fotos-evolucion` |
| auditoria-papeles-consulta | Skill | Revisa consentimientos, protección de datos, citas y facturas de una consulta y devuelve un informe de hallazgos que se puede entregar y cobrar como primer servicio. | se activa sola cuando hace falta |
| protocolo-sala-y-material | Skill | Escribe el protocolo diario de apertura, entre pacientes y cierre de la sala, con higiene, material y control de stock. | se activa sola cuando hace falta |
| control-stock-consumibles | Subagente | Subagente que ordena el material fungible del centro: qué comprar, cuánto, cuándo pedir y qué caducidades vigilar cada semana. | pídele a Claude «usa el subagente control-stock-consumibles» |
| onboarding-nuevo-empleado | Subagente | Prepara el plan completo de los primeros 30 días: qué aprende cada día sin que seas tú el cuello de botella. | pídele a Claude «usa el subagente onboarding-nuevo-empleado» |
| planificador-cuadrante-centro | Subagente | Monta el cuadrante de tu equipo cruzando demanda real con horas: dónde sobra gente, dónde falta. | pídele a Claude «usa el subagente planificador-cuadrante-centro» |
