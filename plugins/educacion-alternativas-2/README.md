# arsenal-educacion-alternativas-2 · Formación · Alternativas (2)

Formación · Alternativas (2): 13 skills, 3 subagentes en español que se parecen a otras piezas de formación; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-educacion-alternativas-2@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| onboarding-alumno | Skill | Diseña los primeros 7 días del alumno tras la compra: mensajes, primera victoria y comprobaciones para que empiece de verdad. | se activa sola cuando hace falta |
| plantilla-leccion-skill | Skill | Genera una plantilla de lección para clase con objetivos, actividades y materiales a partir de un tema y nivel. | se activa sola cuando hace falta |
| propuesta-de-formacion-para-empresas | Skill | Prepara la propuesta comercial de una formación a medida para una empresa: diagnóstico, programa, logística, precio y cómo se mide el resultado. | se activa sola cuando hace falta |
| propuesta-formacion-empresa | Skill | Prepara la propuesta con la que vendes una formación a medida dentro de una empresa: diagnóstico, programa, formato, precio y cómo van a medir si sirvió. | se activa sola cuando hace falta |
| propuesta-formacion-empresas | Skill | Redacta la propuesta para vender una formación a una empresa: objetivos, programa, horas, precio, logística y qué se mide después. | se activa sola cuando hace falta |
| prueba-de-nivel-e-itinerarios | Skill | Crea la prueba de nivel de entrada de tu formación y los itinerarios para que cada alumno empiece por donde le toca. | se activa sola cuando hace falta |
| rescatar-alumnos-parados | Skill | Por qué tus alumnos se quedan a mitad de camino y cómo traerlos de vuelta. | se activa sola cuando hace falta |
| rescate-alumnos-parados | Skill | Detecta a los alumnos que se han quedado parados y te escribe la secuencia de mensajes para reengancharlos antes de que pidan la devolución o desaparezcan. | se activa sola cuando hace falta |
| rubrica-correccion | Skill | Crea la rúbrica con la que corriges los trabajos de tus alumnos y redacta el feedback de cada entrega en minutos, siempre con el mismo criterio. | se activa sola cuando hace falta |
| rubrica-de-evaluacion | Skill | Construye la rúbrica para corregir trabajos, proyectos o entregas de alumnos con criterios claros, niveles y notas justificables. | se activa sola cuando hace falta |
| rubrica-y-feedback-skill | Skill | Crea la rúbrica de corrección de una entrega y te redacta el feedback a cada alumno: rápido, concreto y sin desanimar. | se activa sola cuando hace falta |
| taller-presencial-2h | Skill | Cada minuto de tu taller listo: dinámicas, tiempo, material y qué haces si se descuadra. | se activa sola cuando hace falta |
| test-nivel-inicial | Skill | Monta el test de nivel que pasas antes de empezar, para saber qué sabe cada alumno, colocarlo en el punto correcto y evitar que abandone por aburrimiento o por atasco. | se activa sola cuando hace falta |
| auditor-de-curso-grabado | Subagente | Subagente que se ve las transcripciones de un curso ya grabado y te dice qué sobra, qué falta, dónde se aburre la gente y qué hay que regrabar. | pídele a Claude «usa el subagente auditor-de-curso-grabado» |
| banco-de-preguntas-con-trampa | Subagente | Subagente que construye un banco de preguntas de examen con distractores creíbles basados en los errores reales que comete la gente. | pídele a Claude «usa el subagente banco-de-preguntas-con-trampa» |
| banco-de-preguntas-evaluacion | Subagente | Subagente que construye un banco de preguntas de examen calibrado por dificultad, con distractores creíbles y con la justificación de cada respuesta. | pídele a Claude «usa el subagente banco-de-preguntas-evaluacion» |
