# arsenal-en-agents-1

Arsenal del Marketer in English: 15 subagents (part 1 of 2) for marketing, sales, design and small business.

## Install

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-en-agents-1@arsenal
```

## What's inside

| Piece | Area | What it does |
|---|---|---|
| adaptador-letras-doblaje-en | Music & audio | Subagent that adapts a song lyric into another language while matching syllable count and musical stress, so it can be sung to the same melody. |
| compositor-letras-canciones-en | Music & audio | Subagent that interviews the user and writes a full original song lyric with verses, chorus and bridge, explaining each part for non-musicians. |
| auditor-webhooks-pago-en | Backend | Claude Code subagent auditing payment webhook code for signature checks, double processing and unhandled events, reporting risks in plain language before production. |
| prevision-vs-realidad-en | Data | Claude Code subagent that compares a forecast or simulation with what really happened, measures the error and proposes adjustments that must be checked against new data. |
| auditor-rag-documentos-en | Data & AI | Subagent that stress-tests a document Q&A chat with a question bank, checking answers against sources to find invented facts and retrieval failures. |
| cribador-candidatos-en | Data & AI | Subagent that scores a batch of CVs against a job's must-have and nice-to-have requirements and ranks them with reasons. |
| afinador-movimiento-respuesta-pantalla-en | Design | Claude Code subagent that audits a web or app and specifies how the screen should respond at each moment (tap, loading, success, error, empty state) with accessible, restrained motion. |
| diseno-que-ayuda-a-decidir-en | Design | Claude Code subagent that reviews sales pages and sign-up flows and proposes clear, non-manipulative changes with a measurement plan. |
| asiento-revisor-tienda-en | E-commerce | Read-only subagent for Claude Code that audits a live online shop for issues costing sales or causing complaints, ranked by cost and minimum fix. |
| disenador-rubricas-en | Education | Subagent that builds grading rubrics for assignments, essay exams or presentations, with defined criteria, distinct performance levels and weights that total 100. |
| auditor-cv-web-en | Jobs & résumé | Subagent that reviews an existing CV or portfolio site from its URL or HTML and writes a short report of the most costly problems, used as a sales step. |
| critico-carta-presentacion-en | Jobs & résumé | A subagent that reviews a finished cover letter, bluntly flagging filler sentences, generic phrasing and anything that makes it look like every other applicant's. |
| auditor-facturas-deducibles-en | Finance | Subagent that reviews a batch of received invoices for a Spanish freelancer or small company and marks each as deductible for VAT and IRPF, with a reason. |
| director-de-fotografia-en | Photo & image | Claude Code subagent that turns a product into a full set of AI image prompts with angle, lens, light and platform sizes, plus phone-shooting notes. |
| diagnostico-iot-en | IoT & hardware | Subagent that diagnoses why a DIY IoT device such as a camera, alarm sensor, irrigation relay or weather station stopped working, ruling out causes by likelihood. |
