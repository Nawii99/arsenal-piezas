# arsenal-en-agents-1

Arsenal del Marketer in English: 15 subagents (part 1 of 2) for marketing, sales, design and small business.

## Install

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-en-agents-1@arsenal
```

## What's inside

| Piece | Area | What it does | How to use |
|---|---|---|---|
| adaptador-letras-doblaje-en | Music & audio | Subagent that adapts a song lyric into another language while matching syllable count and musical stress, so it can be sung to the same melody. | ask Claude «use the adaptador-letras-doblaje-en subagent» |
| compositor-letras-canciones-en | Music & audio | Subagent that interviews the user and writes a full original song lyric with verses, chorus and bridge, explaining each part for non-musicians. | ask Claude «use the compositor-letras-canciones-en subagent» |
| auditor-webhooks-pago-en | Backend | Claude Code subagent auditing payment webhook code for signature checks, double processing and unhandled events, reporting risks in plain language before production. | ask Claude «use the auditor-webhooks-pago-en subagent» |
| prevision-vs-realidad-en | Data | Claude Code subagent that compares a forecast or simulation with what really happened, measures the error and proposes adjustments that must be checked against new data. | ask Claude «use the prevision-vs-realidad-en subagent» |
| auditor-rag-documentos-en | Data & AI | Subagent that stress-tests a document Q&A chat with a question bank, checking answers against sources to find invented facts and retrieval failures. | ask Claude «use the auditor-rag-documentos-en subagent» |
| cribador-candidatos-en | Data & AI | Subagent that scores a batch of CVs against a job's must-have and nice-to-have requirements and ranks them with reasons. | ask Claude «use the cribador-candidatos-en subagent» |
| afinador-movimiento-respuesta-pantalla-en | Design | Claude Code subagent that audits a web or app and specifies how the screen should respond at each moment (tap, loading, success, error, empty state) with accessible, restrained motion. | ask Claude «use the afinador-movimiento-respuesta-pantalla-en subagent» |
| diseno-que-ayuda-a-decidir-en | Design | Claude Code subagent that reviews sales pages and sign-up flows and proposes clear, non-manipulative changes with a measurement plan. | ask Claude «use the diseno-que-ayuda-a-decidir-en subagent» |
| asiento-revisor-tienda-en | E-commerce | Read-only subagent for Claude Code that audits a live online shop for issues costing sales or causing complaints, ranked by cost and minimum fix. | ask Claude «use the asiento-revisor-tienda-en subagent» |
| disenador-rubricas-en | Education | Subagent that builds grading rubrics for assignments, essay exams or presentations, with defined criteria, distinct performance levels and weights that total 100. | ask Claude «use the disenador-rubricas-en subagent» |
| auditor-cv-web-en | Jobs & résumé | Subagent that reviews an existing CV or portfolio site from its URL or HTML and writes a short report of the most costly problems, used as a sales step. | ask Claude «use the auditor-cv-web-en subagent» |
| critico-carta-presentacion-en | Jobs & résumé | A subagent that reviews a finished cover letter, bluntly flagging filler sentences, generic phrasing and anything that makes it look like every other applicant's. | ask Claude «use the critico-carta-presentacion-en subagent» |
| auditor-facturas-deducibles-en | Finance | Subagent that reviews a batch of received invoices for a Spanish freelancer or small company and marks each as deductible for VAT and IRPF, with a reason. | ask Claude «use the auditor-facturas-deducibles-en subagent» |
| director-de-fotografia-en | Photo & image | Claude Code subagent that turns a product into a full set of AI image prompts with angle, lens, light and platform sizes, plus phone-shooting notes. | ask Claude «use the director-de-fotografia-en subagent» |
| diagnostico-iot-en | IoT & hardware | Subagent that diagnoses why a DIY IoT device such as a camera, alarm sensor, irrigation relay or weather station stopped working, ruling out causes by likelihood. | ask Claude «use the diagnostico-iot-en subagent» |
