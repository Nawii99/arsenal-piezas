# arsenal-en-agents-2

Arsenal del Marketer in English: 15 subagents (part 2 of 2) for marketing, sales, design and small business.

## Install

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-en-agents-2@arsenal
```

## What's inside

| Piece | Area | What it does | How to use |
|---|---|---|---|
| agente-precio-lanzamiento-en | Games & 3D | Subagent that researches comparable games' prices and proposes a launch price and discount calendar, with a VAT warning when selling outside major stores. | ask Claude «use the agente-precio-lanzamiento-en subagent» |
| asesor-registro-marca-espana-en | Legal & contracts | Subagent that walks first-time applicants through registering a Spanish trademark at OEPM, from naming to filing, with plain-language explanations. | ask Claude «use the asesor-registro-marca-espana-en subagent» |
| afilar-propuesta-de-valor-en | Marketing | Claude Code subagent that sharpens your value proposition using your customers' language, filters the real differences and leaves three versions ready to test with real people. | ask Claude «use the afilar-propuesta-de-valor-en subagent» |
| afinador-propuesta-de-valor-en | Marketing | Drafts several versions of a value proposition using customers' own words, compares them against real alternatives, and sets up a test with real people before you decide. | ask Claude «use the afinador-propuesta-de-valor-en subagent» |
| arregla-mi-app-en | Mobile | Subagent that debugs a single-file HTML mini-app or game when it fails to open, goes blank or a button does nothing, returning the cause, a narrow fix and a one-line explanation. | ask Claude «use the arregla-mi-app-en subagent» |
| auditor-entrega-app-en | Mobile | A subagent that checks an Android or iOS app before delivery or store upload: icons, splash screen, permissions, notifications, metadata and privacy policy. | ask Claude «use the auditor-entrega-app-en subagent» |
| acompanante-practico-separacion-en | Business | Claude Code subagent that helps organise a separation or divorce in Spain: decisions in order, documents, two-household budget and questions for the lawyer. | ask Claude «use the acompanante-practico-separacion-en subagent» |
| brujula-giro-profesional-en | Business | Claude Code subagent that helps think through a professional or business change calmly and returns a 90-day plan of small tests with stop-or-continue criteria. Not therapy. | ask Claude «use the brujula-giro-profesional-en subagent» |
| calculador-cargas-en | Health & fitness | Subagent that estimates 1RM from a performed set, computes working percentages per set and builds a week-by-week load progression for strength or hypertrophy. | ask Claude «use the calculador-cargas-en subagent» |
| derechos-paciente-rgpd-en | Health & fitness | Subagent that analyses a patient's data-rights request under GDPR and Spanish law and drafts a compliant reply with the deadline and what can and cannot be provided. | ask Claude «use the derechos-paciente-rgpd-en subagent» |
| auditor-secretos-dependencias-en | Cybersecurity | Subagent that reviews your own repository or website for leaked secrets, outdated dependencies and missing security headers, returning a prioritized fix plan. | ask Claude «use the auditor-secretos-dependencias-en subagent» |
| agente-pago-a-plazos-en | Sales | Claude Code subagent that plans a buy-now-pay-later setup for an online shop, covering provider choice, fees, copy and test steps before going live. | ask Claude «use the agente-pago-a-plazos-en subagent» |
| atencion-al-cliente-en | Sales | Claude Code subagent that classifies customer messages, drafts replies in brand tone, prepares FAQs and escalates sensitive cases to a person. | ask Claude «use the atencion-al-cliente-en subagent» |
| editor-de-video-en | Video | Claude Code subagent that plans short-video and ad edits with a shot-by-shot table, hook options, CapCut or DaVinci steps and 9:16, 1:1 and 16:9 exports. | ask Claude «use the editor-de-video-en subagent» |
| guionista-video-corto-presentacion-en | Video | Claude Code subagent that writes a short self-presentation video script for jobseekers or freelancers and adapts it to Reels, TikTok, Shorts and LinkedIn. Asks for missing data. | ask Claude «use the guionista-video-corto-presentacion-en subagent» |
