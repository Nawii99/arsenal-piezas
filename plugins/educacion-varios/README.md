# arsenal-educacion-varios · Formación · Más de formación

Formación · Más de formación: 7 skills, 3 subagentes, 1 comando / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-educacion-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| caso-practico | Comando / | Diseña un caso práctico realista con datos, contexto y solución comentada para que tus alumnos practiquen de verdad. | `/caso-practico` o `/arsenal-educacion-varios:caso-practico` |
| buscar-skill-para-tarea-de-clase | Skill | Encuentra skill ya hecha para clase: verifica que sea fiable, con licencia, antes usarla. | se activa sola cuando hace falta |
| casos-practicos-y-role-play | Skill | Escribe casos prácticos realistas y simulaciones de rol para que tus alumnos practiquen decisiones, no solo teoría. | se activa sola cuando hace falta |
| clase-prueba-que-convierte | Skill | Diseña la clase gratuita que enseña algo de verdad y además vende el curso de pago, sin ser un anuncio disfrazado de formación. | se activa sola cuando hace falta |
| de-presencial-a-online | Skill | Rediseña un taller o curso presencial para darlo online sin que se convierta en una charla aburrida de tres horas. | se activa sola cuando hace falta |
| formar-a-alguien-de-tu-equipo | Skill | De tu cabeza al papel: lo que haces cada día convertido en un plan que alguien pueda aprender. | se activa sola cuando hace falta |
| taller-presencial-3h | Skill | Guion minuto a minuto de un taller presencial o por videollamada: dinámicas, tiempos, materiales y plan B si el grupo no participa. | se activa sola cuando hace falta |
| unidad-de-aprendizaje-skill-guiada | Skill | Todas tus unidades salen iguales de claras: mismo orden, mismas preguntas, mismos puntos de control. | se activa sola cuando hace falta |
| entrenador-de-roleplay | Subagente | Hace de cliente difícil en un simulacro: la persona practica hablando y sale el feedback exacto. | pídele a Claude «usa el subagente entrenador-de-roleplay» |
| fabrica-de-ejercicios | Subagente | Convierte tu teoría en ejercicios prácticos: enunciado, datos, solución paso a paso, criterio de corrección. | pídele a Claude «usa el subagente fabrica-de-ejercicios» |
| itinerario-formacion-equipo | Subagente | Subagente que detecta qué le falta saber a un equipo, monta el itinerario de formación por puesto y lo deja listo para presentar a la dirección. | pídele a Claude «usa el subagente itinerario-formacion-equipo» |
