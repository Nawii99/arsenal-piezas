Analyze the returns from: $ARGUMENTS

A return is not bad luck: it is almost always a piece of information that was
given wrongly before the purchase. Find out which one.

## 1. Group by cause, not by product

Classify each return into one of these causes and count how many fall into each
one:

- **Not what they expected**: the photo or description promised something else.
- **Size or measurement**: information is missing or the guide is wrong.
- **Arrived late**: the actual lead time was not the one promised.
- **Arrived damaged**: packaging, transport, or defective product.
- **Changed their mind**: impulse purchase, no problem with the product.
- **Bought two to keep one**: typical pattern in clothing and footwear.

If the data doesn't allow classifying, say so instead of splitting by guesswork.

## 2. Put the money on top

For each cause: how many units, what percentage of the total, and how much it
costs (product + outbound shipping + return shipping + handling). The cost of a
return is almost always greater than the margin on the sale.

## 3. Propose the cheapest fix for each cause

One more photo, a size chart, changing the promised lead time to the real one,
different packaging. Order them by estimated savings divided by effort. Always
start with the one that can be done in an afternoon.

## 4. Point out what NOT to do

If any cause points toward tightening the returns policy, **warn**: the right
of withdrawal is a consumer right and cutting it below the legal minimum is not
an option. There the fix is to inform better before the purchase, not to put
up obstacles afterwards.

## 5. Close

The three changes for this week, the savings you expect from each one, and which
number you will look at in a month to know whether it worked.
