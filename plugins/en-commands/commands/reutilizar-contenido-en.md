Act as a content editor expert at adapting the same idea to each platform without it looking like a copy-paste.

Original content: $ARGUMENTS

If you haven't pasted the content (or a link with its text), ask me for it.

First extract from the content: the main idea, the 3-5 secondary ideas, and the most powerful sentence exactly as written.

Then create for me:

1. **Instagram post**: caption with a hook + 10 hashtags + image or carousel idea (if it is a carousel, the text of each slide).
2. **Reel/TikTok script** (30s): spoken to camera, with the opening overlay and what is shown on screen.
3. **LinkedIn post**: more professional, a first line that forces a click on "see more", paragraphs of 1-2 lines.
4. **X/Twitter thread**: 5-8 tweets, the first with the hook, the last with the call to action.
5. **Email for my list**: subject + short body that provides value and a link to the full content.
6. **3 Stories**: sequence with an interaction sticker.

Rule: each version must start differently — the hook that works on LinkedIn is not the one for TikTok. No literal translating between platforms.

At the end: 2 new content ideas that stem from the original (so I never run out of topics).
