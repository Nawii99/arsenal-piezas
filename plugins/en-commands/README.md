# arsenal-en-commands

Arsenal del Marketer in English: 30 slash commands for marketing, sales, design and small business.

## Install

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-en-commands@arsenal
```

## What's inside

| Piece | Area | What it does | How to use |
|---|---|---|---|
| buscar-comandos-audio-en | Music & audio | Claude Code slash command that searches community commands for one audio or publishing step, such as noise removal or loudness, reads each candidate without running it and gives a verdict. | `/buscar-comandos-audio-en` or `/arsenal-en-commands:buscar-comandos-audio-en` |
| episodio-podcast-en | Music & audio | Claude Code command with three modes for podcast episodes: show notes, promotion texts and a publishing checklist from a transcript. | `/episodio-podcast-en` or `/arsenal-en-commands:episodio-podcast-en` |
| buscar-comandos-cobros-facturas-en | Backend | Claude Code slash command that finds community commands for Stripe payments and invoicing, ranks them by risk to your money, reads them without running, and says which are safe to test. | `/buscar-comandos-cobros-facturas-en` or `/arsenal-en-commands:buscar-comandos-cobros-facturas-en` |
| datos-de-prueba-en | Quality & testing | Claude Code command generating coherent fake tables for shops, CRMs and automations, with valid-looking Spanish tax IDs and VAT totals, for loading into Shopify, Sheets or n8n. | `/datos-de-prueba-en` or `/arsenal-en-commands:datos-de-prueba-en` |
| reutilizar-contenido-en | Content | Claude Code command that turns one piece of content into versions for Instagram, Reels, LinkedIn, X, email and stories, plus two new ideas. | `/reutilizar-contenido-en` or `/arsenal-en-commands:reutilizar-contenido-en` |
| extraer-datos-cv-en | Data & AI | Claude Code command that pulls the key data from CVs or personal documents into an ordered table, with privacy notice and mandatory human review. | `/extraer-datos-cv-en` or `/arsenal-en-commands:extraer-datos-cv-en` |
| brief-logo-en | Design | Claude Code command that turns a few answers about your business into a logo and brand brief, with palette, fonts and AI image prompts. | `/brief-logo-en` or `/arsenal-en-commands:brief-logo-en` |
| asiento-cmd-devoluciones-en | E-commerce | Claude Code slash command that groups a shop's returns by real cause, estimates each cost, and proposes the cheapest fix with estimated savings. | `/asiento-cmd-devoluciones-en` or `/arsenal-en-commands:asiento-cmd-devoluciones-en` |
