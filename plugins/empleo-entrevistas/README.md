# arsenal-empleo-entrevistas · Empleo y currículum · Entrevistas y sueldo

Empleo y currículum · Entrevistas y sueldo: 3 comandos /, 2 subagentes, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-empleo-entrevistas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| negociar-sueldo | Comando / | Pegas la oferta y te devuelve la contrapropuesta lista: cifra, frase para decirla, email de respuesta y hasta dónde aguantar. | `/negociar-sueldo` o `/arsenal-empleo-entrevistas:negociar-sueldo` |
| preparar-entrevista | Comando / | Te prepara para una entrevista técnica y de recursos humanos: 30 preguntas con respuesta, la pregunta del sueldo, qué preguntar tú y un ensayo simulado. | `/preparar-entrevista` o `/arsenal-empleo-entrevistas:preparar-entrevista` |
| simulacro-entrevista | Comando / | Lanza un simulacro de entrevista completo, cronometrado y con informe final, para el puesto que le digas. | `/simulacro-entrevista` o `/arsenal-empleo-entrevistas:simulacro-entrevista` |
| respuestas-star | Skill | Convierte tus proyectos reales en respuestas STAR para las preguntas de comportamiento, sin inventarte nada. | se activa sola cuando hace falta |
| ensayo-negociacion-salarial | Subagente | Prepara tu negociación de sueldo y condiciones con rangos de mercado de fuentes citadas, un mapa de tu paquete completo, un guion de respuestas y un ensayo por turnos. | pídele a Claude «usa el subagente ensayo-negociacion-salarial» |
| preparador-caso-de-producto | Subagente | Entreno para casos de producto: conviertes necesidades vagas en requisitos e historias usuario. | pídele a Claude «usa el subagente preparador-caso-de-producto» |
