# arsenal-salud-alternativas-1 · Salud y deporte · Alternativas (1)

Salud y deporte · Alternativas (1): 22 comandos /, 12 skills en español que se parecen a otras piezas de salud y deporte; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-salud-alternativas-1@arsenal
```
