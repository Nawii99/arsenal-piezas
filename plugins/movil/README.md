# arsenal-movil · Móvil

Móvil: 42 subagentes, 40 comandos /, 35 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-movil@arsenal
```
