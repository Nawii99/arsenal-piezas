# arsenal-diseno · Diseño

Diseño: 23 subagentes, 15 comandos /, 7 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-diseno@arsenal
```
