# arsenal-iot-alternativas-3 · IoT y hardware · Alternativas (3)

IoT y hardware · Alternativas (3): 14 subagentes en español que se parecen a otras piezas de iot y hardware; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-iot-alternativas-3@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| diagnostico-red-zigbee | Subagente | Subagente que arregla redes Zigbee o de malla donde los sensores se caen, tardan o aparecen como no disponibles. | pídele a Claude «usa el subagente diagnostico-red-zigbee» |
| dossier-entrega-instalacion | Subagente | Convierte una instalación domótica terminada en dossier: inventario, esquema, manual del cliente y mantenimiento. | pídele a Claude «usa el subagente dossier-entrega-instalacion» |
| elegir-protocolo-radio | Subagente | Subagente que elige entre wifi, Zigbee, Z-Wave, Thread/Matter, Bluetooth o LoRa para tu caso, con los motivos y el plan B. | pídele a Claude «usa el subagente elegir-protocolo-radio» |
| escritor-esphome | Subagente | Escribe la configuración YAML de ESPHome para tu sensor o control, ya calibrada y comentada. | pídele a Claude «usa el subagente escritor-esphome» |
| manual-entrega-instalacion | Subagente | Subagente que redacta el manual de entrega de una instalación: cómo se usa, dónde está cada cosa, qué hacer si falla y qué cubre tu garantía. | pídele a Claude «usa el subagente manual-entrega-instalacion» |
| migrador-nube-a-local | Subagente | Subagente que planifica y ejecuta el paso de dispositivos que dependen de la nube china a control local, sin dejarte la casa a oscuras. | pídele a Claude «usa el subagente migrador-nube-a-local» |
| piloto-de-sensores-subagente-revisor | Subagente | Sensores auditados: medibles, que alguien puede mantener, respeta privacidad. | pídele a Claude «usa el subagente piloto-de-sensores-subagente-revisor» |
| plan-mantenimiento-iot | Subagente | Diseña el soporte de una instalación IoT después de entregarla para no atender gratis cada dos semanas. | pídele a Claude «usa el subagente plan-mantenimiento-iot» |
| presupuestador-domotica | Subagente | Subagente que convierte lo que quiere un cliente en un presupuesto de domótica con materiales, horas, precio y condiciones, listo para enviar. | pídele a Claude «usa el subagente presupuestador-domotica» |
| presupuesto-instalacion-domotica | Subagente | Subagente que convierte lo que quiere un cliente en un presupuesto de instalación domótica con materiales, mano de obra, riesgos y condiciones. | pídele a Claude «usa el subagente presupuesto-instalacion-domotica» |
| presupuesto-instalacion-iot | Subagente | Subagente que convierte lo que quiere el cliente en lista de materiales, horas de trabajo y un presupuesto con partidas, condiciones y opciones. | pídele a Claude «usa el subagente presupuesto-instalacion-iot» |
| rescate-dispositivo-huerfano | Subagente | Subagente que salva dispositivos cuya app o nube cierra el fabricante, buscando cómo controlarlos en local antes de que se conviertan en un ladrillo. | pídele a Claude «usa el subagente rescate-dispositivo-huerfano» |
| revision-seguridad-red-iot | Subagente | Revisa cacharros conectados: contraseñas por defecto, cámaras expuestas, separación de red sin ataques. | pídele a Claude «usa el subagente revision-seguridad-red-iot» |
| sacar-dispositivos-de-la-nube | Subagente | Subagente que planifica cómo pasar aparatos que dependen de la app del fabricante a control local, sin quedarte con ladrillos. | pídele a Claude «usa el subagente sacar-dispositivos-de-la-nube» |
