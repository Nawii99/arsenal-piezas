# arsenal-diseno-impresion · Diseño · Impresión y producto

Diseño · Impresión y producto: 3 subagentes, 2 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-diseno-impresion@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| mockup-producto | Comando / | Pone tu diseño sobre camisetas, tazas, bolsas o packaging con aspecto real, y comprueba que el tamaño y la resolución valen para imprimir. | `/mockup-producto` o `/arsenal-diseno-impresion:mockup-producto` |
| rotulo-local | Comando / | Diseña el rótulo, el escaparate y los vinilos de un local con las medidas de letra correctas para que se lea desde la calle. | `/rotulo-local` o `/arsenal-diseno-impresion:rotulo-local` |
| critica-de-diseno-antes-de-publicar | Subagente | Mira tu diseño con ojos de profesional y te dice, ordenados por gravedad, los tres o cuatro cambios que más lo mejoran. | pídele a Claude «usa el subagente critica-de-diseno-antes-de-publicar» |
| etiqueta-de-producto-lista-para-vender | Subagente | Diseña la etiqueta o el envase de tu producto con la información obligatoria en su sitio y la jerarquía que hace que se coja del estante. | pídele a Claude «usa el subagente etiqueta-de-producto-lista-para-vender» |
| preparar-archivos-para-imprenta | Subagente | Revisa tu PDF antes de mandarlo a imprimir: sangrado, resolución, colores, fuentes y márgenes, para que no te lo devuelvan. | pídele a Claude «usa el subagente preparar-archivos-para-imprenta» |
