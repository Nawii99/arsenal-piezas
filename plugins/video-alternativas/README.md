# arsenal-video-alternativas · Vídeo · Alternativas

Vídeo · Alternativas: 13 comandos /, 11 subagentes en español que se parecen a otras piezas de vídeo; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-video-alternativas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| ajustes-camara-movil | Comando / | Te da la configuración exacta del móvil, la luz y el sonido para grabar hoy, según lo que vas a grabar y con lo que tienes en casa. | `/ajustes-camara-movil` o `/arsenal-video-alternativas:ajustes-camara-movil` |
| clips-de-largo | Comando / | Encuentra dentro de un vídeo largo los momentos que funcionan como clip vertical y te da el corte exacto, el gancho y el texto en pantalla. | `/clips-de-largo` o `/arsenal-video-alternativas:clips-de-largo` |
| cortar-clips | Comando / | Convierte un vídeo largo (directo, podcast, webinar, clase) en 5-8 clips verticales listos para Reels, TikTok y Shorts, cortados con ffmpeg. | `/cortar-clips` o `/arsenal-video-alternativas:cortar-clips` |
| demo-pantalla | Comando / | Guion y plan para grabar una demostración de pantalla que se entienda: qué mostrar, en qué orden, qué ocultar y cómo evitar los errores que la hacen ilegible. | `/demo-pantalla` o `/arsenal-video-alternativas:demo-pantalla` |
| guion-video-cv | Comando / | Convierte tu CV y la oferta en un guion hablado de 60-90 segundos, con tiempos y versión para teleprompter. Es el paso que más se atasca y el que más tiempo ahorra. | `/guion-video-cv` o `/arsenal-video-alternativas:guion-video-cv` |
| guion-video-presentacion | Comando / | Comando que escribe el guion de un vídeo corto de presentación con datos reales de la persona, y que sirve de ejemplo de cómo se escribe un comando propio con argumentos. | `/guion-video-presentacion` o `/arsenal-video-alternativas:guion-video-presentacion` |
| guion-videocv | Comando / | Comando de Claude Code que escribe el guion de un vídeo currículum de 60 a 90 segundos a partir del perfil y del puesto que buscas, listo para leer en el móvil. | `/guion-videocv` o `/arsenal-video-alternativas:guion-videocv` |
| plan-de-cortes | Comando / | Convierte una transcripción o una descripción de lo grabado en una lista ordenada de cortes con marcas de tiempo, para saber qué recortar antes de montar. | `/plan-de-cortes` o `/arsenal-video-alternativas:plan-de-cortes` |
| presupuesto-video-2 | Comando / | Genera un presupuesto en euros para un encargo de edición de vídeo a partir de duración, complejidad y plazo. | `/presupuesto-video-2` o `/arsenal-video-alternativas:presupuesto-video-2` |
| revision-antes-de-publicar | Comando / | Revisa el vídeo terminado antes de subirlo: formato, zonas seguras, volumen, subtítulos, marca y el fallo tonto que se ve al minuto de publicar. | `/revision-antes-de-publicar` o `/arsenal-video-alternativas:revision-antes-de-publicar` |
| subtitulos-quemados | Comando / | Te saca los subtítulos de un vídeo, los corta al ritmo de lectura y te da el comando exacto para quemarlos con el estilo de Reels o TikTok. | `/subtitulos-quemados` o `/arsenal-video-alternativas:subtitulos-quemados` |
| subtitulos-srt-2 | Comando / | Comando que convierte una transcripción en un archivo .srt troceado y con tiempos, listo para importar en CapCut, DaVinci Resolve o Kdenlive. | `/subtitulos-srt-2` o `/arsenal-video-alternativas:subtitulos-srt-2` |
| teleprompter-guion | Comando / | Transforma un texto escrito en un guion locutable: frases cortas, marcas de respiración, énfasis y ritmo, listo para leer a cámara sin sonar a robot. | `/teleprompter-guion` o `/arsenal-video-alternativas:teleprompter-guion` |
| auditor-de-retencion-de-video | Subagente | Analiza curva de retención y datos de tus vídeos publicados: qué segundos cortar, rehacer, repetir. | pídele a Claude «usa el subagente auditor-de-retencion-de-video» |
| control-de-calidad-antes-de-publicar | Subagente | Revisa técnicamente un vídeo antes de subirlo: formato, duración, texto, audio, miniatura, zonas. | pídele a Claude «usa el subagente control-de-calidad-antes-de-publicar» |
| cortador-de-clips-verticales | Subagente | Extrae los momentos que funcionan solos de un vídeo largo y saca clips verticales limpios con ffmpeg. | pídele a Claude «usa el subagente cortador-de-clips-verticales» |
| doctor-retencion | Subagente | Analiza por qué la gente abandona tu vídeo y te dice la causa concreta, minuto a minuto. | pídele a Claude «usa el subagente doctor-retencion» |
| extractor-clips | Subagente | Subagente que ve un vídeo largo y saca de él los mejores clips cortos para redes, con timecodes exactos, gancho, título y el comando para exportarlos. | pídele a Claude «usa el subagente extractor-clips» |
| jefe-de-produccion-de-rodaje-con-movil | Subagente | Ordena los planos de un rodaje móvil por posición de cámara: sin cambiar la luz cada vez, grabas varios vídeos en un día. | pídele a Claude «usa el subagente jefe-de-produccion-de-rodaje-con-movil» |
| limpiador-audio-video | Subagente | Subagente que arregla el audio de vídeos grabados con móvil: quita ruido de fondo, iguala volumen, corrige voces bajas y deja el nivel que piden las plataformas. | pídele a Claude «usa el subagente limpiador-audio-video» |
| localiza-video | Subagente | Subagente que adapta un vídeo tuyo a otro idioma o a otro mercado: guion adaptado, tiempos que cuadran y subtítulos correctos. | pídele a Claude «usa el subagente localiza-video» |
| publicacion-multiplataforma | Subagente | Prepara todo lo de subir el vídeo: versiones, títulos, descripciones, capítulos por plataforma. | pídele a Claude «usa el subagente publicacion-multiplataforma» |
| rescate-audio-video | Subagente | Subagente que arregla el audio de un vídeo ya grabado: ruido de fondo, voz baja, eco, desincronía y niveles irregulares. | pídele a Claude «usa el subagente rescate-audio-video» |
| subtitulos-que-se-leen | Subagente | Subagente que genera, corrige y quema los subtítulos de tus vídeos con el corte de línea y el estilo correctos. | pídele a Claude «usa el subagente subtitulos-que-se-leen» |
