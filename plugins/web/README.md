# arsenal-web · Web

Web: 28 comandos /, 14 subagentes, 6 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-web@arsenal
```
