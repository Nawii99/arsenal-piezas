# arsenal-documentos · Documentos

Documentos: 25 subagentes, 4 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-documentos@arsenal
```
