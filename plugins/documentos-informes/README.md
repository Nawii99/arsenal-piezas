# arsenal-documentos-informes · Documentos · Informes, plantillas y presentaciones

Documentos · Informes, plantillas y presentaciones: 4 subagentes, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-documentos-informes@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| presentacion-cliente-slides | Skill | Prepara el guion y el borrador de una presentación de cliente (propuesta, informe o pitch) para Google Slides a partir de tus notas, cifras y plantilla. | se activa sola cuando hace falta |
| informe-mensual-word | Subagente | Convierte tus números del mes en un informe presentable para cliente o socio. | pídele a Claude «usa el subagente informe-mensual-word» |
| plantilla-presupuesto-excel | Subagente | Monta una plantilla de presupuestos y facturas: fórmulas, IVA, IRPF, todo bloqueado. | pídele a Claude «usa el subagente plantilla-presupuesto-excel» |
| presentacion-desde-documento | Subagente | Convierte un documento largo en PowerPoint limpio: una idea por diapositiva, notas, apoyo visual. | pídele a Claude «usa el subagente presentacion-desde-documento» |
| subagente-cartas-personalizadas-en-masa | Subagente | Coge tu plantilla y tu lista de contactos: genera un documento personalizado sin campos sin rellenar. | pídele a Claude «usa el subagente subagente-cartas-personalizadas-en-masa» |
