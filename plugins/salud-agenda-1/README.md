Salud y deporte · Agenda y pacientes (1): 14 comandos /, 8 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-salud-agenda-1@arsenal
```
