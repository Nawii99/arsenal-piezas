# arsenal-foto-varios · Foto e imagen · Más de foto e imagen

Foto e imagen · Más de foto e imagen: 7 skills, 7 comandos /, 6 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| adaptar-medidas-imagen | Comando / | Coge una imagen madre y te da el plan de recortes y versiones para cada sitio donde publicas, sin que se corte lo importante. | `/adaptar-medidas-imagen` o `/arsenal-foto-varios:adaptar-medidas-imagen` |
| antes-y-despues | Comando / | Monta comparativas de antes y después creíbles y honestas para servicios: reformas, estética, limpieza, restauración o formación. | `/antes-y-despues` o `/arsenal-foto-varios:antes-y-despues` |
| cartel-con-texto | Comando / | Genera imágenes con texto legible de verdad (carteles, precios, promos) y te dice cuándo es mejor poner el texto encima tú mismo. | `/cartel-con-texto` o `/arsenal-foto-varios:cartel-con-texto` |
| derechos-de-imagen | Comando / | Te dice si puedes usar una imagen en tu negocio sin meterte en un lío: licencias, caras, logos y contenido generado con IA. | `/derechos-de-imagen` o `/arsenal-foto-varios:derechos-de-imagen` |
| rescatar-fotos-movil | Comando / | Diagnostica una foto mala hecha con el móvil, te dice si tiene arreglo y te da el plan de retoque paso a paso con herramientas gratis. | `/rescatar-fotos-movil` o `/arsenal-foto-varios:rescatar-fotos-movil` |
| riesgo-legal-imagen | Comando / | Revisa tus imágenes antes de publicarlas: caras, marcas ajenas, obras protegidas, licencias y cuándo hay que avisar de que son de IA. | `/riesgo-legal-imagen` o `/arsenal-foto-varios:riesgo-legal-imagen` |
| sesion-movil-45min | Comando / | Te monta la sesión de fotos completa con el móvil y cosas de casa: montaje, ajustes y lista de tomas cronometrada. | `/sesion-movil-45min` o `/arsenal-foto-varios:sesion-movil-45min` |
| antes-despues-honesto | Skill | Monta comparativas de antes y después creíbles y legales para servicios: reformas, estética, peluquería, limpieza, talleres o entrenamiento. | se activa sola cuando hace falta |
| cartel-con-texto-skill | Skill | Genera carteles, promos y portadas donde el texto sale bien escrito dentro de la imagen, con jerarquía y contraste legibles. | se activa sola cuando hace falta |
| derechos-imagen-skill | Skill | Te aclara qué imágenes puedes usar y publicar sin meterte en un lío: bancos gratis, marcas ajenas, caras, y qué pasa con lo generado por IA. | se activa sola cuando hace falta |
| foto-movil-a-catalogo | Skill | Cómo fotografiar tu producto con el móvil para que se vea listo para vender. | se activa sola cuando hace falta |
| fotos-de-local-y-espacios | Skill | Método para fotografiar con el móvil un local, una consulta, un piso o unas instalaciones y que se vean amplias, limpias y con luz. | se activa sola cuando hace falta |
| reencuadre-multiformato | Skill | Adapta una misma imagen a todos los formatos (1:1, 4:5, 9:16, 16:9, banner) sin cortar lo importante ni deformar nada. | se activa sola cuando hace falta |
| rescatar-foto-mala | Skill | Diagnostica una foto mala y te dice qué se puede arreglar, cómo hacerlo gratis y cuándo sale más a cuenta repetirla. | se activa sola cuando hace falta |
| cortador-de-carruseles | Subagente | Cómo partir una imagen panorámica en diapositivas de carrusel que se entienda en móvil. | pídele a Claude «usa el subagente cortador-de-carruseles» |
| planificador-sesion-movil | Subagente | La sesión de fotos con el móvil minuto a minuto: qué necesitas, dónde te pones, en qué orden. | pídele a Claude «usa el subagente planificador-sesion-movil» |
| recortes-multiformato | Subagente | Una foto convertida en todas las versiones que necesitas sin perder el producto ni el texto. | pídele a Claude «usa el subagente recortes-multiformato» |
| rescate-fotos-negocio | Subagente | Las fotos con el móvil que tienes, mejoradas o cuáles hay que repetir (sin sesión de fotógrafo). | pídele a Claude «usa el subagente rescate-fotos-negocio» |
| revisor-derechos-imagen | Subagente | Comprueba de dónde salen las imágenes que vas a publicar y si puedes usarlas, para que no te llegue una reclamación. | pídele a Claude «usa el subagente revisor-derechos-imagen» |
| revisor-legibilidad-visual | Subagente | Subagente que comprueba que tus imágenes con texto se leen de verdad: contraste, tamaño, miniatura y visión con problemas de color. | pídele a Claude «usa el subagente revisor-legibilidad-visual» |
