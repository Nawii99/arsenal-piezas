# arsenal-foto-varios · Foto e imagen · Más de foto e imagen

Foto e imagen · Más de foto e imagen: 9 subagentes, 5 skills, 3 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| antes-despues | Comando / | Monta la pieza de antes y después de un trabajo, con las reglas para que sea creíble y no te metas en un lío legal. | `/antes-despues` |
| antes-y-despues | Comando / | Monta comparativas de antes y después creíbles y honestas para servicios: reformas, estética, limpieza, restauración o formación. | `/antes-y-despues` |
| rescatar-fotos-movil | Comando / | Diagnostica una foto mala hecha con el móvil, te dice si tiene arreglo y te da el plan de retoque paso a paso con herramientas gratis. | `/rescatar-fotos-movil` |
| antes-despues-honesto | Skill | Monta comparativas de antes y después creíbles y legales para servicios: reformas, estética, peluquería, limpieza, talleres o entrenamiento. | se activa sola cuando hace falta |
| cartel-con-texto-skill | Skill | Genera carteles, promos y portadas donde el texto sale bien escrito dentro de la imagen, con jerarquía y contraste legibles. | se activa sola cuando hace falta |
| modelo-recurrente-ia | Skill | Consigue que el mismo personaje, modelo o mascota de marca aparezca reconocible en todas tus imágenes generadas. | se activa sola cuando hace falta |
| reencuadre-multiformato | Skill | Adapta una misma imagen a todos los formatos (1:1, 4:5, 9:16, 16:9, banner) sin cortar lo importante ni deformar nada. | se activa sola cuando hace falta |
| rescatar-foto-mala | Skill | Diagnostica una foto mala y te dice qué se puede arreglar, cómo hacerlo gratis y cuándo sale más a cuenta repetirla. | se activa sola cuando hace falta |
| archivador-de-fotos | Subagente | Subagente que ordena una carpeta caótica de fotos: detecta duplicados, las renombra con un sistema claro y te deja un índice en CSV para encontrarlo todo. | pídele a Claude «usa el subagente archivador-de-fotos» |
| cazador-de-fallos-ia | Subagente | Los fallos de IA más típicos en imágenes (manos, texto, reflejos) antes de que lo vea el cliente. | pídele a Claude «usa el subagente cazador-de-fallos-ia» |
| comparador-creatividades | Subagente | Monta la comparación entre varias versiones de una imagen, define cómo probarlas y te dice cuál gana y por qué. | pídele a Claude «usa el subagente comparador-creatividades» |
| entrega-fotos-cliente | Subagente | Cómo entregar tus fotos: versiones, marca de agua, nombres ordenados y condiciones de uso. | pídele a Claude «usa el subagente entrega-fotos-cliente» |
| limpiador-metadatos-foto | Subagente | Quita la ubicación GPS, el modelo del móvil y otros datos que se ven en tu foto. | pídele a Claude «usa el subagente limpiador-metadatos-foto» |
| preparador-para-imprenta | Subagente | Subagente que comprueba si tus imágenes valen para imprimir y te evita el disgusto de recibir 500 folletos borrosos o con los colores cambiados. | pídele a Claude «usa el subagente preparador-para-imprenta» |
| preparar-imprenta | Subagente | Subagente que deja tus imágenes listas para imprimir (flyer, cartel, rótulo, packaging) sin que la imprenta te devuelva el archivo ni salga pixelado. | pídele a Claude «usa el subagente preparar-imprenta» |
| recortes-multiformato | Subagente | Una foto convertida en todas las versiones que necesitas sin perder el producto ni el texto. | pídele a Claude «usa el subagente recortes-multiformato» |
| redactor-alt-text | Subagente | Subagente que mira tus imágenes una a una y escribe el texto alternativo y el nombre de archivo correctos, para accesibilidad y para que Google entienda la foto. | pídele a Claude «usa el subagente redactor-alt-text» |
