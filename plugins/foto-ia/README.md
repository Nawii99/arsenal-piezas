# arsenal-foto-ia · Foto e imagen · Imágenes con IA

Foto e imagen · Imágenes con IA: 5 comandos /, 2 skills, 2 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-ia@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| arreglar-prompt-imagen | Comando / | Por qué falla tu prompt de imagen y qué cambiar para que salga lo que visualizas. | `/arreglar-prompt-imagen` o `/arsenal-foto-ia:arreglar-prompt-imagen` |
| elegir-creatividad | Comando / | Compara tus imágenes candidatas y te dice cuál publicar, con criterios de verdad y no de gusto personal. | `/elegir-creatividad` o `/arsenal-foto-ia:elegir-creatividad` |
| foto-producto | Comando / | Crea 4 prompts de imagen en inglés (catálogo, lifestyle, flat lay y anuncio) con plano, ángulo, lente, luz y medida por plataforma, explicados, y otra idea para el anuncio. | `/foto-producto` o `/arsenal-foto-ia:foto-producto` |
| foto-servicio-invisible | Comando / | Consigue imágenes para un negocio que no tiene producto que fotografiar: consultoría, formación, software, gestoría, servicios a distancia. | `/foto-servicio-invisible` o `/arsenal-foto-ia:foto-servicio-invisible` |
| iluminacion-foto | Comando / | Propone 6 esquemas de iluminación para tu producto, cada uno con su efecto, un prompt en inglés para IA y cómo hacerlo con luz real y el móvil. | `/iluminacion-foto` o `/arsenal-foto-ia:iluminacion-foto` |
| fotos-producto-ia | Skill | Aplica el lenguaje de la fotografía profesional a tus prompts de imagen: plano, ángulo, lente, luz, estilo y medida según dónde se publica, con plantilla y ejemplo. | se activa sola cuando hace falta |
| modelo-recurrente-ia | Skill | Consigue que el mismo personaje, modelo o mascota de marca aparezca reconocible en todas tus imágenes generadas. | se activa sola cuando hace falta |
| comparador-creatividades | Subagente | Monta la comparación entre varias versiones de una imagen, define cómo probarlas y te dice cuál gana y por qué. | pídele a Claude «usa el subagente comparador-creatividades» |
| director-de-fotografia | Subagente | Convierte tu producto en un set completo de fotos: prompts de imagen con IA en inglés con plano, lente, luz y medidas por plataforma, y cómo hacer cada foto con el móvil. | pídele a Claude «usa el subagente director-de-fotografia» |
