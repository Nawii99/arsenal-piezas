# arsenal-web-mantenimiento · Web · Mantenimiento de la web

Web · Mantenimiento de la web: 9 comandos /, 3 subagentes, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-web-mantenimiento@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| compartir-bonito | Comando / | Arregla cómo se ve el enlace de tu web cuando alguien lo pega en WhatsApp, Instagram, LinkedIn o Google: imagen, título, descripción y favicon. | `/compartir-bonito` |
| compartir-en-whatsapp | Comando / | Arregla cómo se ve tu enlace cuando alguien lo pega en WhatsApp, Instagram, LinkedIn o Google: imagen, título y descripción. | `/compartir-en-whatsapp` |
| conectar-mi-dominio | Comando / | Te lleva de la mano para conectar tu dominio a la web ya publicada, con https y correo, sin romper nada de lo que ya funciona. | `/conectar-mi-dominio` |
| dns-dominio | Comando / | Te guía para conectar tu dominio a tu web y montar el correo profesional, explicando cada registro DNS sin jerga. | `/dns-dominio` |
| enlaces-rotos | Comando / | Rastrea tu web y te dice qué enlaces, imágenes, botones y descargas están rotos o apuntan a donde no deben. | `/enlaces-rotos` |
| enlaces-rotos-y-redirecciones | Comando / | Encuentra los enlaces rotos de tu web y prepara las redirecciones cuando cambias de página, de dominio o reorganizas. | `/enlaces-rotos-y-redirecciones` |
| medir-visitas | Comando / | Instala analítica en tu web y define qué tres o cuatro cosas medir de verdad, para saber qué páginas traen clientes y cuáles sobran. | `/medir-visitas` |
| redirecciones-404 | Comando / | Prepara las redirecciones y la página de error cuando cambias direcciones de tu web, para no perder las visitas que ya venían de Google. | `/redirecciones-404` |
| web-lenta | Comando / | Encuentra por qué tu web tarda en cargar y te da la lista de arreglos ordenada por lo que más peso quita con menos esfuerzo. | `/web-lenta` |
| publicar-mi-web | Skill | Guía paso a paso para poner online una landing o cualquier HTML gratis en GitHub Pages, Cloudflare Pages, Netlify o Vercel, y conectar un dominio propio con SSL. | se activa sola cuando hace falta |
| auditor-velocidad-web | Subagente | Subagente que mide por qué tu web tarda en cargar, encuentra lo que pesa de más y lo arregla: imágenes, fuentes y scripts. | pídele a Claude «usa el subagente auditor-velocidad-web» |
| cazador-enlaces-rotos | Subagente | Subagente que rastrea toda tu web buscando enlaces rotos, imágenes que no cargan y páginas huérfanas, y te dice qué arreglar primero. | pídele a Claude «usa el subagente cazador-enlaces-rotos» |
| migrador-dominio-sin-perder-google | Subagente | Cambias de dominio sin perder posicionamiento en Google: inventario, redirecciones y checklist. | pídele a Claude «usa el subagente migrador-dominio-sin-perder-google» |
