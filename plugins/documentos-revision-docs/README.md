# arsenal-documentos-revision-docs · Documentos · Revisar y comparar documentos

Documentos · Revisar y comparar documentos: 5 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-documentos-revision-docs@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| revisor-documento-largo | Subagente | Revisa documento entero: numeración, índice, referencias cruzadas, estilo y coherencia. | pídele a Claude «usa el subagente revisor-documento-largo» |
| subagente-analista-de-pliegos-y-bases-de-concurso | Subagente | Subagente que se lee un pliego o unas bases largas y te saca la ficha corta: si puedes presentarte, qué documentos hacen falta, cómo puntúa y qué te deja fuera. | pídele a Claude «usa el subagente subagente-analista-de-pliegos-y-bases-de-concurso» |
| subagente-auditor-de-plantilla-de-marca-en-documentos | Subagente | Revisa tus documentos de Word y PowerPoint: dónde se rompieron tipografías, colores, márgenes, pies. | pídele a Claude «usa el subagente subagente-auditor-de-plantilla-de-marca-en-documentos» |
| subagente-comparador-de-versiones-de-contrato | Subagente | Subagente que compara dos versiones de un contrato o documento y te dice en cristiano qué ha cambiado, qué es cosmético y qué te puede costar dinero. | pídele a Claude «usa el subagente subagente-comparador-de-versiones-de-contrato» |
| subagente-verificador-de-cifras-antes-de-enviar | Subagente | Revisa un documento importante: cifras que no cuadran, fechas imposibles, huecos sin rellenar. | pídele a Claude «usa el subagente subagente-verificador-de-cifras-antes-de-enviar» |
