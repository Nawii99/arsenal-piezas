# arsenal-salud-habitos · Salud y deporte · Hábitos y entrenamiento

Salud y deporte · Hábitos y entrenamiento: 8 subagentes, 7 skills, 6 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-salud-habitos@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| lista-compra | Comando / | Convierte un menú semanal ya escrito, o unas recetas sueltas, en una lista de la compra agrupada por sección de supermercado, lista para marcar desde el móvil mientras se compra. | `/lista-compra` |
| lista-compra-semanal | Comando / | Comando que convierte un menú semanal ya hecho en una lista de la compra agrupada por secciones del súper, lista para copiar al móvil. | `/lista-compra-semanal` |
| plan-habito-cliente | Comando / | Diseña con tu cliente un plan de seis semanas para instalar un hábito, con el mínimo diario, los avisos y qué hacer cuando falla. | `/plan-habito-cliente` |
| plan-habitos-cliente | Comando / | El plan de hábitos de 4 semanas para que tus clientes mantengan cambios entre sesiones. | `/plan-habitos-cliente` |
| registro-entreno | Comando / | Comando que registra los datos de una sesión de entrenamiento y calcula el volumen total, para empezar a llevar seguimiento del progreso desde el primer día. | `/registro-entreno` |
| reto-habitos-21 | Comando / | Crea un programa de hábitos de 21 días para tus clientes, con seguimiento diario y mensajes ya escritos. | `/reto-habitos-21` |
| calculadora-macros-tdee | Skill | Calcula el gasto calórico diario y el reparto de macros de una persona a partir de sus datos, para no tener que hacer las cuentas a mano cada vez que cambia de objetivo o de peso. | se activa sola cuando hace falta |
| cuestionario-inicial-habitos | Skill | Diseña el cuestionario previo que rellena la persona antes de la primera sesión de coaching, nutrición o entrenamiento, con las banderas rojas que obligan a mandarla al médico. | se activa sola cuando hace falta |
| plan-de-habitos-skill-guiada | Skill | Plan de hábitos repetible: mismos principios, adaptado a ti. | se activa sola cuando hace falta |
| plan-entre-sesiones | Skill | Convierte las pautas que el profesional da en consulta en un plan de hábitos para casa que el paciente cumpla de verdad, con recordatorios y registro. | se activa sola cuando hace falta |
| plan-entrenamiento-principiante | Skill | Crea una rutina de entrenamiento básica de 4 a 8 semanas para alguien que empieza de cero, según su objetivo, su material y los días que puede entrenar de verdad. | se activa sola cuando hace falta |
| plan-entrenamiento-vendible | Skill | Genera un plan de entrenamiento personalizado y listo para entregar a un cliente de pago, a partir de sus datos y su objetivo. | se activa sola cuando hace falta |
| revisor-rutina-entrenamiento | Skill | Revisa una rutina de entrenamiento que te pase el usuario y señala los errores más comunes: falta de descanso entre grupos musculares, volumen mal calculado, sin progresión y desequilibrios. | se activa sola cuando hace falta |
| calculador-cargas | Subagente | Tu 1RM estimado, porcentajes de trabajo y progresión semana a semana para no estancarte. | pídele a Claude «usa el subagente calculador-cargas» |
| disenador-programa-habitos | Subagente | Empaqueta lo que ya haces con clientes en un programa de 4 semanas con material y seguimiento vendible. | pídele a Claude «usa el subagente disenador-programa-habitos» |
| plan-adherencia-habitos | Subagente | Diseña cómo seguir a un cliente 90 días para que no abandone en la semana tres: mensajes, hitos, registro. | pídele a Claude «usa el subagente plan-adherencia-habitos» |
| plan-de-habitos-subagente-revisor | Subagente | Hábitos auditados: objetivos realistas, rutina clara, señales de parada. | pídele a Claude «usa el subagente plan-de-habitos-subagente-revisor» |
| planificador-menu-semanal | Subagente | Subagente que diseña un menú semanal sencillo y realista ajustado a las calorías y macros objetivo de alguien que empieza de cero en nutrición. | pídele a Claude «usa el subagente planificador-menu-semanal» |
| revisor-adherencia-habitos | Subagente | Lee el registro de hábitos de un cliente y te dice dónde se rompe la rutina y qué ajuste probar. | pídele a Claude «usa el subagente revisor-adherencia-habitos» |
| seguimiento-progreso | Subagente | Varias sesiones de entrenamiento -> informe de evolución: cargas, volumen, constancia. Revisar con un especialista. | pídele a Claude «usa el subagente seguimiento-progreso» |
| seguimiento-progreso-cliente | Subagente | Revisa cada semana los datos de entrenamiento de un cliente, calcula si debe subir carga, mantenerla o bajarla, y prepara el mensaje para enviarselo. | pídele a Claude «usa el subagente seguimiento-progreso-cliente» |
