# arsenal-video-videocv · Vídeo · Vídeo currículum

Vídeo · Vídeo currículum: 3 subagentes, 2 skills, 2 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-video-videocv@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| guion-video-cv-2 | Comando / | Escribes el guion de presentación de un cliente de 60-90 segundos: apertura, qué cuenta, cierre con llamada a acción. | `/guion-video-cv-2` o `/arsenal-video-videocv:guion-video-cv-2` |
| guiones-en-lote-video-presentacion | Comando / | Escribe de una tacada los guiones de vídeo de presentación de toda una lista de personas, uno por archivo, con una hoja de control para revisarlos. | `/guiones-en-lote-video-presentacion` o `/arsenal-video-videocv:guiones-en-lote-video-presentacion` |
| grabar-videocv-movil | Skill | Skill de Claude Code que guía la grabación de un vídeo currículum con un móvil Android sin material extra: luz, sonido, encuadre, tomas y criterios para dar una toma por buena. | se activa sola cuando hace falta |
| servicio-video-curriculum | Skill | Convierte el vídeo currículum y el vídeo de presentación profesional en un servicio con packs, proceso, entrega y cobro. Se activa cuando quieres venderlo o presupuestarlo. | se activa sola cuando hace falta |
| guionista-video-corto-presentacion | Subagente | Subagente que escribe el guion de un vídeo corto de presentación personal o profesional y lo adapta a Reels, TikTok, Shorts y LinkedIn. | pídele a Claude «usa el subagente guionista-video-corto-presentacion» |
| revisor-toma-video-cv | Subagente | Le pasas la transcripción de lo que has grabado y te dice qué cortar, qué regrabar y qué dejar. Te ahorra ver la toma diez veces para decidirlo. | pídele a Claude «usa el subagente revisor-toma-video-cv» |
| revisor-videocv | Subagente | Subagente de Claude Code que revisa el guion, la transcripción o la descripción de un vídeo currículum como lo haría alguien de selección con prisa. | pídele a Claude «usa el subagente revisor-videocv» |
