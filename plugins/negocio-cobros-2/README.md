# arsenal-negocio-cobros-2 · Negocio · Cobros y facturas (2)

Negocio · Cobros y facturas (2): 19 subagentes, 2 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-cobros-2@arsenal
```
