# arsenal-foto-retrato · Foto e imagen · Retrato y marca

Foto e imagen · Retrato y marca: 5 comandos /, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-retrato@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| retrato-linkedin-cobrable | Comando / | Comando que monta el encargo completo de retrato profesional: qué pedir al cliente, cómo hacerlo con móvil o con IA, qué entregar y a qué precio. | `/retrato-linkedin-cobrable` o `/arsenal-foto-retrato:retrato-linkedin-cobrable` |
| retrato-marca-ia | Comando / | Te prepara los retratos profesionales de tu cara para web, LinkedIn y prensa a partir de selfies, sin que parezcas un muñeco de plástico. | `/retrato-marca-ia` o `/arsenal-foto-retrato:retrato-marca-ia` |
| retrato-perfil-sin-errores | Comando / | Guia paso a paso para conseguir una foto de perfil decente para LinkedIn o curriculum, con movil o con IA, evitando los fallos de siempre. | `/retrato-perfil-sin-errores` o `/arsenal-foto-retrato:retrato-perfil-sin-errores` |
| retrato-profesional | Comando / | Convierte selfies normales en un retrato decente para tu web, LinkedIn o ficha de Google, sin que parezca un muñeco de plástico. | `/retrato-profesional` o `/arsenal-foto-retrato:retrato-profesional` |
| retratos-de-marca | Comando / | Prepara la sesión de retratos tuya o de tu equipo, para perfil profesional y para la web, con coherencia entre todas las caras. | `/retratos-de-marca` o `/arsenal-foto-retrato:retratos-de-marca` |
| retrato-profesional-marca | Skill | Consigue una foto de perfil profesional para tu marca personal, ya sea haciéndola con el móvil o generándola con IA a partir de tus selfies. | se activa sola cuando hace falta |
