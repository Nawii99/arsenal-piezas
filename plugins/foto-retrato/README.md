# arsenal-foto-retrato · Foto e imagen · Retrato y marca

Foto e imagen · Retrato y marca: 7 comandos /, 2 skills, 2 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-retrato@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| retrato-linkedin-cobrable | Comando / | Comando que monta el encargo completo de retrato profesional: qué pedir al cliente, cómo hacerlo con móvil o con IA, qué entregar y a qué precio. | `/retrato-linkedin-cobrable` |
| retrato-marca-ia | Comando / | Te prepara los retratos profesionales de tu cara para web, LinkedIn y prensa a partir de selfies, sin que parezcas un muñeco de plástico. | `/retrato-marca-ia` |
| retrato-perfil-movil | Comando / | Guia paso a paso para sacar tu foto de perfil de LinkedIn o curriculum con el movil que ya tienes, y dejarla lista en las medidas correctas. | `/retrato-perfil-movil` |
| retrato-perfil-sin-errores | Comando / | Guia paso a paso para conseguir una foto de perfil decente para LinkedIn o curriculum, con movil o con IA, evitando los fallos de siempre. | `/retrato-perfil-sin-errores` |
| retrato-profesional | Comando / | Convierte selfies normales en un retrato decente para tu web, LinkedIn o ficha de Google, sin que parezca un muñeco de plástico. | `/retrato-profesional` |
| retratos-de-marca | Comando / | Prepara la sesión de retratos tuya o de tu equipo, para perfil profesional y para la web, con coherencia entre todas las caras. | `/retratos-de-marca` |
| sesion-movil-45min | Comando / | Te monta la sesión de fotos completa con el móvil y cosas de casa: montaje, ajustes y lista de tomas cronometrada. | `/sesion-movil-45min` |
| retrato-profesional-ia | Skill | Convierte tus selfies en retratos profesionales creíbles para web, LinkedIn o dossier, manteniendo tu cara reconocible. | se activa sola cuando hace falta |
| retrato-profesional-marca | Skill | Consigue una foto de perfil profesional para tu marca personal, ya sea haciéndola con el móvil o generándola con IA a partir de tus selfies. | se activa sola cuando hace falta |
| cortador-de-carruseles | Subagente | Cómo partir una imagen panorámica en diapositivas de carrusel que se entienda en móvil. | pídele a Claude «usa el subagente cortador-de-carruseles» |
| planificador-sesion-movil | Subagente | La sesión de fotos con el móvil minuto a minuto: qué necesitas, dónde te pones, en qué orden. | pídele a Claude «usa el subagente planificador-sesion-movil» |
