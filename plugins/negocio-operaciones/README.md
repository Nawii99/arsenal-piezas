# arsenal-negocio-operaciones · Negocio · Operaciones y equipo

Negocio · Operaciones y equipo: 7 subagentes, 6 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-operaciones@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| cierre-de-trimestre-informe-y-reunion | Skill | Reúne las cifras del trimestre, las compara con lo previsto, escribe el informe y la agenda de la reunión (interna, con un cliente o con inversores) y deja acuerdos con responsable y fecha. | se activa sola cuando hace falta |
| cierre-semanal-negocio | Skill | Repasa la semana de tu negocio (qué pasó, qué aprendiste y cuánto ingresaste) y termina con tres prioridades para la siguiente. | se activa sola cuando hace falta |
| hoja-pedido-compra-super-clientes | Skill | Convierte la lista de la compra que te manda un cliente en una hoja de pedido ordenada, con sustituciones acordadas, presupuesto y cuadre final con el ticket para cobrar con claridad. | se activa sola cuando hace falta |
| horas-presupuesto-proyectos-odoo | Skill | Revisa los partes de horas de Odoo, compara lo gastado con el presupuesto de cada proyecto, avisa de los que se desvían y prepara un borrador de lo que toca facturar. | se activa sola cuando hace falta |
| retomar-negocio | Skill | Lee los archivos donde guardaste el estado de tu negocio y te hace un resumen corto para empezar la sesión sin volver a explicarlo todo. | se activa sola cuando hace falta |
| revision-de-lineales-y-colocacion | Skill | Cruza las ventas de tu tienda con el espacio que ocupa cada producto y propone pocos cambios de colocación, con una forma de medir si han funcionado. | se activa sola cuando hace falta |
| entrenador-de-liderazgo-practico | Subagente | Entrena una conversación o una habilidad de liderazgo concreta con guion, ensayo y plan de dos semanas, a partir de una situación real de tu equipo. | pídele a Claude «usa el subagente entrenador-de-liderazgo-practico» |
| hoja-ruta-tres-versiones | Subagente | Ordena ideas y peticiones en una hoja de ruta con prioridades razonadas y la escribe en tres versiones: dirección, equipo técnico y clientes. | pídele a Claude «usa el subagente hoja-ruta-tres-versiones» |
| impulsar-cambio-en-la-organizacion | Subagente | Prepara el terreno para una idea nueva dentro de una organización con mapa de afectados, objeciones, piloto pequeño y propuesta de una página para quien decide. | pídele a Claude «usa el subagente impulsar-cambio-en-la-organizacion» |
| registro-riesgos-proyecto | Subagente | Detecta los riesgos de un proyecto, los puntúa y deja un registro con medidas para evitarlos, señales de aviso y plan B. | pídele a Claude «usa el subagente registro-riesgos-proyecto» |
| reparto-de-tareas-por-habilidades-y-agenda | Subagente | Propone quién hace cada tarea de un proyecto según las habilidades y las horas libres que le des, avisa de sobrecargas y deja la decisión final a quien dirige el equipo. | pídele a Claude «usa el subagente reparto-de-tareas-por-habilidades-y-agenda» |
| resumen-para-decidir | Subagente | Condensa informes, cifras y notas en un resumen de una página para inversores, bancos, socios o dirección que dice qué se pide, por qué y qué riesgos hay. | pídele a Claude «usa el subagente resumen-para-decidir» |
| ruta-huella-pyme | Subagente | Revisa los consumos y hábitos de un negocio pequeño y devuelve una lista ordenada de acciones para reducir su impacto ambiental, con coste, esfuerzo y forma de medir cada una. | pídele a Claude «usa el subagente ruta-huella-pyme» |
