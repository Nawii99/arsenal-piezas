# arsenal-web-legal · Web · Legal, privacidad y accesibilidad

Web · Legal, privacidad y accesibilidad: 11 comandos /, 4 subagentes, 4 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-web-legal@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| accesibilidad-web | Comando / | Revisa tu web para que la pueda usar cualquiera: contraste, textos alternativos, navegación con teclado y formularios entendibles. | `/accesibilidad-web` |
| accesible-de-verdad | Comando / | Revisa que tu web se pueda usar con el móvil al sol, con el teclado y por personas mayores o con poca vista, y lo arregla. | `/accesible-de-verdad` |
| auditoria-legal-web | Comando / | Revisa aviso legal, privacidad, cookies, formularios, tienda y accesibilidad de una web española y devuelve un informe por riesgo que sirve como diagnóstico para vender el arreglo. | `/auditoria-legal-web` |
| cookies-y-legales | Comando / | Genera las páginas legales y el aviso de cookies de tu web en España: aviso legal, privacidad, cookies y el banner que de verdad bloquea hasta que aceptan. | `/cookies-y-legales` |
| formulario-que-llega | Comando / | Monta o repara el formulario de contacto de tu web para que los mensajes te lleguen de verdad al correo, sin servidor ni cuotas, y con filtro antispam. | `/formulario-que-llega` |
| formulario-que-si-llega | Comando / | Monta un formulario de contacto que de verdad te envíe los mensajes al correo, sin servidor ni programación de backend. | `/formulario-que-si-llega` |
| medir-lo-que-importa | Comando / | Instala una medición sencilla de tu web y define los tres números que de verdad te dicen si funciona. | `/medir-lo-que-importa` |
| paginas-legales-web | Comando / | Genera los textos legales que necesita una web en España (aviso legal, privacidad, cookies) adaptados a tu caso real. | `/paginas-legales-web` |
| revision-web-con-formularios | Comando / | Comando de Claude Code (un archivo .md en .claude/commands) que revisa en solo lectura una web con formularios antes de publicarla: formularios, cookies, datos personales, textos legales y seguridad básica. | `/revision-web-con-formularios` |
| textos-legales-web | Comando / | Genera el borrador de aviso legal, política de privacidad y política de cookies de una web española a partir de unas pocas preguntas. Marca lo que un profesional debe revisar. | `/textos-legales-web` |
| textos-legales-web-2 | Comando / | Redacta aviso legal, política de privacidad, política de cookies, texto de primera capa para formularios y textos del banner a partir de los datos del negocio. | `/textos-legales-web-2` |
| auditoria-de-una-web-skill-guiada | Skill | Auditoría de web como rutina: siempre el mismo estándar de mejora. | se activa sola cuando hace falta |
| auditoria-legal-web | Skill | Revisa en 20 minutos si una web cumple lo mínimo en aviso legal, formularios, privacidad, cookies, venta online y accesibilidad obligatoria. | se activa sola cuando hace falta |
| revision-legal-web-publicada | Skill | Revisa una web ya publicada y devuelve una lista de lo que falta o está mal en aviso legal, privacidad, cookies, formularios y accesibilidad. Pensada para quien no es abogado. | se activa sola cuando hace falta |
| textos-legales-web | Skill | Redacta aviso legal, privacidad, cookies y condiciones de contratación con los datos reales del titular, dice dónde colocar cada cosa y cómo venderlo como servicio sin ser abogado. | se activa sola cuando hace falta |
| accesibilidad-web-esencial | Subagente | Revisa que ciegos, mayores y gente con discapacidad naveguen tu web sin problemas: contraste, accesos, formularios. | pídele a Claude «usa el subagente accesibilidad-web-esencial» |
| analitica-y-cookies-legal | Subagente | Monta la analítica de tu web conforme al RGPD: qué medir, cómo instalarlo y qué aviso de cookies necesitas. | pídele a Claude «usa el subagente analitica-y-cookies-legal» |
| auditoria-de-una-web-subagente-revisor | Subagente | Tu web auditada por un especialista: puntos débiles, cambios verificables. | pídele a Claude «usa el subagente auditoria-de-una-web-subagente-revisor» |
| reparador-formularios-web | Subagente | Subagente que arregla el formulario de contacto de tu web: que envíe, que te llegue el correo, que no te entre spam y que el visitante sepa que se ha enviado. | pídele a Claude «usa el subagente reparador-formularios-web» |
