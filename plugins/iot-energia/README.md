# arsenal-iot-energia · IoT y hardware · Energía, baterías y consumo

IoT y hardware · Energía, baterías y consumo: 3 skills, 2 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-iot-energia@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| auditar-consumo-electrico | Comando / | Analiza el consumo de los enchufes inteligentes de una casa o local, señala qué aparatos se comen la factura y qué automatizar para bajarla. | `/auditar-consumo-electrico` o `/arsenal-iot-energia:auditar-consumo-electrico` |
| autonomia-pilas | Comando / | Calcula cuánto van a durar las pilas de un sensor inalámbrico y qué cambiar para que duren el doble, con los números a la vista. | `/autonomia-pilas` o `/arsenal-iot-energia:autonomia-pilas` |
| cableado-y-alimentacion | Skill | Dimensiona la alimentación y el cableado de una instalación de sensores: fuentes, caída de tensión, PoE y qué cable usar en cada tramo. | se activa sola cuando hace falta |
| dimensionar-nodo-autonomo | Skill | Calcula batería, panel solar y ciclo de envío para que un sensor sin enchufe aguante meses o años sin visitas. | se activa sola cuando hace falta |
| medir-ahorro-electrico-real | Skill | Mide el consumo real de tus aparatos y calcula si un cambio se paga solo, con tu tarifa y sin cuentos. | se activa sola cuando hace falta |
