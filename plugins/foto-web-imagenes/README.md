# arsenal-foto-web-imagenes · Foto e imagen · Imágenes para la web y SEO

Foto e imagen · Imágenes para la web y SEO: 3 subagentes, 3 comandos /, 2 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-web-imagenes@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| imagenes-web-ligeras | Comando / | Deja las fotos de tu web ligeras y bien nombradas para que la página cargue rápido y Google las entienda, sin programas de pago. | `/imagenes-web-ligeras` o `/arsenal-foto-web-imagenes:imagenes-web-ligeras` |
| optimizar-imagenes-web | Comando / | Revisa las imágenes de tu web, te dice cuáles pesan de más y te da los comandos exactos para dejarlas ligeras sin que pierdan calidad. | `/optimizar-imagenes-web` o `/arsenal-foto-web-imagenes:optimizar-imagenes-web` |
| seo-imagenes | Comando / | Prepara los nombres de archivo, los textos alternativos y el marcado de tus imágenes para que traigan visitas desde Google. | `/seo-imagenes` o `/arsenal-foto-web-imagenes:seo-imagenes` |
| optimizar-imagenes-web-skill | Skill | Convierte tus fotos en imágenes web ligeras y nítidas: tamaños, formatos, compresión y el HTML correcto para que la página cargue rápida. | se activa sola cuando hace falta |
| seo-imagenes-skill | Skill | Prepara nombres de archivo, textos alternativos y datos de tus imágenes para que aparezcan en Google Imágenes y ayuden a posicionar la página. | se activa sola cuando hace falta |
| auditor-imagenes-web | Subagente | Revisa todas las imágenes de tu web o tienda y te dice cuáles pesan de más, están mal cortadas o sin texto alternativo, con la lista de arreglos. | pídele a Claude «usa el subagente auditor-imagenes-web» |
| optimizador-imagenes-web | Subagente | De imágenes pesadas de 5 MB a una web que carga rápido: tamaños, WebP, srcset. | pídele a Claude «usa el subagente optimizador-imagenes-web» |
| redactor-alt-y-nombres | Subagente | Subagente que escribe el texto alternativo y el nombre de archivo de todas las imágenes de tu web: accesibles, útiles y bien vistos por Google. | pídele a Claude «usa el subagente redactor-alt-y-nombres» |
