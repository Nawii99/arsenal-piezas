# arsenal-juegos-varios-1 · Videojuegos y 3D · Más de videojuegos y 3d (1)

Videojuegos y 3D · Más de videojuegos y 3d (1): 16 skills, 3 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-juegos-varios-1@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| balance-economia | Comando / | Ajusta los números de tu juego (vidas, monedas, precios, subidas de nivel) para que no se haga aburrido ni imposible. | `/balance-economia` |

| visor-3d-web | Comando / | El código de un visor 3D interactivo con AR para girar productos en tu web de muebles o joyería. | `/visor-3d-web` |

| configurador-3d-producto | Skill | Monta un visor 3D interactivo en tu web para que el cliente gire el producto y elija color o acabado antes de comprar. | se activa sola cuando hace falta |
