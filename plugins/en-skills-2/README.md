# arsenal-en-skills-2

Arsenal del Marketer in English: 20 skills (part 2 of 2) for marketing, sales, design and small business.

## Install

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-en-skills-2@arsenal
```
