# arsenal-iot · IoT y hardware

IoT y hardware: 38 skills, 37 subagentes, 33 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-iot@arsenal
```
