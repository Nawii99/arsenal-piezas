# arsenal-movil-web-movil · Móvil · Web y formularios en el móvil

Móvil · Web y formularios en el móvil: 2 subagentes, 2 comandos /, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-movil-web-movil@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| enlaces-que-abren-app | Comando / | Crea los enlaces que abren directamente WhatsApp, el mapa, el teléfono o una pantalla concreta de tu app desde un QR, un anuncio o un botón. | `/enlaces-que-abren-app` o `/arsenal-movil-web-movil:enlaces-que-abren-app` |
| movil-rapido | Comando / | Diagnostica por qué tu web o tienda va lenta en el móvil con datos móviles y te da los arreglos ordenados por lo que más peso quita. | `/movil-rapido` o `/arsenal-movil-web-movil:movil-rapido` |
| auditoria-movil-web | Skill | Por qué tu web pierde gente en el móvil y qué arreglas primero. | se activa sola cuando hace falta |
| auditor-formularios-y-teclado-movil | Subagente | Revisa tus formularios y tu proceso de compra en el móvil: teclados, autorrellenado, errores y el botón que tapa el teclado. | pídele a Claude «usa el subagente auditor-formularios-y-teclado-movil» |
| enlaces-que-abren-tu-app | Subagente | Monta enlaces profundos: un QR, un enlace o un anuncio abre la pantalla exacta de tu app. | pídele a Claude «usa el subagente enlaces-que-abren-tu-app» |
