# arsenal-negocio-estrategia-3 · Negocio · Plan y estrategia (3)

Negocio · Plan y estrategia (3): 22 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-estrategia-3@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|

| mapa-previo-riesgos-regulatorios | Subagente | Hace un mapa previo de las normas que pueden afectar a tu producto o a tu entrada en otro mercado y prepara el dossier de preguntas para tu abogado; no es asesoramiento jurídico. | pídele a Claude «usa el subagente mapa-previo-riesgos-regulatorios» |
