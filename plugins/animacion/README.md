# arsenal-animacion · Webs animadas

Webs animadas: 7 skills, 3 subagentes, 2 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-animacion@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| conceptos-logo-animado | Comando / | Propone tres conceptos de animación distintos para un logo que le describes, con el porqué de cada uno, una tabla comparativa y una recomendación. | `/conceptos-logo-animado` o `/arsenal-animacion:conceptos-logo-animado` |
| revisar-animaciones-web | Comando / | Revisa el CSS o la descripción de las animaciones de una página y devuelve problemas de rendimiento y accesibilidad con su arreglo en una tabla. | `/revisar-animaciones-web` o `/arsenal-animacion:revisar-animaciones-web` |
| alcance-de-un-encargo-de-animacion | Skill | Define el alcance de un encargo de animación: entregables, formatos, rondas, plazos y derechos de uso, y enseña a calcular el precio con tus horas y tarifa. | se activa sola cuando hace falta |
| animar-ilustraciones-y-fotos-con-ia-de-imagen-a-video | Skill | Prepara la imagen y la petición para animar ilustraciones y fotos con un generador de vídeo con IA, mantiene al personaje igual entre planos y revisa el clip. | se activa sola cuando hace falta |
| brief-de-animacion-de-logo-para-cortinillas | Skill | Convierte un logo y la personalidad de una marca en un brief de animación para cortinillas: concepto, movimiento, duración, sonido y entregas. | se activa sola cuando hace falta |
| decidir-donde-animar-en-una-web | Skill | Decide qué animaciones de una web ayudan y cuáles estorban: propósito, duración, peso, alternativa con movimiento reducido y cómo pedirla o implementarla. | se activa sola cuando hace falta |
| planificar-pieza-animada-para-redes | Skill | Planifica un reel, story o anuncio con texto en movimiento: gancho, ritmo segundo a segundo, texto legible, zonas seguras y versión sin sonido. | se activa sola cuando hace falta |
| video-explicativo-animado-del-problema-al-storyboard | Skill | Convierte el problema de un cliente en el guion y el storyboard plano a plano de un vídeo explicativo animado de 60 a 90 segundos, con mensaje único y tiempos. | se activa sola cuando hace falta |
| web-animada-con-criterio-skill-guiada | Skill | Cada animación de web pasa por el mismo proceso: mapeo de impacto, especificación técnica, medición de velocidad. | se activa sola cuando hace falta |
| director-de-movimiento | Subagente | Propone el sistema de animación de una pantalla descrita: qué se mueve, cuánto dura, con qué curva y qué pasa con movimiento reducido, en una tabla coherente. | pídele a Claude «usa el subagente director-de-movimiento» |
| revisor-de-pieza-animada | Subagente | Revisa una pieza animada ya hecha a partir de su descripción plano a plano o de capturas y señala fallos de legibilidad, ritmo y accesibilidad con su arreglo. | pídele a Claude «usa el subagente revisor-de-pieza-animada» |
| web-animada-con-criterio-subagente-revisor | Subagente | Cuéntale qué quieres animar, te devuelve especificación técnica, piezas animadas con código y medición de rendimiento. | pídele a Claude «usa el subagente web-animada-con-criterio-subagente-revisor» |
