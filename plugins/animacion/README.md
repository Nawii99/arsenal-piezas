# arsenal-animacion · Webs animadas

Webs animadas: 1 skill, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-animacion@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| web-animada-con-criterio-skill-guiada | Skill | Cada animación de web pasa por el mismo proceso: mapeo de impacto, especificación técnica, medición de velocidad. | se activa sola cuando hace falta |
| web-animada-con-criterio-subagente-revisor | Subagente | Cuéntale qué quieres animar, te devuelve especificación técnica, piezas animadas con código y medición de rendimiento. | pídele a Claude «usa el subagente web-animada-con-criterio-subagente-revisor» |
