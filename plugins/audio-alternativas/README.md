# arsenal-audio-alternativas · Música y audio · Alternativas

Música y audio · Alternativas: 3 comandos /, 2 skills en español que se parecen a otras piezas de música y audio; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-audio-alternativas@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| letra-cancion | Comando / | Comando para escribir la letra completa de una canción (versos, estribillo, puente) a partir de un tema, un estilo y un idioma, lista para llevar a un generador de música o a un cantante. | `/letra-cancion` o `/arsenal-audio-alternativas:letra-cancion` |
| notas-episodio | Comando / | Convierte la transcripción o tus apuntes del episodio en título, descripciones para Spotify y YouTube, capítulos y frases para redes. | `/notas-episodio` o `/arsenal-audio-alternativas:notas-episodio` |
| notas-episodio-2 | Comando / | Comando de Claude Code que lee la transcripción de un episodio y genera el paquete de textos que entregas a un cliente: título, descripción, capítulos, citas y post para redes. | `/notas-episodio-2` o `/arsenal-audio-alternativas:notas-episodio-2` |
| asiento-skill-audio | Skill | Skill que ordena el arreglo de una grabación de voz mala: qué problema se ataca primero, con qué herramienta, y qué parte del audio directamente no tiene arreglo y hay que regrabar. | se activa sola cuando hace falta |
| separar-pistas-audio | Skill | Skill que explica cómo aislar la voz, la música o instrumentos concretos de una canción con herramientas de IA, para hacer karaoke, remixes o sacar una pista suelta. | se activa sola cuando hace falta |
