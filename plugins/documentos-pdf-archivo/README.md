# arsenal-documentos-pdf-archivo · Documentos · Escaneos, PDF y archivo

Documentos · Escaneos, PDF y archivo: 6 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-documentos-pdf-archivo@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| anonimizar-documentos | Subagente | Subagente que quita nombres, DNI, teléfonos y datos personales de un documento para que lo puedas compartir, publicar o usar de ejemplo. | pídele a Claude «usa el subagente anonimizar-documentos» |
| montar-expediente-pdf | Subagente | Subagente que junta un montón de documentos sueltos en un único PDF ordenado, con portada, índice y páginas numeradas. | pídele a Claude «usa el subagente montar-expediente-pdf» |
| ocr-y-archivar-escaneos | Subagente | Convierte escaneos de papeles en PDFs con texto buscable, renombrados con criterio, ordenados. | pídele a Claude «usa el subagente ocr-y-archivar-escaneos» |
| subagente-archivador-y-renombrador-de-ficheros | Subagente | Subagente que pone orden en una carpeta caótica de documentos: nombres coherentes, estructura de carpetas, duplicados fuera e índice para encontrar todo. | pídele a Claude «usa el subagente subagente-archivador-y-renombrador-de-ficheros» |
| subagente-digitalizar-papeles-escaneados | Subagente | Convierte escaneos y fotos en PDFs con texto buscable: controla la calidad del reconocimiento. | pídele a Claude «usa el subagente subagente-digitalizar-papeles-escaneados» |
| subagente-preparar-pdf-para-imprenta | Subagente | Revisa tu PDF antes de imprimir: sangrado, márgenes, resolución, fuentes, color, qué pedir a la imprenta. | pídele a Claude «usa el subagente subagente-preparar-pdf-para-imprenta» |
