# arsenal-empleo-portfolio · Empleo y currículum · Portfolio, web y perfiles online

Empleo y currículum · Portfolio, web y perfiles online: 4 comandos /, 4 skills, 1 subagente en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-empleo-portfolio@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| cv-una-pagina-html | Comando / | Comando para Claude Code que genera tu currículum de una página en un solo archivo HTML, listo para abrir en el navegador e imprimir a PDF. Sin instalar nada. | `/cv-una-pagina-html` o `/arsenal-empleo-portfolio:cv-una-pagina-html` |
| perfil-github | Comando / | Ordena tus repositorios de GitHub y escribe los README que un reclutador lee de verdad, para que tu perfil sostenga lo que dice tu LinkedIn. | `/perfil-github` o `/arsenal-empleo-portfolio:perfil-github` |
| portfolio-3d | Comando / | Genera tu portfolio en una sola pagina con secciones que se animan al bajar, en 3D ligero o solo CSS, y en un unico archivo listo para publicar. | `/portfolio-3d` o `/arsenal-empleo-portfolio:portfolio-3d` |
| portfolio-web | Comando / | Elige y ordena tus proyectos, redacta los textos y te da el index.html completo, con los pasos para publicarlo gratis en GitHub Pages y los README. | `/portfolio-web` o `/arsenal-empleo-portfolio:portfolio-web` |
| cv-web-desde-pdf | Skill | Convierte un currículum en PDF, Word o texto plano en una página web de una sola pantalla, lista para compartir por enlace, sin maquetar nada a mano. | se activa sola cuando hace falta |
| elegir-proyectos-portfolio | Skill | Decide que proyectos ensenas en el portfolio y en que orden, segun la oferta concreta a la que postulas. Y cuales conviene esconder. | se activa sola cuando hace falta |
| generador-curriculum-web | Skill | Convierte los datos de una persona en una página de currículum y portfolio de una sola pantalla, lista para publicar gratis en GitHub Pages o Netlify. | se activa sola cuando hace falta |
| linkedin-titular-acerca-de | Skill | Reescribe el titular y el apartado "acerca de" de LinkedIn para que un reclutador entienda en seis segundos que puesto buscas y por que vales. | se activa sola cuando hace falta |
| revisor-cv-web | Subagente | Subagente que audita una página de currículum o portfolio ya hecha, por URL o código, y devuelve una lista de mejoras priorizada por impacto, sin esperar a que otra persona dé su opinión. | pídele a Claude «usa el subagente revisor-cv-web» |
