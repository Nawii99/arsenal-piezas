# arsenal-educacion-alumnos · Formación · Alumnos y seguimiento

Formación · Alumnos y seguimiento: 10 skills, 8 comandos /, 7 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-educacion-alumnos@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| bajar-el-nivel | Comando / | Coge un texto técnico o denso y lo reescribe para el nivel real de tus alumnos, con analogías y escalera de conceptos. | `/bajar-el-nivel` |
| guion-tutoria | Comando / | Prepara la sesión de tutoría o mentoría uno a uno: qué preguntar, cómo repartir el tiempo y qué acta enviar después. | `/guion-tutoria` |
| primeros-7-dias | Comando / | Monta la bienvenida y los siete primeros días de un alumno para que empiece, avance y no deje el curso aparcado. | `/primeros-7-dias` |
| primeros-siete-dias | Comando / | Diseña la bienvenida y los 7 primeros días del alumno para que empiece el curso de verdad y no lo deje aparcado. | `/primeros-siete-dias` |
| rescatar-abandonos | Comando / | Detecta a los alumnos que dejaron el curso a medias y escribe el mensaje de reenganche según por dónde lo dejaron. | `/rescatar-abandonos` |
| rescate-abandonos | Comando / | Detecta en qué punto exacto se te caen los alumnos de un curso y te monta la secuencia de mensajes para reengancharlos. | `/rescate-abandonos` |
| rescate-alumnos | Comando / | Detecta a los alumnos parados y prepara los mensajes y el plan para reengancharlos antes de que pidan la devolución o desaparezcan. | `/rescate-alumnos` |
| testimonios-alumnos | Comando / | Te guía para entrevistar a un alumno y convertir su experiencia en un caso de éxito y testimonios que puedas usar para vender. | `/testimonios-alumnos` |
| cuaderno-de-trabajo-alumno | Skill | Diseña el cuaderno de ejercicios descargable que acompaña a tu formación: hojas de trabajo, ejemplos resueltos y criterios de hecho. | se activa sola cuando hace falta |
| microleccion-en-video | Skill | Guiona una vídeo-lección corta de 5-8 minutos con un solo objetivo: gancho, explicación, demostración en pantalla, resumen y ejercicio. | se activa sola cuando hace falta |
| onboarding-alumno | Skill | Diseña los primeros 7 días del alumno tras la compra: mensajes, primera victoria y comprobaciones para que empiece de verdad. | se activa sola cuando hace falta |
| primeros-7-dias-del-alumno | Skill | Monta la bienvenida y los primeros 7 días de un alumno nuevo para que empiece, tenga una victoria rápida y no se quede parado. | se activa sola cuando hace falta |
| prueba-de-nivel-e-itinerarios | Skill | Crea la prueba de nivel de entrada de tu formación y los itinerarios para que cada alumno empiece por donde le toca. | se activa sola cuando hace falta |
| rescatar-alumnos-parados | Skill | Por qué tus alumnos se quedan a mitad de camino y cómo traerlos de vuelta. | se activa sola cuando hace falta |
| rescate-abandono | Skill | Detecta en qué punto exacto abandonan tus alumnos y te da el plan y los mensajes para reengancharlos. | se activa sola cuando hace falta |
| rescate-alumnos-parados | Skill | Detecta a los alumnos que se han quedado parados y te escribe la secuencia de mensajes para reengancharlos antes de que pidan la devolución o desaparezcan. | se activa sola cuando hace falta |
| sesion-de-mentoria-1a1 | Skill | Estructura una sesión de mentoría o tutoría individual: preparación, guion de la hora, acta con compromisos y seguimiento entre sesiones. | se activa sola cuando hace falta |
| test-nivel-inicial | Skill | Monta el test de nivel que pasas antes de empezar, para saber qué sabe cada alumno, colocarlo en el punto correcto y evitar que abandone por aburrimiento o por atasco. | se activa sola cuando hace falta |
| alumno-critico-de-pruebas | Subagente | Subagente que se hace pasar por tu alumno más despistado, recorre tu material paso a paso y te dice exactamente dónde se atasca. | pídele a Claude «usa el subagente alumno-critico-de-pruebas» |
| corrector-entregas-feedback | Subagente | Corrige las entregas de tus alumnos con la rúbrica, redacta el feedback personalizado y te avisa de quién necesita ayuda. | pídele a Claude «usa el subagente corrector-entregas-feedback» |
| entrenador-de-roleplay | Subagente | Hace de cliente difícil en un simulacro: la persona practica hablando y sale el feedback exacto. | pídele a Claude «usa el subagente entrenador-de-roleplay» |
| prueba-nivel-diagnostica | Subagente | Crea la prueba de nivel que sitúa a cada alumno antes de empezar, con corrección automática y recomendación de por dónde debe entrar. | pídele a Claude «usa el subagente prueba-nivel-diagnostica» |
| rescate-abandono-curso | Subagente | Analiza los datos de progreso de tus alumnos, encuentra dónde se caen y te da el plan y los mensajes para recuperarlos. | pídele a Claude «usa el subagente rescate-abandono-curso» |
| rescate-de-alumnos | Subagente | Monta el sistema para que no abandonen: señales de riesgo, mensajes por hito, plan de recuperación. | pídele a Claude «usa el subagente rescate-de-alumnos» |
| rescate-de-alumnos-parados | Subagente | Subagente que mira los datos de progreso de tu curso, detecta quién se ha quedado atascado y escribe los mensajes exactos para recuperarlo antes de que pida devolución. | pídele a Claude «usa el subagente rescate-de-alumnos-parados» |
