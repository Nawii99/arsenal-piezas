# arsenal-juegos-assets-2 · Videojuegos y 3D · Modelos, texturas y assets (2)

Videojuegos y 3D · Modelos, texturas y assets (2): 10 subagentes, 7 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-juegos-assets-2@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| publicar-build-web-itch | Skill | Empaqueta tu juego para navegador y lo publica en itch.io: ajustes de exportación, tamaño de ventana, compresión y los fallos que dejan la pantalla en negro. | se activa sola cuando hace falta |
| publicar-pack-assets-3d | Skill | Prepara y publica un pack de modelos 3D para venderlo en tiendas de assets, con los requisitos técnicos que piden. | se activa sola cuando hace falta |
| revisar-licencias-assets | Skill | Revisa si los assets (arte, música, sonido, fuentes, código) que usas en tu juego tienen licencia para venderlo, y qué exige cada tipo. Para quien empieza y no distingue licencias. | se activa sola cuando hace falta |
| revisor-licencias-assets | Skill | Revisa las licencias de los assets (arte, musica, sonido, codigo, fuentes) que usa tu juego y te dice si puedes venderlo sin riesgo legal. | se activa sola cuando hace falta |
| rig-personaje-para-animar | Skill | Prepara un personaje 3D para que se anime solo con Mixamo o animaciones compradas, y arregla los fallos típicos de deformación. | se activa sola cuando hace falta |
| stl-impresion-3d | Skill | Prepara un modelo 3D para que se imprima bien y se pueda vender como archivo: grosores, escala, cortes, soportes y comprobaciones. | se activa sola cuando hace falta |
| texturas-pbr-revision | Skill | Revisa por qué tus materiales 3D se ven de plástico o apagados y te da la corrección concreta mapa por mapa. | se activa sola cuando hace falta |
| auditor-licencias-assets | Subagente | Revisa de dónde sale cada asset y si los puedes usar comercialmente; te deja el fichero de créditos. | pídele a Claude «usa el subagente auditor-licencias-assets» |
| auditor-licencias-de-assets | Subagente | Revisa qué has metido en tu juego para saber qué puedes publicar sin que te traiga problemas. Consulta legales si tomas decisiones finales. | pídele a Claude «usa el subagente auditor-licencias-de-assets» |
| devlog-y-clips-progreso | Subagente | Subagente que mira lo que has avanzado de verdad en el proyecto y te saca el devlog y los clips para redes, sin inventarse nada. | pídele a Claude «usa el subagente devlog-y-clips-progreso» |
| empaquetador-pack-3d-venta | Subagente | Organiza tus modelos en un pack vendible: carpetas, formatos, previews y README listos para publicar. | pídele a Claude «usa el subagente empaquetador-pack-3d-venta» |
| guardian-proyecto-unity | Subagente | Subagente que ordena tu proyecto de Unity o Unreal para que no pese una barbaridad, se guarde bien en la nube y no pierdas trabajo. | pídele a Claude «usa el subagente guardian-proyecto-unity» |
| optimizador-glb-web | Subagente | Optimiza modelos 3D para web: reduce peso manteniendo calidad para que carguen rápido en móvil. | pídele a Claude «usa el subagente optimizador-glb-web» |
| preparador-assets-motor | Subagente | Revisa tus modelos antes de importarlos: escala, pivote, nombres y UVs para que entren correctos. | pídele a Claude «usa el subagente preparador-assets-motor» |
| presupuestador-encargos-3d | Subagente | Convierte el encargo confuso en un presupuesto con alcance, entregables y condiciones cerradas. | pídele a Claude «usa el subagente presupuestador-encargos-3d» |
| publicador-build-itch | Subagente | Prepara y sube tu build a itch.io comprimida, por canales, y sin líos en la ficha de presentación. | pídele a Claude «usa el subagente publicador-build-itch» |
| renderizador-blender-lote | Subagente | Genera decenas de renders de tu modelo en lote: ángulos, colores, fondos sin tocar la interfaz. | pídele a Claude «usa el subagente renderizador-blender-lote» |
