# arsenal-iot-sensores-2 · IoT y hardware · Sensores y cámaras (2)

IoT y hardware · Sensores y cámaras (2): 10 subagentes, 3 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-iot-sensores-2@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| sensor-esphome-diy | Skill | El fichero listo para convertir una placa barata en un sensor propio: temperatura o humedad. | se activa sola cuando hace falta |
| sensores-y-camaras-cumpliendo-rgpd | Skill | Qué cámaras y sensores puedes instalar en tu local legalmente (revísalo con un abogado). | se activa sola cuando hace falta |
| videovigilancia-y-datos | Skill | Revisa que una instalación de cámaras o sensores cumpla lo básico de protección de datos: dónde apuntan, carteles, plazos y accesos. | se activa sola cuando hace falta |
| auditor-privacidad-camaras | Subagente | Revisa dónde van las cámaras de un negocio y deja la instalación en orden legal y técnico. Consulta si es decisión final. | pídele a Claude «usa el subagente auditor-privacidad-camaras» |
| autonomia-sensor-a-pilas | Subagente | Calcula cuánto durará la pila de tu sensor inalámbrico y qué cambiar para que dure meses. | pídele a Claude «usa el subagente autonomia-sensor-a-pilas» |
| calculadora-autonomia-bateria | Subagente | Calcula cuánto durará tu sensor a pilas o con panel solar y qué cambiar para que dure el triple. | pídele a Claude «usa el subagente calculadora-autonomia-bateria» |
| calculo-autonomia-sensor | Subagente | Calcula cuánto va a durar la pila de un sensor y qué ajustes hacen que dure el triple. | pídele a Claude «usa el subagente calculo-autonomia-sensor» |
| detective-falsas-alarmas | Subagente | Subagente que investiga por qué tu automatización se dispara sola o no se dispara, y te devuelve la regla corregida. | pídele a Claude «usa el subagente detective-falsas-alarmas» |
| diagnostico-iot | Subagente | Tu cámara, sensor o riego dejó de funcionar. Te guía paso a paso antes de que compres nada: alimentación, WiFi, configuración. | pídele a Claude «usa el subagente diagnostico-iot» |
| escritor-esphome | Subagente | Escribe la configuración YAML de ESPHome para tu sensor o control, ya calibrada y comentada. | pídele a Claude «usa el subagente escritor-esphome» |
| revisor-riego-automatico | Subagente | Es un subagente que revisa la lista de piezas, el esquema y el código de un riego automático casero (ESP32, sensor de humedad, relé, bomba) antes de dejarlo funcionando solo. | pídele a Claude «usa el subagente revisor-riego-automatico» |
| seleccionador-componentes | Subagente | Subagente que elige los componentes de tu prototipo electrónico, saca la lista de compra con alternativas y detecta lo que no encaja. | pídele a Claude «usa el subagente seleccionador-componentes» |
| traductor-de-datasheet | Subagente | Lee la hoja de datos de un sensor y te da conexionado, avisos de tensión y código mínimo que funciona. | pídele a Claude «usa el subagente traductor-de-datasheet» |
