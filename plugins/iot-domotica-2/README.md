# arsenal-iot-domotica-2 · IoT y hardware · Domótica (2)

IoT y hardware · Domótica (2): 16 subagentes, 3 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-iot-domotica-2@arsenal
```
