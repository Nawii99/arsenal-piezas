# arsenal-negocio-revisar-plan · Negocio · Revisar un plan y decidir mejor

Negocio · Revisar un plan y decidir mejor: 9 skills, 3 subagentes en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-revisar-plan@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| autopsia-previa-plan | Skill | Ataca tu plan antes de ponerle dinero: imagina que ha fracasado a los seis meses, busca por qué, ordena las causas y propone pruebas baratas para comprobarlas. | se activa sola cuando hace falta |
| choque-de-dominios | Skill | Cruza tu negocio o problema con un campo que no tiene nada que ver para sacar propiedades nuevas y convertirlas en ideas que se pueden probar barato. | se activa sola cuando hace falta |
| dar-la-vuelta-a-las-suposiciones | Skill | Saca lo que das por hecho en tu negocio, lo pone del revés una cosa tras otra y te dice qué límites reales y qué alternativas aparecen. | se activa sola cuando hace falta |
| examen-de-inversor | Skill | Lee tu plan como lo haría un inversor exigente y te dice si es financiable, si puede crecer y qué preguntas duras te harían. | se activa sola cuando hace falta |
| mesa-de-cuatro-miradas | Skill | Pasa un plan de negocio por cuatro revisores simulados (inversor, cliente, quien lo ejecuta y escéptico) y te enseña solo los puntos donde no coinciden. | se activa sola cuando hace falta |
| patrones-entre-sectores | Skill | Compara un problema de tu negocio con casos de otros sectores, separa patrones reales de anécdotas y propone experimentos pequeños para comprobarlos. | se activa sola cuando hace falta |
| prueba-de-extremos-negocio | Skill | Lleva un proceso, un precio o un servicio a escalas extremas (mucho menos y mucho más) para ver qué se rompe, qué sobra y qué depende de una sola persona. | se activa sola cuando hace falta |
| una-decision-que-quita-muchas-piezas | Skill | Ayuda a encontrar la idea o el cambio de suposición que haría sobrar a la vez varias herramientas, pasos, reglas, tarifas o productos de tu negocio. | se activa sola cuando hace falta |
| viabilidad-en-solitario | Skill | Comprueba si puedes sacar adelante tu plan tú solo con el tiempo, el dinero y las habilidades que de verdad tienes. | se activa sola cuando hace falta |
| desatascador-de-problemas-dificiles | Subagente | Toma un problema concreto en el que estás bloqueado, lo reformula, genera opciones con varios métodos creativos y te devuelve las tres mejores con una prueba barata para cada una. | pídele a Claude «usa el subagente desatascador-de-problemas-dificiles» |
| espejo-con-datos | Subagente | Busca patrones que se repiten en tus decisiones de trabajo y los convierte en hipótesis que puedes comprobar con pruebas pequeñas y con la opinión de otras personas. | pídele a Claude «usa el subagente espejo-con-datos» |
| probar-decision-en-varios-futuros | Subagente | Construye cuatro escenarios de futuro a partir de dos incertidumbres y comprueba cómo sale cada opción de tu decisión en cada uno. | pídele a Claude «usa el subagente probar-decision-en-varios-futuros» |
