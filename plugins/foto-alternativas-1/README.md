# arsenal-foto-alternativas-1 · Foto e imagen · Alternativas (1)

Foto e imagen · Alternativas (1): 16 comandos /, 7 skills, 1 subagente en español que se parecen a otras piezas de foto e imagen; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-foto-alternativas-1@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| alt-text-imagenes | Comando / | Escribe el texto alternativo, el nombre de archivo y el pie de foto de tus imágenes para que Google las entienda y sean accesibles. | `/alt-text-imagenes` o `/arsenal-foto-alternativas-1:alt-text-imagenes` |
| antes-despues | Comando / | Monta la pieza de antes y después de un trabajo, con las reglas para que sea creíble y no te metas en un lío legal. | `/antes-despues` o `/arsenal-foto-alternativas-1:antes-despues` |
| depurar-prompt-imagen | Comando / | Coge tu prompt de imagen que no sale bien, te dice exactamente qué falla dentro y te devuelve tres versiones corregidas. | `/depurar-prompt-imagen` o `/arsenal-foto-alternativas-1:depurar-prompt-imagen` |
| derechos-imagen | Comando / | Comprueba si puedes usar una imagen en tu negocio: licencias, bancos de fotos, imágenes de IA, marcas y personas que aparecen. | `/derechos-imagen` o `/arsenal-foto-alternativas-1:derechos-imagen` |
| fotos-para-marketplace | Comando / | Adapta tus fotos a las normas exactas de Amazon, Wallapop, Google Shopping, Etsy o el marketplace que uses, para que no te tumben la ficha. | `/fotos-para-marketplace` o `/arsenal-foto-alternativas-1:fotos-para-marketplace` |
| imagen-con-texto | Comando / | Crea imágenes donde el texto sale bien escrito y legible: carteles, portadas, promos y anuncios con palabras dentro. | `/imagen-con-texto` o `/arsenal-foto-alternativas-1:imagen-con-texto` |
| imagenes-marketplace | Comando / | Prepara las fotos de un producto para cumplir los requisitos técnicos de Amazon, Google Shopping, Shopify, Etsy o Wallapop sin que te las rechacen. | `/imagenes-marketplace` o `/arsenal-foto-alternativas-1:imagenes-marketplace` |
| imagenes-rapidas-web | Comando / | Deja las imágenes de tu web ligeras y bien nombradas, con su texto alternativo, para que la página cargue rápido y Google las entienda. | `/imagenes-rapidas-web` o `/arsenal-foto-alternativas-1:imagenes-rapidas-web` |
| licencia-imagen | Comando / | Comprueba si puedes usar una imagen en tu negocio: licencia, personas que salen, marcas visibles e imágenes de IA, y qué pruebas guardar. | `/licencia-imagen` o `/arsenal-foto-alternativas-1:licencia-imagen` |
| medidas-imagen | Comando / | Los tamaños y recortes de cada canal: Instagram, TikTok, YouTube, LinkedIn. Cómo no cortar lo importante. | `/medidas-imagen` o `/arsenal-foto-alternativas-1:medidas-imagen` |
| medidas-redes | Comando / | Convierte una imagen en todos los tamaños que necesitas para cada red y te dice dónde recortar para que no se coma nada importante. | `/medidas-redes` o `/arsenal-foto-alternativas-1:medidas-redes` |
| receta-estilo-visual | Comando / | Convierte tus mejores imágenes en una receta escrita y repetible para que todo lo que generes después tenga el mismo aspecto. | `/receta-estilo-visual` o `/arsenal-foto-alternativas-1:receta-estilo-visual` |
| receta-visual-marca | Comando / | Crea el bloque de estilo fijo que pegas en todos tus prompts para que todas tus imágenes parezcan de la misma marca. | `/receta-visual-marca` o `/arsenal-foto-alternativas-1:receta-visual-marca` |
| recortes-por-canal | Comando / | Convierte una sola imagen en todos los formatos que necesitas, con las medidas exactas y sin cortar lo importante. | `/recortes-por-canal` o `/arsenal-foto-alternativas-1:recortes-por-canal` |
| rescatar-foto-movil | Comando / | Diagnostica una foto que has hecho con el móvil y te da el plan exacto para repetirla o arreglarla hasta que parezca de catálogo. | `/rescatar-foto-movil` o `/arsenal-foto-alternativas-1:rescatar-foto-movil` |
| retrato-perfil-movil | Comando / | Guia paso a paso para sacar tu foto de perfil de LinkedIn o curriculum con el movil que ya tienes, y dejarla lista en las medidas correctas. | `/retrato-perfil-movil` o `/arsenal-foto-alternativas-1:retrato-perfil-movil` |
| antes-despues-servicio | Skill | Monta imágenes de antes y después creíbles y honestas para servicios: reformas, limpieza, jardinería, taller, peluquería o diseño. | se activa sola cuando hace falta |

| ficha-estilo-visual | Skill | Crea la ficha de estilo visual de tu marca: un bloque fijo de prompt para que todas tus imágenes de IA parezcan de la misma casa. | se activa sola cuando hace falta |
| imagen-para-marketplace | Skill | Prepara tus imágenes para cumplir los requisitos de Amazon, Google Shopping, Wallapop o Etsy y que no te rechacen la publicación. | se activa sola cuando hace falta |
| imagenes-rapidas-web-skill | Skill | Deja las imágenes de tu web ligeras y bien nombradas para que cargue rápido y Google las entienda, sin tocar código complicado. | se activa sola cuando hace falta |
| retrato-profesional-ia | Skill | Convierte tus selfies en retratos profesionales creíbles para web, LinkedIn o dossier, manteniendo tu cara reconocible. | se activa sola cuando hace falta |

| adaptador-formatos-visuales | Subagente | Coge tu imagen buena y te dice cómo recortarla para cada sitio (Reels, feed, Amazon, portada, anuncio) sin que se corte lo importante. | pídele a Claude «usa el subagente adaptador-formatos-visuales» |
