# arsenal-diseno-varios · Diseño · Más de diseño

Diseño · Más de diseño: 3 comandos /, 1 subagente, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-diseno-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| miniatura-youtube | Comando / | Diseña 5 conceptos de miniatura con idea visual, texto corto, composición y colores, prompt de imagen en inglés y pasos para montarla en Canva. | `/miniatura-youtube` o `/arsenal-diseno-varios:miniatura-youtube` |
| plantillas-redes | Comando / | Diseña el sistema de plantillas para tus redes: medidas exactas, rejilla, zonas seguras y reglas para que todo se vea de la misma familia. | `/plantillas-redes` o `/arsenal-diseno-varios:plantillas-redes` |
| presentar-propuesta | Comando / | Prepara cómo presentar tu propuesta de diseño al cliente y cómo defender cada decisión sin entrar en guerra de gustos. | `/presentar-propuesta` o `/arsenal-diseno-varios:presentar-propuesta` |
| taller-creativos-visuales-anuncios-redes | Skill | Prepara y mejora piezas visuales (posts, banners, anuncios, miniaturas) a partir de un brief claro, con varias direcciones, formatos listos y los textos legales a revisar. | se activa sola cuando hace falta |
| kit-de-plantillas-para-redes | Subagente | Te crea plantillas propias de post, carrusel y story con tu marca, editables cambiando el texto, sin depender de Canva. | pídele a Claude «usa el subagente kit-de-plantillas-para-redes» |
