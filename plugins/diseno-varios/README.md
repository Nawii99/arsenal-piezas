# arsenal-diseno-varios · Diseño · Más de diseño

Diseño · Más de diseño: 8 subagentes, 3 comandos /, 2 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-diseno-varios@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| miniatura-youtube | Comando / | Diseña 5 conceptos de miniatura con idea visual, texto corto, composición y colores, prompt de imagen en inglés y pasos para montarla en Canva. | `/miniatura-youtube` |
| presentar-propuesta | Comando / | Prepara cómo presentar tu propuesta de diseño al cliente y cómo defender cada decisión sin entrar en guerra de gustos. | `/presentar-propuesta` |
| rotulo-local | Comando / | Diseña el rótulo, el escaparate y los vinilos de un local con las medidas de letra correctas para que se lea desde la calle. | `/rotulo-local` |
| diagramas-procesos-embudos-mermaid | Skill | Convierte la descripción de un proceso, embudo, calendario o estructura de datos en un diagrama Mermaid que se ve en el navegador y se descarga como imagen. | se activa sola cuando hace falta |
| presentaciones-powerpoint-notas-plantilla | Skill | Crea o edita un archivo .pptx a partir de tu contenido, con diapositivas claras, notas del ponente y, si la tienes, tu plantilla de empresa. | se activa sola cuando hace falta |
| afinador-movimiento-respuesta-pantalla | Subagente | Revisa una web o app y propone, momento a momento, cómo debe responder la pantalla (toque, carga, éxito, error, vacío) con movimientos sobrios, accesibles y baratos de programar. | pídele a Claude «usa el subagente afinador-movimiento-respuesta-pantalla» |
| diseno-que-ayuda-a-decidir | Subagente | Revisa una pantalla o un recorrido de compra y propone cambios para que la persona decida con claridad, usando psicología sin trucos ni presión. | pídele a Claude «usa el subagente diseno-que-ayuda-a-decidir» |
| guia-de-proposito-y-legado | Subagente | Te guía con preguntas para aclarar tus valores, a quién quieres ayudar y qué tres acciones concretas harás este año, sin imponerte un propósito. | pídele a Claude «usa el subagente guia-de-proposito-y-legado» |
| optimizador-de-imagenes-web | Subagente | Deja tus fotos e imágenes ligeras y en el formato correcto para que la web cargue rápido sin que se vean feas. | pídele a Claude «usa el subagente optimizador-de-imagenes-web» |
| plan-aprendizaje-con-pruebas-reales | Subagente | Diseña un plan de 4 a 12 semanas para aprender una habilidad concreta de tu trabajo, con práctica semanal, repasos y pruebas con criterios claros de que la has aprendido. | pídele a Claude «usa el subagente plan-aprendizaje-con-pruebas-reales» |
| plan-entrenamiento-habilidad | Subagente | Convierte una habilidad que quieres mejorar en un plan semanal de ejercicios cortos con feedback, un registro de progreso y una regla clara para saber si avanzas. | pídele a Claude «usa el subagente plan-entrenamiento-habilidad» |
| plan-habitos-pasos-pequenos | Subagente | Convierte un hábito que quieres crear o dejar en un plan de pasos pequeños, con disparador, versión mínima, plan para días malos y revisión, y te manda a un profesional si el caso lo pide. | pídele a Claude «usa el subagente plan-habitos-pasos-pequenos» |
| revisor-de-usabilidad-de-pantallas | Subagente | Revisa los pasos que da una persona para hacer algo en tu app o web (menús, gestos, formularios, avisos de error) y devuelve problemas ordenados por gravedad con arreglos concretos. | pídele a Claude «usa el subagente revisor-de-usabilidad-de-pantallas» |
