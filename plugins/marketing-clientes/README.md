# arsenal-marketing-clientes · Marketing · Clientes y reseñas

Marketing · Clientes y reseñas: 11 subagentes, 6 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-marketing-clientes@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| disenador-formularios-formsite | Skill | Formulario o encuesta con lógica, textos limpios, aviso privacidad: listo para Formsite. | se activa sola cuando hace falta |
| encuesta-inscripcion-masiva-formdesk | Skill | Diseña una encuesta o inscripción, te ayuda a montarla en Formdesk y planifica los envíos y recordatorios; al cerrar, resume las respuestas. | se activa sola cuando hace falta |
| formulario-por-pasos-feathery | Skill | Diseña un formulario por pasos para Feathery: preguntas, textos de cada pantalla, lógica, consentimiento RGPD y plan de pruebas. | se activa sola cuando hace falta |
| negocio-local | Skill | Método para captar y fidelizar clientes de un negocio de barrio: ficha de Google, reseñas, WhatsApp Business, contenido local y qué automatizar y qué no. | se activa sola cuando hace falta |
| preguntas-segun-respuesta-fillout | Skill | Diseña en Fillout formularios donde cada persona solo ve las preguntas que le tocan, con mapa de lógica y matriz de pruebas. | se activa sola cuando hace falta |
| resenas-sin-trampas-gatherup | Skill | Prepara los mensajes para pedir opinión a clientes reales, redacta borradores de respuesta a reseñas y resume lo que dicen, sin filtros ni premios. | se activa sola cuando hace falta |
| beneficios-contrastados-con-clientes | Subagente | Contrasta los beneficios que dices de tu producto con lo que cuentan clientes reales y reescribe los mensajes con sus propias palabras. | pídele a Claude «usa el subagente beneficios-contrastados-con-clientes» |
| caso-real-a-caso-publicable | Subagente | Convierte la experiencia real de un cliente en un caso de éxito o un testimonio, comprobando antes que hay permiso por escrito y que cada cifra se puede demostrar. | pídele a Claude «usa el subagente caso-real-a-caso-publicable» |
| casos-de-exito-reales | Subagente | Convierte un caso real de cliente en un caso de éxito, un testimonio y textos cortos, comprobando cada dato y el permiso para publicarlo. | pídele a Claude «usa el subagente casos-de-exito-reales» |
| ensayo-general-presentaciones | Subagente | Presentación lista: claridad, orden del guion, preguntas difíciles anticipadas, plan ensayo. | pídele a Claude «usa el subagente ensayo-general-presentaciones» |
| entrenador-de-candidatura-cv-entrevista-sueldo | Subagente | Adapta tu CV a ofertas reales sin inventar nada, prepara las preguntas de entrevista con respuestas basadas en tu experiencia y te deja un guion para negociar el sueldo. | pídele a Claude «usa el subagente entrenador-de-candidatura-cv-entrevista-sueldo» |
| ficha-de-cliente-ideal | Subagente | Crea de una a tres fichas de cliente ideal con datos reales (reseñas, correos, llamadas, encuestas), marcando qué es dato y qué es suposición. | pídele a Claude «usa el subagente ficha-de-cliente-ideal» |
| gente-como-tu | Subagente | Reúne las pruebas reales de que gente parecida a tu cliente ya te elige (cifras, casos, encuestas, comunidad) y las convierte en textos que puedes demostrar. | pídele a Claude «usa el subagente gente-como-tu» |
| guion-y-ensayo-de-charla | Subagente | Prepara una charla o presentación con idea central, diapositivas, guion con tiempos, preguntas difíciles y plan de ensayo, con hábitos prácticos para manejar los nervios. | pídele a Claude «usa el subagente guion-y-ensayo-de-charla» |
| primera-impresion-coherente | Subagente | Revisa todos los sitios donde un cliente te conoce (web, perfiles, correos, presupuestos, respuestas) para que una buena primera impresión se mantenga y se apoye en pruebas reales. | pídele a Claude «usa el subagente primera-impresion-coherente» |
| primeras-horas-crisis-reputacion | Subagente | Ordena los hechos de una crisis de reputación, te ayuda a decidir si responder y redacta borradores de respuesta y de seguimiento, también en modo simulacro, para que los revise una persona. | pídele a Claude «usa el subagente primeras-horas-crisis-reputacion» |
| testimonios-y-avales-reales | Subagente | Testimonios y premios reales: los consigues con permiso, editas sin cambiar sentido, colocas. | pídele a Claude «usa el subagente testimonios-y-avales-reales» |
