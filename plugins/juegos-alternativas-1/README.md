# arsenal-juegos-alternativas-1 · Videojuegos y 3D · Alternativas (1)

Videojuegos y 3D · Alternativas (1): 28 comandos /, 5 skills en español que se parecen a otras piezas de videojuegos y 3d; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-juegos-alternativas-1@arsenal
```
