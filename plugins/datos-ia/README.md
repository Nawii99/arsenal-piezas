# arsenal-datos-ia · Datos e IA

Datos e IA: 30 comandos /, 18 subagentes, 8 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-datos-ia@arsenal
```
