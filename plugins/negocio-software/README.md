# arsenal-negocio-software · Negocio · Vender software y SaaS

Negocio · Vender software y SaaS: 12 subagentes, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-negocio-software@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| plan-mvp-saas-lanzamiento | Skill | Convierte tu idea de producto por suscripción en un plan de primera versión: qué construir y qué dejar fuera, herramientas, usuarios y cobros, y qué comprobar antes de lanzar. | se activa sola cuando hace falta |
| afinador-pruebas-gratuitas | Subagente | Diseña o revisa una prueba gratuita completa, con duración, avisos, ampliaciones y un paso a pago claro para el cliente. | pídele a Claude «usa el subagente afinador-pruebas-gratuitas» |
| calculadora-de-cambios-de-plan | Subagente | Calcula el prorrateo cuando un cliente cambia de plan a mitad de ciclo (subida, bajada o cambio lateral), enseña las cuentas paso a paso y redacta el mensaje para el cliente. | pídele a Claude «usa el subagente calculadora-de-cambios-de-plan» |
| calibrador-limites-plan-gratis | Subagente | Decide qué va gratis y qué se paga en una app, dónde poner los límites y cómo mostrar el plan de pago sin trucos. | pídele a Claude «usa el subagente calibrador-limites-plan-gratis» |
| disenador-comprobacion-licencias | Subagente | Diseña, en lenguaje claro, cómo comprobar por API las licencias de tu software cuando lo vendes a través de terceros, y deja una ficha lista para quien lo programe. | pídele a Claude «usa el subagente disenador-comprobacion-licencias» |
| disenador-de-modelos-de-cobro-para-software | Subagente | Cómo cobrar por software: prueba, versión gratis con límites, suscripción, pago único. | pídele a Claude «usa el subagente disenador-de-modelos-de-cobro-para-software» |
| lanzamiento-por-tandas-con-vuelta-atras | Subagente | Prepara el plan para sacar una versión nueva a tandas de usuarios, con qué vigilar en cada tanda, cuándo parar y cómo volver a la versión anterior si algo falla. | pídele a Claude «usa el subagente lanzamiento-por-tandas-con-vuelta-atras» |
| mapa-planes-y-accesos | Subagente | Define qué puede usar cada cliente según su plan, prueba, impago o baja, y comprueba que tu producto lo cumple de verdad. | pídele a Claude «usa el subagente mapa-planes-y-accesos» |
| plan-licencias-saas-multiempresa | Subagente | Pone por escrito cómo se reparten las licencias de un software por suscripción entre varias empresas clientes, con planes, jerarquías, administradores delegados y ciclo de vida. | pídele a Claude «usa el subagente plan-licencias-saas-multiempresa» |
| planificador-cobros-recurrentes | Subagente | Planifica por escrito cómo cobrar una suscripción con Stripe, PayPal o domiciliación: planes, recorrido del cliente, cobros fallidos, disputas y lo que deben validar gestor y abogado. | pídele a Claude «usa el subagente planificador-cobros-recurrentes» |
| planificador-licencias-clientes | Subagente | Planifica un portal donde tus clientes activan, renuevan y gestionan sus licencias solos, y decide si te conviene comprarlo hecho o construirlo. | pídele a Claude «usa el subagente planificador-licencias-clientes» |
| programa-marca-blanca-socios | Subagente | Diseña un programa para que socios y distribuidores revendan tu producto con su propia marca: modelo, qué lleva marca, registro de licencias y puntos del contrato para llevar al abogado. | pídele a Claude «usa el subagente programa-marca-blanca-socios» |
| revision-de-idea-de-plataforma | Subagente | Pone a prueba una idea de marketplace o plataforma de dos lados: efectos de red, fugas, dependencias, regulación y un experimento barato para comprobarla. | pídele a Claude «usa el subagente revision-de-idea-de-plataforma» |
