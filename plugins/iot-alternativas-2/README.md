# arsenal-iot-alternativas-2 · IoT y hardware · Alternativas (2)

IoT y hardware · Alternativas (2): 9 subagentes, 6 skills en español que se parecen a otras piezas de iot y hardware; la recomendada de cada grupo está en su plugin temático. Del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-iot-alternativas-2@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| mantenimiento-recurrente-iot | Skill | Diseña el contrato de mantenimiento de instalaciones IoT o domóticas, con el checklist de revisión y el precio, para tener ingresos que se repiten cada mes. | se activa sola cuando hace falta |
| presupuesto-instalacion-domotica | Skill | Redacta el presupuesto de una instalación de domótica con partidas, horas, margen y condiciones que evitan discusiones. | se activa sola cuando hace falta |
| red-zigbee-inestable | Skill | Por qué se desconectan tus dispositivos Zigbee y cómo arreglarlo (sin gastar de entrada). | se activa sola cuando hace falta |
| sensor-esphome-diy | Skill | El fichero listo para convertir una placa barata en un sensor propio: temperatura o humedad. | se activa sola cuando hace falta |
| servicio-mantenimiento-iot | Skill | Diseña un servicio de mantenimiento y vigilancia remota de las instalaciones que ya has hecho, con cuota mensual y alertas. | se activa sola cuando hace falta |
| videovigilancia-y-datos | Skill | Revisa que una instalación de cámaras o sensores cumpla lo básico de protección de datos: dónde apuntan, carteles, plazos y accesos. | se activa sola cuando hace falta |
| alertas-sin-falsos-positivos | Subagente | Convierte alertas que sobran o faltan en avisos fiables con retardos, histéresis y horarios bien hechos. | pídele a Claude «usa el subagente alertas-sin-falsos-positivos» |
| analista-consumo-electrico | Subagente | Convierte tus datos de enchufes en quién se come la luz, cuánto cuesta y qué mover de hora. | pídele a Claude «usa el subagente analista-consumo-electrico» |
| auditor-privacidad-camaras | Subagente | Revisa dónde van las cámaras de un negocio y deja la instalación en orden legal y técnico. Consulta si es decisión final. | pídele a Claude «usa el subagente auditor-privacidad-camaras» |
| auditor-red-zigbee | Subagente | Subagente que diagnostica una red Zigbee o Z-Wave que va lenta o pierde dispositivos, y te entrega el plan de arreglo ordenado. | pídele a Claude «usa el subagente auditor-red-zigbee» |
| autonomia-sensor-a-pilas | Subagente | Calcula cuánto durará la pila de tu sensor inalámbrico y qué cambiar para que dure meses. | pídele a Claude «usa el subagente autonomia-sensor-a-pilas» |
| calculadora-autonomia-bateria | Subagente | Calcula cuánto durará tu sensor a pilas o con panel solar y qué cambiar para que dure el triple. | pídele a Claude «usa el subagente calculadora-autonomia-bateria» |
| calculo-autonomia-sensor | Subagente | Calcula cuánto va a durar la pila de un sensor y qué ajustes hacen que dure el triple. | pídele a Claude «usa el subagente calculo-autonomia-sensor» |
| cazador-consumo-fantasma | Subagente | Analiza el consumo de tus enchufes medidores para saber qué aparato se come la luz en espera. | pídele a Claude «usa el subagente cazador-consumo-fantasma» |
| detective-falsas-alarmas | Subagente | Subagente que investiga por qué tu automatización se dispara sola o no se dispara, y te devuelve la regla corregida. | pídele a Claude «usa el subagente detective-falsas-alarmas» |
