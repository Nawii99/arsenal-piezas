# arsenal-diseno-interfaz · Diseño · Interfaces de web y app

Diseño · Interfaces de web y app: 4 subagentes, 1 skill en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-diseno-interfaz@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| pulir-diseno-visual-web-app | Skill | Revisa el diseño visual de tu web, tienda o app y propone cambios concretos de jerarquía, espacio, tipografía y color, ordenados por prioridad. | se activa sola cuando hace falta |
| afinador-movimiento-respuesta-pantalla | Subagente | Revisa una web o app y propone, momento a momento, cómo debe responder la pantalla (toque, carga, éxito, error, vacío) con movimientos sobrios, accesibles y baratos de programar. | pídele a Claude «usa el subagente afinador-movimiento-respuesta-pantalla» |
| diseno-que-ayuda-a-decidir | Subagente | Revisa una pantalla o un recorrido de compra y propone cambios para que la persona decida con claridad, usando psicología sin trucos ni presión. | pídele a Claude «usa el subagente diseno-que-ayuda-a-decidir» |
| ordenar-estilos-web | Subagente | Revisa los estilos de una web (CSS o Sass), encuentra lo repetido y propone colores, tamaños y espacios con nombre fijo, sin cambiar cómo se ve. | pídele a Claude «usa el subagente ordenar-estilos-web» |
| revisor-de-usabilidad-de-pantallas | Subagente | Revisa los pasos que da una persona para hacer algo en tu app o web (menús, gestos, formularios, avisos de error) y devuelve problemas ordenados por gravedad con arreglos concretos. | pídele a Claude «usa el subagente revisor-de-usabilidad-de-pantallas» |
