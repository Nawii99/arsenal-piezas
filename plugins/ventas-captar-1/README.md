# arsenal-ventas-captar-1 · Ventas · Captar clientes (1)

Ventas · Captar clientes (1): 18 skills, 3 comandos / en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-ventas-captar-1@arsenal
```
