# arsenal-video-guion-1 · Vídeo · Guion e ideas (1)

Vídeo · Guion e ideas (1): 20 comandos /, 3 subagentes, 2 skills en español, del Arsenal del Marketer.

## Instalar

```
/plugin marketplace add Nawii99/arsenal-piezas
/plugin install arsenal-video-guion-1@arsenal
```

## Qué trae

| Pieza | Tipo | Qué hace | Cómo se usa |
|---|---|---|---|
| auditoria-retencion | Comando / | Analiza los datos de un vídeo que ya publicaste y te dice dónde se va la gente, por qué, y qué cambiar en el siguiente. | `/auditoria-retencion` |
| clips-de-largo | Comando / | Encuentra dentro de un vídeo largo los momentos que funcionan como clip vertical y te da el corte exacto, el gancho y el texto en pantalla. | `/clips-de-largo` |
| clips-de-video-largo | Comando / | Saca de un vídeo largo o un directo los 6 trozos que funcionan solos en vertical, con su minutaje, su gancho reescrito y su recorte. | `/clips-de-video-largo` |
| demo-pantalla | Comando / | Guion y plan para grabar una demostración de pantalla que se entienda: qué mostrar, en qué orden, qué ocultar y cómo evitar los errores que la hacen ilegible. | `/demo-pantalla` |
| ficha-youtube | Comando / | Escribe el paquete de publicación de un vídeo: título, descripción, capítulos con tiempos, etiquetas, comentario fijado y texto de la pantalla final. | `/ficha-youtube` |
| ganchos-3-segundos | Comando / | Genera 12 aperturas distintas para el mismo vídeo (texto, imagen y primera frase) y te dice cuáles probar primero y cómo comparar resultados. | `/ganchos-3-segundos` |
| guion-demo-pantalla | Comando / | Prepara la grabación de pantalla de tu producto o servicio: qué enseñar, en qué orden, qué decir en cada clic y cómo dejar la pantalla limpia. | `/guion-demo-pantalla` |
| guion-tiktok | Comando / | Escribe 2 guiones de 20-40 segundos en primera persona que no suenan a anuncio (storytime y lista de 3), con texto en pantalla, descripción, hashtags y 5 ganchos extra. | `/guion-tiktok` |
| guion-video-cv | Comando / | Convierte tu CV y la oferta en un guion hablado de 60-90 segundos, con tiempos y versión para teleprompter. Es el paso que más se atasca y el que más tiempo ahorra. | `/guion-video-cv` |
| guion-video-cv-2 | Comando / | Escribes el guion de presentación de un cliente de 60-90 segundos: apertura, qué cuenta, cierre con llamada a acción. | `/guion-video-cv-2` |
| guion-video-presentacion | Comando / | Comando que escribe el guion de un vídeo corto de presentación con datos reales de la persona, y que sirve de ejemplo de cómo se escribe un comando propio con argumentos. | `/guion-video-presentacion` |
| guion-videocv | Comando / | Comando de Claude Code que escribe el guion de un vídeo currículum de 60 a 90 segundos a partir del perfil y del puesto que buscas, listo para leer en el móvil. | `/guion-videocv` |
| guion-vsl | Comando / | Escribe el guion completo de un vídeo de ventas de 5 a 15 minutos, con su estructura de bloques, minutaje y qué se ve en pantalla en cada tramo. | `/guion-vsl` |
| guion-youtube | Comando / | Guion de vídeo YouTube 8-15 min: 5 títulos, gancho 30 s, bloques, capítulos, cierre. | `/guion-youtube` |
| guiones-en-lote-video-presentacion | Comando / | Escribe de una tacada los guiones de vídeo de presentación de toda una lista de personas, uno por archivo, con una hoja de control para revisarlos. | `/guiones-en-lote-video-presentacion` |
| lista-broll | Comando / | Convierte un guion en una lista de tomas de apoyo (b-roll) grabables con el móvil, indicando qué grabar, cómo y en qué segundo entra cada una. | `/lista-broll` |
| plan-de-cortes | Comando / | Convierte una transcripción o una descripción de lo grabado en una lista ordenada de cortes con marcas de tiempo, para saber qué recortar antes de montar. | `/plan-de-cortes` |
| subtitulos-quemados | Comando / | Te saca los subtítulos de un vídeo, los corta al ritmo de lectura y te da el comando exacto para quemarlos con el estilo de Reels o TikTok. | `/subtitulos-quemados` |
| teleprompter-guion | Comando / | Transforma un texto escrito en un guion locutable: frases cortas, marcas de respiración, énfasis y ritmo, listo para leer a cámara sin sonar a robot. | `/teleprompter-guion` |
| texto-teleprompter | Comando / | Convierte tu guion en texto para leer a cámara: frases cortas, marcas de pausa, palabras que trabas y el HTML de un teleprompter que puedes abrir. | `/texto-teleprompter` |
| produccion-de-video-skill-guiada | Skill | Repite el mismo proceso cada vez que grabas: paso a paso igual, sin saltarte nada, con el mismo estándar. | se activa sola cuando hace falta |
| servicio-video-curriculum | Skill | Convierte el vídeo currículum y el vídeo de presentación profesional en un servicio con packs, proceso, entrega y cobro. | se activa sola cuando hace falta |
| adaptador-de-un-video-a-todas-las-plataformas | Subagente | Saca cada versión del vídeo: formato, duración, gancho y texto listos para YouTube, TikTok, LinkedIn y tu web. | pídele a Claude «usa el subagente adaptador-de-un-video-a-todas-las-plataformas» |
| auditor-de-retencion-de-video | Subagente | Analiza curva de retención y datos de tus vídeos publicados: qué segundos cortar, rehacer, repetir. | pídele a Claude «usa el subagente auditor-de-retencion-de-video» |
| auditor-retencion | Subagente | Analiza la curva de retención de tus vídeos y te dice los segundos donde se va la gente y qué cambiar. | pídele a Claude «usa el subagente auditor-retencion» |
